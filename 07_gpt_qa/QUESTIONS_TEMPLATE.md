# QUESTIONS_TEMPLATE — GPT 提问格式

复制下面模板，**每个问题一段**，不要合并。执行侧会按 `Q-id` 逐条回答。

```
## Q<n>｜<一句话问题>
- 为什么需要（要判断什么）：<它支撑哪个结论/决策>
- 我已读的文件：<仓库路径，1–3 个>
- 我需要的形式：<数字表 / 引用原文 / 判定 / 实验设计>
- 如果数据不存在，请直接告诉我缺失项，并给"最小可判别测量"
```

示例：

```
## Q3｜实机四轮 Fn 的参考值到底是测的还是反演的？
- 为什么需要：决定 W_A 的 Fn 一致性能不能当证据
- 我已读的文件：01_sim2real_bundle/docs/as2w_v2_simreal_rootcause_20261119/13_PHASE_J_FINAL_DECISION.md、07_gpt_qa/phase_hij_audit/results/wa_candidate_reaudit.json
- 我需要的形式：一个表（轮 / 值 / 来源类型 / 独立与否）+ 一句话判定
- 如果数据不存在：指出需要称重还是轮下传感器，并给最小实验
```

## 提问前请自查

1. 这个问题在 `07_gpt_qa/AVAILABLE_DATA.md` 里能查到吗？
2. 这个问题是否已经在 `04_our_analysis/RPT-*.md` 或 `07_gpt_qa/ANSWERS_ROUND_0.md` 里回答过？
3. 你要的是**数字**还是**实验设计**？两者回答方式不同，请写清。
4. 如果你的问题依赖 `.npz`，请改成"请执行侧从 npz 里取 X"，因为网页版读不了二进制。
