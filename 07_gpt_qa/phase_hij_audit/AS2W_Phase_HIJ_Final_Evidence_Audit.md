# AS2-W Phase H/I/J 最终证据审计：阶段一结果

日期：2026-11-21。范围：P55/P85/OG/OS 静态诊断与现有 Phase H/I/J 文档，未延伸到动态策略验收。来源包、现场日志和同事训练服务器均保持只读；新增脚本与结果只在 `GPUFREE服务器/04_诊断实验/phase_hij_evidence_audit_20261121/`。本阶段不运行新仿真或 RL。

## 结论先行

1. **I4 的 5.872 Nm 不是已经验证的 PhysX 接触力矩缺口。** 原脚本把根刚体质心当作整机质心。用同一归档接触时间序列和候选 URDF 的整机质心复算，平均外力矩残差由 **5.872 Nm 降到 0.124 Nm**。这消除了原报告用来推测“接触位置平均化造成 5.872 Nm”的主要数值依据。剩余 0.124 Nm 仍是聚合接触位置近似下的账本残差，不能直接解释为物理接触误差。
2. H2 的七会话 `tau_est - tau_PD` RMS **0.119–0.134 Nm** 可复现，但它只表明与固件估计一致。原文用地面稳窗较低的逐帧相关系数推断“tau_est 通道带宽较低”，证据不足。P55G2 四髋的 `tau_PD` 标准差仅 **0.016–0.022 Nm**，`tau_est` 每髋只有 **4–5 个量化值**，最小级差 0.05 Nm；±20 ms 的互相关峰位在 **0–2 ms**，未出现一致延迟。悬空 P55S 的信号幅度大得多，相关系数 0.974–0.997。现有静态窗不具备独立辨识驱动器动态带宽的激励和真力矩测量。
3. W_A 可作为**当前候选相对对照**，但不能叫已验证的 Sim2Real 验收基准。它与实机 pitch 接近；所谓四轮 Fn 误差 ≤1.6 N 的参考值是 G2 **模型反演量**，并非独立秤测。W_A 的前髋角差约 0.13 rad、前髋力矩估计差约 7.1 Nm；后髋角差约 0.065–0.068 rad、后髋力矩估计差约 3.6 Nm。
4. “接触约束与求解器设置显著影响静态解”由现有仿真支持；“实机有限接触斑是主要物理根因”仍是假设。I3 证明初态敏感，尚不足以证明多个**局部稳定**平衡分支。

## 一、I4：5.872 Nm 的独立复算

原脚本 `runs/as2w_v2_simreal_rootcause_20261119/scripts/i4_physx_contact_balance.py` 读取 2400 个 5 ms 稳窗帧，计算 `sum((contact_pos_w - root_com_pose_w) × net_forces_w)`。其 `root_com` 来自 `i_common.py` 中的 `robot.data.root_com_pose_w[0, :3]`。[Isaac Lab v3.0 官方属性说明](https://isaac-sim.github.io/IsaacLab/v3.0.0/source/api/lab_physx/isaaclab_physx.assets.html)将该属性定义为**根刚体**质心，而非整机质心。

复算脚本用归档圆柱轮 URDF、已记录的髋/大腿/小腿稳态平均角，通过完整关节树 FK 对各连杆质心按质量加权。固定在 base_link 的 JT128 被计入根刚体。交叉校验：URDF 得到根刚体质量 **10.58 kg**，由根姿态重建的根刚体质心与 PhysX 归档 `root_com` 的差值均值 **0.047 mm**、最大 **0.084 mm**；整机质量 **26.0 kg** 与 PhysX 运行记录相同。这验证了坐标系、四元数顺序及固定连杆合并口径。

| 量 | 复算结果 |
|---|---:|
| 根刚体质心，base 坐标 (x,y,z) | (0.045707, −0.000700, 0.020441) m |
| 整机质心，base 坐标 (x,y,z) | (0.017358, −0.000317, −0.053520) m |
| 整机相对根刚体质心的世界 x 差 | −0.023076 m |
| 原报告：分别取时均后叉乘 | **5.872134 Nm** |
| 仍用根刚体质心，改为逐帧叉乘再平均 | **5.872096 Nm** |
| 使用整机质心，逐帧叉乘再平均 | **0.124494 Nm** |
| 修正后平均力矩向量 (x,y,z) | (0.016145, −0.015744, −0.122434) Nm |
| 修正后前/后半窗平均力矩向量 | (0.025608, −0.015103, −0.111241) / (0.006683, −0.016385, −0.133628) Nm |

23.1 mm 的 x 差乘 255.06 N 模型重力，对应约 **5.89 Nm**，与被消除的 y 向力矩相符。另一个被质疑的“先平均后叉乘”问题在本稳窗仅影响约 0.00004 Nm，不是这次残差主因。

**剩余限制：**归档中只有稳态平均关节角，没有逐帧关节角，整机质心的逐帧值是以平均角和逐帧基座姿态近似重建；`contact_pos_w` 是聚合位置，归档没有每个接触点的力—位置配对或接触扭矩。0.124 Nm 是该近似账本的结果，不应标为精确真实外力矩。原脚本对 `weight_model=255.06 N` 的说明也明确它由模型 26 kg 得到；即使另有相近的实机称重记录，I4 的该项并不是独立秤测输入。

**阶段决策：**撤回“5.872 Nm 支持接触点平均化误差/接触流形差异”的归因。现有数据已足以解释这个大残差的主要来源；不为它立即安排新的 PhysX 实验。

## 二、H2/H3/H1：观测来源与带宽结论

`tau_PD = kp(q_des-q)+kd(dq_des-dq)+tau_ff` 是由命令及固件反馈 q/dq **计算**的理想 PD 值。`tau_est` 是 HG LowState 的**固件估计**；`residual=tau_est-tau_PD`。独立重算七个窗口的 12 腿轴 RMS：OG 0.1220、OS 0.1195、P55G1 0.1264、P55G2 0.1337、P55G3 0.1263、P55S 0.1193、P85DS 0.1199 Nm，和 H2 表一致。这不是实际输出力矩相对独立测力装置的标定误差，也不能独立排除承载时的传动损失或固件削顶。

H2.4 地面相关系数低的同时，P55G2 四髋的 `tau_PD` 稳窗标准差只有 0.016–0.022 Nm，和 `tau_est` 0.05 Nm 量化级差同量级。P55S 信号标准差 0.092–0.276 Nm，相关系数自然更高。我们的 ±20 ms 互相关峰在 0–2 ms，差分互相关峰值亦低；频域结果受静态窗激励、量化和固件估计算法限制。**不能由这些数据单独估出真实电机带宽或宣称 `tau_est` 滤波低于理想 PD。** H2.4 应写成“地面稳窗相关较低，原因待辨识”。

H3 的 0.0096 rad 是**悬空固定基座仿真平衡角与实机记录角的 RMS 差**，不能用作编码器独立精度预算。H1 在其原作者环境没有 P55 发布端本地源码，只依据上游文档行号及命令记录复核。当前 Windows 项目有 `cpp_deploy-as2w` 源文件，但它是后续维护快照；未核实与 11-19 实机会话源码同 SHA 前，不应反写成“当时直接审计了相同源码”。

## 五、仍不能判断的问题与下一门槛

- 没有四轮独立法向力、接触斑、真实摩擦/柔顺性数据，不能把某个接触模型确认为真实轮胎的物理表示。
- `tau_est` 的固件计算、滤波、绝对标定及高负载行为未知；静态残差不能排除动态/高载异常。
- PhysX `contact_pos_w` 仅暴露平均位置；[Isaac Lab v3.0 ContactSensor 文档](https://isaac-sim.github.io/IsaacLab/v3.0.0/source/api/lab/isaaclab.sensors.html)没有提供本包所需的逐点力—位置配对。修正后的 0.124 Nm 也不能被精确拆成接触点、接触扭矩、角加速度或四舍五入误差。
- I3 现有 7 条件×2 次重复、60 s 内终态不同且 `settle_ok=true`，但没有终态局部扰动后回归、延长时长收敛或跨步长同一吸引域检验。
- H1 发布端历史源码的 SHA 与当前维护源码尚未对齐；命令记录仍是该实机会话合同的直接证据。

**阶段一判断：**先不启动新 PhysX，也不修改正式 URDF/MJCF、策略或训练。若要进一步确认 I4 的剩余小残差，下一步是在用户自有服务器的隔离副本上记录逐帧关节角、各连杆质心及质量，并先复现原 I4 基线。I3 长时/终态扰动是另一个有价值的条件实验，但须先通过运行环境和基线对齐。有限接触区域候选模型仅作结构敏感性试验；没有独立实机接触数据不能用来“证明根因”。

**阶段一 RL 判定：**P55 静态缺口尚不具备据此重训的依据。R2000A 零速动作饱和翻转与 unitreestyle 弱转向、后腿下沉另立动态策略任务；其训练决定不能由本静态审计代替。
