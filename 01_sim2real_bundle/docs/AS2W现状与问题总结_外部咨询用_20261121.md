# AS2W 残差滚动策略：现状与问题完整总结（2026-11-21，供外部咨询）

## 0. 一句话现状

交付中的复合残差策略 `as2w_residual_run2000a` 行走安全但存在两类未解决问题：
①真机零速档腿目标 25Hz 满幅翻转（0.3577 rad/20ms）导致伺服啸叫——根因是**冻结的 base actor 饱和翻转**，残差被门控关断无法修复，目前只有部署侧滤波缓解（已验证），根治需重训 base（未拍板）；
②跨仿真域（Isaac→MuJoCo）转向场景 YAWR 五档续训全部倒地（混沌带内），MuJoCo 在环残差续训 500 it 未能兑现跨域增益，但证明了对 Isaac 侧零回退。

## 1. 任务与机器人背景

- 机器人：AS2W 四足轮足混合（Unitree 风格），12 腿关节（FL,FR,RL,RR × hip,thigh,calf）+ 4 个主动轮。
- 控制周期：**50 Hz（20 ms）**。腿关节位置 PD：KP=55, KD=2；轮子速度伺服 KD=2。物理步长 0.005 s × decimation 4 = 0.020 s（两仿真器一致，曾因 dt 契约不一致踩坑）。
- 目标：全向轮足滚动行走的 RL 策略，Isaac Lab 训练，MuJoCo 做 sim2sim 验证，最终部署真机。
- 部署形态：`weights.npz`（纯 numpy 推理）+ ONNX，运行时 `runtime/contract.py`。

## 2. 策略架构（复合残差合同，关键）

```
action = clip( base_mlp(obs) , -1, 1 )  +  gate * LIMIT * tanh( residual_mlp(obs) )
gate   = clamp( max(|vy_cmd|/0.15, |wz_cmd|/0.35), 0, 1 )
LIMIT  = 0.24    # 残差幅值上限
```

- obs 58 维：[0:3] 指令 (vx,vy,wz)；[3:6] 体坐标角速度；[6:9] 体坐标投影重力；[9:25] 腿角−默认角（轮置零）；[25:41] 16 关节速度×0.05；[41:53] 上一帧腿目标/0.25；[53:57] 上一帧轮目标/12；[57] 常数 0.37（非实测高度）。
- 动作后处理：腿目标 = 默认角 + LEG_SCALE(0.25)×action，经 10 Hz 一阶低通（ALPHA_LEG=0.7154/帧）；轮目标 = vx/0.086 经 5 Hz 低通，±12 rad/s 钳位。
- base 和 residual 均为 4 层 MLP（ELU）。
- **训练时 base 冻结、只训 residual**（run-2000-a 的合同）。这个设计是后面问题 ①的结构根源。
- obs[41:57] 的上一帧目标反馈环经消融证明是**站立承重结构**：切断后机器人直接倒地（tilt 62°），不可移除。

## 3. 训练历程（干了什么）

### Phase 1：Isaac 侧域随机化（DR）续训
- 在训练仓对 Isaac 环境加域随机化（摩擦、质量、PD 增益等），resume 续训，每 100 it 做 Isaac/MuJoCo cross-check + TensorBoard 曲线。
- 五档完成后产出 **u3720** 热启动 checkpoint；Isaac 侧十场景全存活，MuJoCo 侧仅剩 YAWR 倒地。

### Phase 2：MuJoCo 在环混合续训（刚完成，本文重点）
- 自研 MuJoCo 矢量化 RL env（`mujoco_env.py`）：与 Isaac 完全同合同的 58obs/16action、对齐 reward/termination；Isaac+MuJoCo 混合 VecEnv；on-policy PPO 风格自定义 learner（`train_phase2.py`/`learner_phase2.py`）。
- 从 u3720 热启动，**5 档 × 100 it**（u3820/u3920/u4020/u4120/u4220，MuJoCo envs 1024→2048），每档跑双门：
  - **G1** = MuJoCo 闭环 8 场景（STAND/FWD/REV/LEFT/RIGHT/YAWL/YAWR/MIX），门=存活（tilt>60° 或 z<0.15 算倒）+ 动作质量（anti-chatter，见 §5）
  - **G2** = Isaac flat 11 场景相对基线无回退（速度 MAE，_regressed 列表须为空）
- 训练中加了**抗颤振正则**（见 §5.3）：动作速率惩罚 + 饱和 hinge 惩罚，command=0 时权重加大。

## 5. 问题 ①：R2000A 零速啸叫（真机已复现的重大问题）

### 5.1 现象
真机零速指令下伺服/齿轮啸叫。策略输出在 ±1 满幅翻转：单帧腿目标步进 0.3577 rad/20ms，25Hz 交变。真机齿隙（backlash）把 25Hz 目标翻转变成 20–80Hz 振鸣。仿真里刚性 PD 下"无声无害"，所以训练时从未暴露。

### 5.2 根因（已用 bit 级证据定案）
- 颤振链：base 输出 ±1 rail-to-rail 翻转 × ALPHA_LEG(0.7154) × LEG_SCALE(0.25) × 2 = **0.3577 rad/20ms**。
- **源头是冻结的 base actor，不是残差**。证据：
  1. 4 个不同残差权重的 STAND chatter 轨迹逐位一致（17 位小数相同）；
  2. base 权重 diff = 0.000e+00（五档间）；
  3. 零速指令时 gate = max(|0|/0.15, |0|/0.35) = 0，**残差通路被完全关断**，composite = clip(base)。
- 因此残差侧的任何训练正则对零速啸叫**在数学上无效**——Phase 2 五档 STAND chatter 逐位不变再次证实。
- R2000A 文档 §5.4 原文"残差贴 ±1"的归因需要修正为 base。
- obs[41:57] 反馈环驱动 base 翻转自持，但该环是站立承重结构（切断即倒地 tilt 62°），不能简单移除。

### 5.3 已做的训练侧修正（对零速无效，但已证明无害）
- 抗颤振正则（MuJoCo env + Isaac env 双侧）：`(a_t−a_{t−1})²` 速率惩罚 + `(|a|−0.9)⁺²` 饱和 hinge；command≈0 时权重×3（W_RATE 0.25→0.75，W_SAT 0.10→0.50）。
- 结论：G2 零回退证明其无害；对行走平滑度仍有价值（FWD 的 20–30Hz 频带能量 20.9% 待压）；但零速 chatter 毫无变化（bit 级相同）。

### 5.4 已做的部署侧缓解（已验证，现运行时默认开启）
条件：`gate 强度 < 0.05 且 |vx| < 0.01`（**必须含 |vx| 条件**，否则 FWD/REV 因 vy=wz=0 被误钳——这是实现中踩过的坑）时：
- 腿目标低通 10 Hz → **0.5 Hz**（25Hz 翻转增益 −34 dB）；
- 每帧腿目标步进钳位 **0.02 rad**（= 1.0 rad/s 目标速度上限）。

MITIGATED 验证结果（8 场景 400 步）：
- STAND：step_max 0.3577→**0.0200**，step_p95 0.0143，flips50=5，20–30Hz band 2.04%→**0.0021%**，dq_rms 0.363→**0.231**（过 0.3 门），dq 翻转 1.38/s/关节（门 5/s）——**啸叫激励压到噪声级**。
- FWD/REV 位移与 raw 一致（+4.55/−4.49 vs +4.54/−4.48 m）——行走不受缓解影响。
- **诚实 FAIL 项**：STAND 目标方差 var=1.14e-02 > 1e-4 门。这是 base 饱和模式**慢速姿态游走**（非啸叫，是策略本体缺陷），部署滤波只能压激励不能除根。**var 这条门只有重训 base 才可能过。**

### 5.5 验收判据（已实现进 harness，R2000A 文档 §4）
- 门（GATE）：单帧腿目标步进 p95≤0.10 / max≤0.20 rad；50 帧窗内目标增量符号翻转 <8 次（幅值下限 0.005 rad 防伺服噪声误计）；20–30Hz 频带能量 ≤5%；STAND 专项加目标方差 ≤1e-4 rad²、腿 dq RMS ≤0.3 rad/s、dq 符号翻转 ≤5/s/关节（幅值下限 0.05）。
- 记录（RECORD，不拦截）：tilt_max/p95、height_min、dx/dy、vel_mean/vel_mae。
- 按 R1199 已验收参考（step max 0.063），现 base 策略的行走 gait 本身也是 bang-bang（FWD step_max 0.3513、band 20.9%）——**整个 base 的动作质量均不合格**，不只是零速。

## 6. 问题 ②：跨仿真域缺口（Isaac→MuJoCo）

- MuJoCo 闭环 8 场景里直行/侧移/站立在权重侧一直稳定存活；**yaw 类场景（YAWL/YAWR/MIX）跨域倒地**是主要缺口，Phase 2 的残差续训（含 MuJoCo 在环）5 档未能解决。
- 转向场景是强混沌系统：1e-5 rad 初始扰动翻转终态，因此：
  - 单次 rollout verdict 只能定性比较，不能用"某一档 YAWL 存活了"当作收敛证据；
  - 需要多 seed/多扰动 rollout 统计（尚未做，属后续计划）。
- YAWR 五档全倒是稳定的失败信号（非纯混沌噪声可解释）——怀疑 yaw 工况在 MuJoCo 侧有系统性建模差（轮地接触/侧偏、执行器带宽、齿隙均未建模），但这只是待验证假设。

## 7. 仿真/测试环节踩过的坑（已修复，列出来防止外部建议踩回去）

1. **dt 契约**：仿真 timestep × decimation 必须等于训练 POLICY_DT（0.02s）；同模型不同脚本行为差异先 diff harness 再怀疑权重。
2. **坐标系**：MuJoCo 自由关节 qvel[3:6] 是世界系角速度，须 R.T 转体系；真机 IMU 陀螺仪本身就是体系，直接喂（若再转一次就错了）。
3. **四元数顺序**：MuJoCo wxyz vs 常见 xyzw，回放曾因序错出现"闭环倒地"假象。
4. **诊断 harness 的 obs 切片 bug**：11 个同源消融脚本共享同一 obs 切片错误，导致"FWD 必倒需续训"的整体误判；下重结论前必须用参考 runtime 逐字段对拍 harness。该错误结论已作废。
5. **遥测表头 '...' 展开 off-by-one**：列静默错位产出 -1.0 假值；须锚点断言 + PD 残差自洽性终验。
6. **合同关节数组是 part-major**（k*4+i），不是腿 major（i*3+k）——载荷通道曾因此全零。
7. **零速缓解条件必须含 |vx|**：只看 vy/wz gate 强度会误钳 FWD/REV。
8. **GPU 被占位进程占用**（CUDA OOM）→ 诊断脚本用 CPU 跑。
9. **执行器建模缺口**：MuJoCo/Isaac 都是刚性 PD + 无齿隙，25Hz 目标翻转在仿真里无声，这是啸叫在仿真侧不可见的根因（文档 §6 建议 FOC 电流环一阶延迟 + backlash 模型，未做）。
