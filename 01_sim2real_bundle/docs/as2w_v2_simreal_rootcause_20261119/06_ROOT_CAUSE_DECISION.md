# 06 最终归因决策（Phase F）

日期：2026-11-20。输入：Phase A–E（`00`–`05`）。证据标签：`RAW_DATA_CONFIRMED` / `SIM_RUN_CONFIRMED` / `MODEL_CALCULATION` / `INFERENCE` / `SOURCE_CONFIRMED`；`UNKNOWN` 表示无独立实测。

## 0. 一句话结论

**悬空 hip 的 2–3 Nm 是重力项，两引擎与实机同符号同幅值（≤0.26 Nm）；地面 hip 的 11–15 Nm 反号是轮地接触项——它反号且大于腿部自重项约 4 倍。轮心几何错位（H5）是必要的第一资产修复（解释后腿约 7.6 Nm），但**不是充分原因**：PhysX 训练资产已含正确轮心仍复现不了实测，同资产 MuJoCo 与 PhysX 又定性分叉，说明剩余缺口在**轮地侧向力/轮胎柔顺接触模型**。实机是否存在该外撑侧向力，现有数据不可辨识，必须补两项实机测量。**

### Q2 地面力矩反号：接触项反号且大于自重？还是姿态变化已能解释？

**接触项反号且大于自重。姿态变化不能单独解释。`MODEL_CALCULATION`。**

P55G2：hip 重力项 g = +4.03/−4.04/+4.20/−4.20 Nm（与悬空同号），实测 tau = −11.81/+11.70/−15.15/+15.19。**接触项（电机侧账本残差）= tau − g = −15.84/+15.74/−19.35/+19.39 Nm**，是重力项的 3.9–4.6 倍且反号。
- **口径说明**：此残差与 Phase C `JOINT_TORQUE_DECOMPOSITION.csv` 的 `tau_from_contact` 列同口径（P55G2 FL −15.606 / RL −18.826，差值为 `tau_bias`），指「接触对电机力矩的载荷贡献」。05 §4 引用的 +7.8（前）/+11.0（后） Nm 则是**接触法向力对髋的力臂力矩**（Fn × 接触点至髋的 y 距离：47×0.165≈7.8、80×0.146≈11.0）——两者是不同的量，不可直接比较。
- 姿态变化（hip q −0.052→+0.214，thigh/calf 下蹲）只把重力项从 +2.8 抬到 +4.0，**不改变符号**；反号完全由接触项承担。
- 前后腿分项：前腿接触 −15.8、后腿 −19.4 Nm；后腿更大与后重 Fn（80 vs 47 N）一致。

### Q3 纯法向接触是否足够？需要多少 Fy？是否物理可行？

**不够。`SIM_RUN_CONFIRMED` + `MODEL_CALCULATION` + `INFERENCE`。**

- 正确轮心 + 实际姿态的 MuJoCo C1：前 hip −4.50（实测 −11.81 的 38%）、后 −11.69（实测 −15.15 的 77%）。剩余缺口 **前 7.3 / 后 3.5 Nm**。
- 该缺口需要**外撑侧向力**：Phase C 18 方程反演 Fy = 前 +24.1/−24.2、后 +18.6/−18.5 N（左轮 +Y、右轮 −Y，ΣFy=0）；仅用 hip 4 行的下界为前 46–49 / 后 57–67 N。
- 物理可行性：μFn ≈ 0.8×47 ≈ 38 N（前），M1 的 24 N 在摩擦锥内；hip-only 下界 46–49 N 已接近/超过 38 N，说明**纯 hip 通道需要接近锥极限**——这正是需要独立测量的原因。
- PhysX 反证：PhysX 也产生侧向力，但方向**向内**（FL −11.9、RL −29.7 N），把法向力矩抵消到 +4.4/+1.4 Nm；而实测仅法向力臂力矩就需 +7.8/+11.0 Nm，侧向还须**外撑**（Phase C 反演前 +24.1/后 +18.6 N）。**侧向力的方向是判别关键。**

### Q4 传动偏置还剩多少？

**非接触 hip 剩余项 ≤0.46 Nm，小量。`MODEL_CALCULATION`。**

Phase B 悬空重力校准后 hip 残差 +0.05/−0.14/+0.23/−0.02 Nm（P55S）、−0.07/−0.23/+0.13/+0.08（P85DS）、−0.23/−0.46/−0.24/+0.16（OS）。地面接触解扣除该偏置后 Fn/Fy 变化 <1.5 N、符号模式不变。**但未做 hip 扫角，只能约束、不能宣称摩擦/零位已被排除。**

### Q5 后 Calf 大误差怎么解释？旧 30/98 N 反事实还有必要吗？

**由真实姿态 + 前后 Fn 重分配解释；旧反事实不再必要。`SIM_RUN_CONFIRMED`。**

实测后 calf 15.1/14.8 Nm；MuJoCo C1 12.37/12.42（欠 2.7/2.4 Nm），其 Fn 后 78.2/78.4 vs 实测 80.2/80.0。**C1 用实际 pitch（−6.58°）和官方 CoM 自然复现了后重分配，无需人为设前轮 30 N / 后轮 98 N。** 剩余 2.7 Nm 与侧向通道同源。

### Q6 为何官方站立 hip 力矩较小？200/4 与 55/2、q_des 与 T2 要分开吗？

**要分开；官方差异由姿态（侧向力臂变小）解释，不是隐藏前馈。`SIM_RUN_CONFIRMED`。**

MuJoCo C1 用**官方 q_des + kp200/kd4** 给出 GO hip −6.25/+6.28/−5.80/+5.83，实测 −4.35/+5.61/−5.79/+4.46（后腿近精确，前腿偏大 44%）。官方 pose（thigh 0.6、calf −1.2、hip −0.15）比 P55 T2（thigh 0.8、calf −1.6、hip 0）的侧向力臂小，因此 hip 力矩小。**同一资产、同一引擎、只换目标与增益即可复现官方站立的小力矩——无需前馈假设。**

### Q7 Kp=85 的意义？

**悬空 e_q 随 Kp 变化符合 e_q = tau/kp，说明执行器静态模型可信；与地面接触建模独立。`RAW_DATA_CONFIRMED` + `MODEL_CALCULATION`。**

悬空下 tau 由重力决定，q 的偏移随 kp 反比变化，实测与理论一致。这验证的是**执行器/传动静态关系**，不能外推到地面高增益部署。**禁止据此给出地面高 Kp 建议。**

### Q8 哪一个仿真器错得更多？

**地面域 PhysX 错得更多；悬空域两者持平。`SIM_RUN_CONFIRMED`。**

|---|---|---|---|
| S | hip tau RMSE / hip q RMSE | 0.17 Nm / 0.0031 rad | 0.16 Nm / 0.0029 rad |
| G | hip tau RMSE / 12 关节 RMSE | **5.67 / 3.46** | **13.68 / 8.04** |
| GO | hip tau RMSE / 12 关节 RMSE | **1.22 / 1.03** | **9.91 / 5.87** |

G 的 hip RMSE PhysX 是 MuJoCo C1 的 2.4×，GO 是 8.1×。**MuJoCo C1（官方资产 + 轮心修正）是当前最好的地面静力学复现器。**

### Q9 MJCF 轮心修正的实质贡献？

**fixed λ 下静态杠杆 Δτ_hip ≈ 2.1–4.0 Nm/腿（与理论 Δr_y×Fn 吻合）；free λ 闭环下解释后腿约 7.6 Nm 与 pitch 约 4.2°。`SIM_RUN_CONFIRMED` + `MODEL_CALCULATION`。**

- **勘误（V2 复核，`f1_audit_phaseC.py`）**：本节原文写「fixed λ 下静态杠杆 ≤0.07 Nm」。该数值来自 `c1_ground_ledger.py` 的接触点构造 `xpos − [0,0,0.086]`——世界系下投影，**既不含轮体旋转也不含 C1 碰撞几何 54.6 mm 侧向偏移**；接触点被钉在轮 body 原点正下方，C0→C1 对它不可见，0.07 Nm 只反映 λ 二阶变化（hip 最小范数 0.65 vs 0.68 Nm），是该构造的伪影而非物理结论。
- **修正后的 fixed λ 反事实**：倾斜感知接触点（轮心 + R_body@[0,±0.0546,−0.086]）下，保持 C0 的 λ、仅把接触点移到 C1 轮心，Δτ_hip = −2.12/+2.10/−3.95/+3.84 Nm（P55G2；P55G1 −2.27/+2.20/−3.99/+3.79，OG −2.70/+3.60/−3.18/+2.51）——与理论 Δr_y×Fn（Δy=54.6 mm，Fn 30–96 N → 1.7–5.2 Nm）一致。数据：`tables/F_C_INVERSION_AUDIT.json` `fixed_lambda_dtau_hip_Nm`。
- free λ（Phase D 闭环，结论不变）：C0→C1 后腿 hip −4.11→−11.69（+7.58 Nm）、前腿 −1.67→−4.50（+2.83）、pitch −2.37→−6.58（−4.21°）、Fn 前/后 55/72→49/78。
- 对 14–16 Nm 的 Ground/Suspended signed gap：轮心修正静态杠杆贡献约 2.1–4.0 Nm/腿，闭环（含姿态/Fn 重分布放大）约 7.6 Nm（后腿约一半），其余是侧向通道。**必要但不充分。**

### Q10 数据缺口与最多两项补测

见 `RECOMMENDED_NEXT_ACTIONS.md`。按「消除不可辨识性 / 成本 / 安全」排序取前二：
