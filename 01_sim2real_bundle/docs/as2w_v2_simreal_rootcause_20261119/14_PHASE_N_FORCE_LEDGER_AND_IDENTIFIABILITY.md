## 0. 结论先行

1. **7.2 Nm 髋缺口不是共位形账本里的量。** 把模型放到**实机 q + 实机 IMU 姿态**（P55G2 窗 8–19 s）后，四轮点的接触力可以解释实测 `tau_est` 到 **最大 2.0 Nm**（26 kg 资产）/ **1.1 Nm**（27.512 kg 资产）；髋关节残差 0.22–2.0 Nm。**7.2 Nm 是"实机位形 vs W_A 落点位形"的差**，不是未解释力矩。→ `MODEL_CALCULATION`，直接推翻 RPT-018 §5.2 的"前髋缺口至少有一部分不是地面接触力"。
2. **3.1 Nm 的传动归因不成立。** 它由 7.2 − μ·Fn·h 得到，而 7.2 已不成立；共位形账本下的总未解释量 ≤2.0 Nm（且这是 4 点刚性模型的结构地板，不是已识别的传动损失）。等级维持 **UNKNOWN（T0 以下）**。
3. **髋力矩不是"只能走 Fy"。** 逐项分解 `(r×F)_x = r_y F_z − r_z F_y`：在实机位形下 `r_y F_z` 项（接触点相对髋的**横向偏移** 0.23–0.37 m × 法向力）是主项，`r_z F_y` 只占约 1/4。四轮的四项互相大幅抵消，净额才是髋力矩。RPT-018 §5.2 的单力臂 H 估算（7.2/0.3425→21 N）**忽略了两点**：跨位形重力项、以及 `r_y F_z`。
4. **Fy 的方向只在部分假设下可辨识。** 26 kg 资产：前轮区间 [6.96,12.41] / [−12.81,−6.42]（μ=0.25，2 Nm 带）不跨零；**后轮在 27.512 kg 资产下跨零**（RL [−15.12,+5.99]、RR [−5.93,+14.75]）→ 后轮方向 **UNKNOWN**。且共位形解的后轮符号与 G2 反演相反，说明"方向稳定"只在原来的点接触族内成立。
5. **MuJoCo 确实有单点接触力偶通道。** Phase K 的"只能写 3 个摩擦数 → 没有力偶通道"是**错误推理**：三个数分别是滑动、扭转长度、滚动长度；`condim=4` 加绕法向力矩、`condim=6` 再加切平面滚动力矩。smoke test 给出编译后 `dim=4/6` 与非零力矩分量。但**准静态速率下力矩远小于 `friction×Fn`**（受求解器摩擦阻抗支配），不能把它当作自由上界。
6. **本轮不恢复有限接触斑分支**；不重启同轴分片拟合；不启动 RL。

## 2. N0-2：共位形 6D + 12 关节静力账本

### 2.1 输入与方法

- 位形：P55G2 窗 (8, 19) s 均值，`q`（12 腿）`=[0.2142,−0.2155,0.2779,−0.2755,0.7467,0.7356,0.7044,0.7037,−1.7154,−1.7275,−1.875,−1.8743]`，`quat(wxyz)=[0.99853,−0.00060,−0.05352,0.00805]`（pitch −6.135°，roll −0.119°），`tau_est` 见下。
- 模型：`M_cylwheel`（C1 轮心几何，单圆柱，condim4，friction "1.0 0.05 0.001"，dt 0.002），资产两版：delivery 26.0 kg / load-v0 27.512 kg。
- 平衡式（qacc=0）：`qfrc_bias = qfrc_applied + J^T f`，即 `A f = b`，`b = qfrc_bias − [0_base; tau_est]`；未知量 `f` 为四轮 (Fn, Fx, Fy)。
- 约束：6D 基座平衡为**等式**；16 个关节行为 `|b_j − (A f)_j| ≤ tol`（tol 即"关节侧修正量"上界，不当作真实传动损失）；摩擦锥用内接八边形（保守）。
- 接触点：按实时位形取各轮圆柱最低点（世界系），四点高度 **0 / 4.4 / 3.1 / 3.7 mm**——刚性模型在实机位形下**四轮不共面**，这是"实机轮胎压缩约 4 mm"的几何读数，也是本账本的已知近似。

### 2.2 结果

| 量 | 26.0 kg | 27.512 kg |
|---|---|---|
| 基座 bias（N, Nm） | `[0, 0, 255.06, −0.093, −6.079, −0.003]` | 同（质量差异进关节/基座力矩） |
| 关节行 `b` 髋（FL/FR/RL/RR） | `15.834 / −15.739 / 19.350 / −19.391` | 同（`q`、`tau` 相同；差异来自 bias） |
| 最小 max\|δτ\|（对 16 关节） | **1.985 Nm**（μ≥0.2 全同） | **1.123 Nm**（μ≥0.2 全同） |
| 用 G2 力（Fn/Fy，Fx=0）的髋残差 | −0.92 / +1.135 / −1.472 / +1.409 | 同 |
| 用 G2 力的最大关节残差 | 2.862 Nm（RL_calf） | 同 |
| 最优解的髋残差（μ=0.25，2 Nm 带） | 0.659 / 0.221 / 1.265 / **−2.0** | 2.0 / 2.0 / −2.0 / −1.851 |

**关键读数**：
- 实测 `tau_est` 与模型重力项在实机位形下是**自洽**的：接触力只需提供 15.8/−15.7/19.4/−19.4 Nm 的髋广义力（`b` 的髋分量），G2 量级的力就能给到 16.75/−16.9/19.9/−19.8（残差 ≤1.5 Nm）。
- 在 W_A 落点位形同一账本只需 8.1/−8.1/11.6/−11.6 Nm，而该位形的 PD 力矩是 −4.61/4.63/−11.57/11.60——**两者相差约 7.2 Nm 正是"位形差"，不是"未解释力"**。
- 残余的 1–2 Nm 是 12 个力变量无法同时满足 16 个关节方程的结构地板（4 点、无 CoP 迁移、无力偶）。

### 2.3 逐项分解（实机位形，26 kg，μ=0.25 解）

`M_x = r_y F_z − r_z F_y`（r 为接触点相对髋）：

| 髋 | Σ`r_y F_z`（Nm） | Σ`−r_z F_y`（Nm） | 净 `M_x`（世界 x） | 广义力（关节符号） |
|---|---|---|---|---|
| FL | 主导项，四轮合计 ≈ +11.4（本轮自身轮） | 同轮 ≈ 3.5 | **−16.17** | +15.17 |
| FR | — | — | **+14.43** | −15.96 |
| RL | — | — | **−14.42** | +18.09 |
| RR | — | — | **+16.18** | −17.39 |

**要点**：`r_y F_z` 项在实机位形下是主项（接触点相对髋的横向偏移 0.23–0.37 m），`r_z F_y` 只占约 1/4；四轮贡献大幅互相抵消。**把缺口归成"需要 21 N 的 Fy"是错的**，因为它把 `r_y F_z` 与跨位形重力差都塞进了一个力臂。

### 2.4 限制

- 4 个刚性点、无 CoP 迁移、无力偶；`tau_est` 当作轴端输出（真实 `tau_out` 未测）；接触点取几何最低点，未含轮胎压缩后的压力中心。
- 四轮不共面 4.4 mm：若强制共面，力矩臂变化 ≤ `Fx·0.004` ≈ 0.05 Nm，不改变结论。
- **不**据此声明"账本已闭合"：残差 1–2 Nm 仍在，只是小了一个量级，且与 `tau_est` 定义混淆。

### 3.3 结论

1. 前轮 Fy 方向（外撑）在两个资产、μ=0.2–0.5 下都不跨零 → `INFERENCE` 级条件方向结论。

4. 2 Nm 带是"模型/估计不确定"的工程假设，不是实测噪声；换带宽会改变区间宽度，报告里必须写明。

## 4. N0-4：MuJoCo 4.0.1 接触力偶接口 smoke test

模型：1 kg 盒放平面（4 个角接触），`friction="1.0 0.010 0.005"`（滑动 / 扭转长度 10 mm / 滚动长度 5 mm），只改 `condim`。

| condim | 编译后 dim | 力矩分量（规定的相对速率下） | 判读 |
|---|---|---|---|
| 3 | 3 | 扭转、滚动全为 0 | 只有法向 + 2 切向 |
| 4 | 4 | 扭转：rate 0.1 → −3.4e−4 Nm；rate 1.0 → −3.4e−3 Nm | 绕法向力矩**存在** |
| 6 | 6 | 扭转同上；滚动：rate 0.1 → −2.02e−2；rate 1.0 → −4.30e−2 Nm | 切平面滚动力矩**存在** |

- `friction[1]×Fn = 0.098 Nm`、`friction[2]×Fn = 0.049 Nm` 是**摩擦长度给出的量纲上界**，但实测力矩在准静态速率下**远低于**该上界，且随速率近似线性 → 该通道在近零速时表现为**求解器阻抗**，不是库仑饱和。
- **结论**：① 接口存在，Phase K 的"没有通道"必须撤回；② 但把 `Fn·b/2` 或 `friction·Fn` 当成静态账本里可自由使用的力偶上界是**乐观的**；③ 本轮不因此恢复有限接触斑分支。
