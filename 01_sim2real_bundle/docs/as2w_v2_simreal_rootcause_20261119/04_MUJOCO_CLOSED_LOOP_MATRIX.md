日期：2026-11-20。方法：交付 MJCF `as2w_scene.xml`（deliveries/as2w-t15-layered-delivery-20261117/simulation/mujoco/）在真实控制合同（实测 kp/kd/目标）下闭环 PD 仿真（`qfrc_applied` 路径，50 s 收敛，末 20% 窗均值），对比实机精炼窗均值。两个资产变体：

- **C0（stock）**：交付 MJCF 原样——`*_wheel_coll` 碰撞圆柱位于髋枢轴正下方，碰撞轮距 0.3308 m；
- **C1（H5 轮心修正）**：四个 `*_wheel_coll` cylinder geom 加 `pos="0 ±0.0546 0"`（FL/RL +0.0546、FR/RR -0.0546），碰撞轮移到真实轮心（URDF/STL），轮距 0.3308 → **0.4400 m**。

三场景：S 悬空（固定基座 XML=悬挂带，无接触，P55 目标 T2 @55/2，初值=实测 P55S 收敛位形）；G 地面（自由基座、轮触地，P55 目标 T2 @55/2，对照 P55G2）；GO 地面官方（官方目标 [-0.15,+0.15,-0.15,+0.15, 0.6×4, -1.2×4] @200/4，对照 OG）。

脚本 `runs/…/scripts/d1_closed_loop_matrix.py`；产物 `runs/…/tables/MUJOCO_REAL_SIM_MATRIX.csv`、修正 XML 副本 `runs/…/mujoco_c1/`（C1）、`mujoco_s0/s1/`（去 freejoint 固定基座版）。SIM_RUN_CONFIRMED；实机列 RAW_DATA_CONFIRMED。MuJoCo 3.12.0。

## 0. Harness 完整性（本 Phase 发现并修复的三个 bug，及其影响面）

1. **MJCF 内置执行器污染**：交付 MJCF 自带 16 个 position/velocity 执行器（ctrl=0，腿 kp60/90、kv2/3）。用 `qfrc_applied` 施加外部 PD 时它们作为第二个隐形 PD 反向竞争（发现路径：S 场景 thigh 稳在 44/115=0.3826，恰为两 PD 平衡点；qacc=0 但外加力矩≠重力）。修复：`m.actuator_gainprm[:,:]=0; m.actuator_biasprm[:,:]=0`。**影响面声明：H 套报告（as2w-t15-layered 20261117）中一切基于该 MJCF 的 qfrc_applied 闭环结论（含 Layer B "hip 塌零/闭环不收敛" 类结论）全部失效，须以本套修正 harness 重跑后再引用。**
2. **基座 pinning hack 无效**：早期版本逐帧 `d.qpos[:7]=base0` 模拟悬挂——step 内基座是自由的（freejoint 仍在），动力学不连贯，S 场景腿折叠到 calf 限位。修复：改用删除 `<freejoint name="root"/>` 的固定基座 XML 副本（mujoco_s0/s1），悬挂语义正确。（固定基座下 pitch/roll 显示 90°/-96° 是 qpos 索引移位的显示假象，无物理意义。）
3. **保持力矩符号**：静止平衡要求 `tau_applied = qfrc_bias`（非 `-`）。旧版 `-qfrc_bias` 与错误 hip sign 形成双重抵消（见 02）。

另有方法论教训（Phase A/B/D 三处一致印证）：**hip sign 不能靠 PD 一致性或对称性单锚确定，必须用重力下垂物理锚**。V2 构建 hip sign=+1（模型坐标=原生值），与历史实机 clip 的 −1 相反；证据链与纪律见 00 §2。

## 2. G 地面 hipdiag：C1 修正轮心把复现度从 15-27% 提到 77-80%（后腿）

实机 P55G2 8-19：hip tau -11.81/+11.70/-15.15/+15.19，hip q +0.214/-0.216/+0.278/-0.276，pitch -6.13°，Fn 47/48/80/80（Phase C M1 反演）。

|---|---|---|---|
| hip tau FL/FR | -1.67/+1.68 | **-4.50/+4.53** | -11.81/+11.70 |
| hip tau RL/RR | -4.11/+4.11 | **-11.69/+11.71** | -15.15/+15.19 |
| hip q 前腿 | +0.030 | +0.082 | +0.214 |
| hip q 后腿 | +0.075 | +0.213 | +0.278 |
| pitch° | -2.37 | **-6.58** | -6.13 |

- **H5 轮心修正有效且方向正确**：仅加 54.6 mm 轮心偏移，后腿 hip 幅值 4.1→11.7 Nm（实测 15.2 的 **77%**）、pitch -2.4→-6.6°（实测 -6.1）、Fn 前/后分配与 Phase C 反演几乎重合（49/78 vs 47/80）。C0 全部严重低估。
- **剩余缺口集中在侧向/前腿**：sim 前腿 hip 仅 4.5（实测 11.8 的 38%）、后腿 hip q 0.213 vs 0.278。闭合到实测仍缺的正是 Phase C 指出的外撑侧向力通道——MuJoCo 点接触（单点、无轮宽）产生不了足够的横向力矩臂，与 Phase C 静力学推断一致（INFERENCE）。缺口量级=前腿 7.3、后腿 3.5 Nm。
- 结论：轮距错误（H5）是地面域 sim2real hip 失配的**主要资产根因**（把复现度从 ~15-27% 提到 77-80%），但非全部；剩余部分需轮宽接触建模（多接触点/摩擦锥）或实机侧向补测（Phase F）。

## 4. 综合结论

1. 悬空域：MuJoCo+PD 完整复现（hip ≤0.28 Nm / ≤0.005 rad）——H0/H1 定案。
2. 地面域：**H5 轮心错位是 Sim2Real hip 失配的第一资产根因**；修正后 pitch、Fn 分配、后腿 hip、后 calf 大部复现。
3. 剩余系统性缺口=侧向外撑力矩（前腿 7.3 / 后腿 3.5 Nm，G 场景）——静态点接触模型的已知极限，归因为轮宽接触/地面横向约束未建模，非腿链动力学错误（悬空域已排除该可能）。
4. 官方 GO 域复现良好（后腿近精确），该交付资产在轮心修正后可用于官方站立类任务的仿真侧开发。
