# 建议的下一步实机实验（V2 复核后修订，2026-11-20）

排序依据：**能消除多少不可辨识性 / 执行成本 / 安全风险**。两项都只做静态、低速、轮离地或低载荷工况，不需要跑策略。

> **V2 复核修订**：原「测试 2：单腿悬空 hip 扫角」**暂缓**。理由：三个悬空会话已把 hip 机械零位/传动摩擦（M5）的上界压到 0.02–0.46 Nm，比地面缺口 11–15 Nm 小 20–50 倍；空载 ±0.3 rad 扫角只能重复该上界，且若轮端受侧向约束会把 M3/M5 混在一起。若未来确需扫角，唯一有意义的问题是「hip 传动在 10–15 Nm 工作载荷下是否有随载荷增长的附加摩擦」，需要加载扫角而非空载扫角。详见 `docs/AS2W_悬空负载诊断V2_PhaseA-F复核与下一步计划.md` §7。

## 测试 1（首选）：四轮独立称重 + 整机 CoM 辨识

**要消除的不可辨识性**
1. 前后 Fn 分配（Phase C 反演值 47/48/80/80 N 对接触点模型敏感，不是直接测量）。
2. 整备质量是 26.0 kg（官方）还是 27.5 kg（load-v0 ×1.15）。
3. base CoM 是官方 0.035 m 还是 load-v0 的 0.020 m（−15 mm）。
4. 「前轮离地 12 mm」的支撑高差假设是否真实（旧 H6 反事实）。

**做法**
- 四个独立称重台/载荷传感器分别垫在四轮下，保持机器人**同一 P55 T2 位形**（hip 0、thigh 0.8、calf −1.6）与官方 OG 位形各一次。
- 四支撑面共面，高差 ≤±1 mm（水平仪 + 垫片逐点校）；每个轮下垫纸确认四轮均受力。
- 每姿态连续测 3 次、间隔 ≥3 min，要求单轮标准差 <1% 满量程。
- 记录四轮 Fn、总重、基座 pitch/roll（IMU 或外部水平仪）、每轮轮倾角、环境温度。
- 再用同一装置把机器人前后/左右各倾斜 ±2°，拟合整机 CoM 的 x/y。

**单秤 + 三刚性支撑（备选，须声明为初步测量）**
- 三个刚性支撑与秤面等高（高差 ≤±1 mm），一次只把一个轮放秤上，依次轮换四轮，每轮 3 次。
- 假设车架刚性、支撑高度完全匹配；车架柔顺或高度失配会重分配载荷，因此**只能作初步测量**。
- 校验：四次读数之和应等于整机总重，偏差 >3% 需重调支撑高度。

**判据**
- 总重 ≈255 N（26.0 kg）→ load-v0 的 ×1.15 质量不成立，训练资产应回退到官方质量；≈270 N（27.5 kg）→ load-v0 成立。
- 四轮 Fn 前/后 ≈47/80 N 且总重 255 N → Phase C 反演方向正确（数值仍受接触点模型影响）。
- 前轮 Fn 明显低于 47 N 或为 0 → 支撑高差/轮胎压缩假设成立，需要单独建模台阶/轮胎压缩。
- 拟合 CoM x ≈0.035 → 训练资产应改回官方 CoM；若 ≈0.020 → load-v0 成立。

**成本/风险**：低。静态、低速、无策略；只需载荷传感器与调平。**这是性价比最高的一项。**

## 测试 2（次选，新增）：轮子几何测量

**要消除的不可辨识性**
- Phase C 敏感性最大的三个接触假设：轮倾角、轮心位置（轮距/偏移/半径）、接触斑尺寸与轮胎压缩。V2 复核显示 Fn 对接触点模型摆幅 30%、后腿 Fy 符号随接触点定义翻转、μ_req 从 0.5 变到 1.2。

**做法**
1. **轮倾角**：数字倾角仪贴轮侧面，记录每轮相对地面的 roll/pitch，重复 3 次；对照模型 hip roll 0.28 rad 的预测。
2. **轮心位置**：卷尺测左右轮外/内侧面距离 → 轮距（模型 0.44 m）；测轮心离地高度（模型 0.086 m）；测轮心相对 hip 轴的 y 偏移（模型 0.0546 m）。
3. **接触斑**：轮下垫复写纸/压力纸，加载后取出，测接触斑长×宽；对照圆柱假设（宽 52 mm）。
4. **轮胎压缩**：测空载与整机加载时的轮心高度差，估算等效垂向刚度。

**判据**
- 轮倾 >0.05 rad、轮距偏离 0.44 m >5 mm、接触斑宽偏离 52 mm >30%、或压缩 >5 mm → 接触点模型需修正并回填反演。

**成本/风险**：极低。无需拆轮、无需上电。

## 不建议优先做

- **单腿悬空 hip 扫角**：见文首修订说明；空载扫角无新信息，加载扫角需专门加载装置，暂缓。
- **轮侧向力传感器**：需要在轮毂改装，成本高、周期长；称重 + 轮几何测量能在不改装的前提下先缩小问题。
- **重复老建议的全套扫角/多工况**：边际信息低。
- **地面高 Kp 部署**：Q7 只验证了执行器静态模型，不支持地面高增益结论。
- **RL 重训**：接触模型未定，重训会继承错误接触；待 P0 测量与 PhysX–MuJoCo 消融结论后再议。
