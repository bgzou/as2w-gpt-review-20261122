## 1. 最小测量组合（O1）

### 1.1 四项测量与能力边界

| 阶段 | 测什么 | 花费 | 能独立排除 | 不能排除 | 停止/回退 |
|---|---|---|---|---|---|
| **M0** | 与实机附件状态一致的整机质量 | 低 | 26.000 vs 27.512 kg 两资产（需 ≤0.2 kg 合成不确定度） | base CoM、四轮 Fn、μ、传动 | 质量介于两者或附件未核清 → 不选资产，保留区间 |
| **M4** | 前/后轮横向起滑 + 载荷—位移（两档 Fn × 两档轮倾 × 正反两向） | 中 | 该胎/该地面/该载荷下的侧向摩擦容量与剪切刚度 | 站立时 Fy 方向、四轮分配、Hip 输出力矩 | 先滚动/夹具滑移 → INVALID |
| **M1**（可选） | 前后轴同步载荷 | 低—中 | 总载荷与前后比例 | 左右单轮 Fn、后轮符号 | 轴载对支撑高度过敏 → 转 M2 |
| **M2** | 四轮 Fn 同步（+ q/IMU/轮倾） | 中 | 每轮法向反演是否真实；质量/CoM/Fn 联合约束 | 单靠 Fn 仍不能测 Fy/CoP/传动 | 四轮和 ≠ M0 或轮不共面 → 不合格 |

**精度目标**：M0 合成 ≤0.2 kg（不是分辨率）；M2 每轮 95% 扩展不确定度 ≤1 N（达不到就报实际值）；M4 的 μ 重复性 ≤10%、与夹具阻力可区分。

### 1.2 按目标分流

| 你的目标 | 需要的组合 | 能得到的结论 | 不能得到的结论 |
|---|---|---|---|
| 只要**模型条件**的前轮 Fy 方向 | O0 已完成即可 | "在 4 点刚性 + 指定质量/μ/误差带下前轮外撑" | 真实方向 |
| 检查前轮**有没有能力**提供所需 Fy | M0 + M4（用实测 μ 重算修正后 SOCP 可行域） | 该 μ 下前轮 Fy 容量是否够 | Fy 的符号/分配 |
| 评价四轮账本、后轮方向、1–2 Nm 残差 | M0 + M2（+ M4 更好） | 后轮符号能否定；残差是否仍超预算 | 传动是否存在 |
| 判断是否真有 `tau_est−tau_out` | O0 + M0/M2 +（M4/CoP）+ 髋台架 | T1/T2 | 台架单独不能定 P55 缺口 |

### 1.3 先 M2 还是先 M4

- 现场能方便拿到四轮同步秤：**M0 → M2 → M4** 物理上最直接（Fn 是后轮符号争议的核心）。
- M2 设备暂时没有：**M0 → M4（筛查）→ M1/M2** 合理。
- **M4 只测容量，不决定接触力正负号**；不得把 M4 结果升级成"前轮 Fy 方向已实测"。

## 2. 髋带载台架（O2）

### 2.1 要区分的量

```
δτ_est-out(q, L, T) = τ_est − τ_out
```

只有**独立于驱动器估计**的 `tau_out` 测量才能把这个差叫"估计误差"。编码器 + LowCmd + `tau_est` 的自洽、或悬空重力项复现，都**不是**输出轴力矩标定。

### 2.2 目标分辨率与不确定度（预注册）

| 目标 | 要求 |
|---|---|
| 扭矩显示分辨率（或等效力矩分辨率） | ≤ **0.05–0.10 Nm** |
| 判 **1 Nm** 偏差的 95% 扩展不确定度 `U95(δτ)` | ≤ **0.3 Nm** |
| 只判 **2 Nm** | ≤ **0.5 Nm**（可作初筛） |
| 力传感器（L=0.25 m 时） | 1 Nm ↔ 4 N；2 Nm ↔ 8 N；15 Nm ↔ 60 N；0.1 Nm 需 ≤0.4 N 力分辨 |

**这是选型量级，不是加载指令。** 校准偏差、作用线误差、支撑摩擦通常比分辨率更关键。

### 2.3 不确定度预算（必须逐项列出）

力传感器零点/线性/滞后；力臂长度；作用线与关节轴夹角；实际 q；负载转移；工装挠曲；重力模型；温度；`tau_est` 时延/滤波/重复性。
**不要简单相加**：给校准证书值、统计误差、主要系统误差，说明合成方法（RSS 或蒙特卡洛）。

### 2.4 载荷方向与最小矩阵

- 先把关节轴方向 `a_h` 与力点 `r` 用 3D FK 求出；外载沿**侧向正反两向**施加，使 `a_h·(r×F)` 变号；另加垂向已知负载对照。
- 姿态：P55G2 的四个 Hip 角附近 + 官方 OG 角。
- 载荷：先低载检查，再覆盖接近实机 P55 的 Hip 负载区间（级别由厂家额定与工装安全审批定）。
- 过程：升载、卸载、反向；每级 ≥3 次；记录温度与 q。
- 安全：额定基座/输出端夹具、防跌落、急停、力/力矩硬上限、受训人员；**不得用高 Kp 顶机械限位**。

### 2.5 判别方法

1. **同位形负载差分**：`Δtau_est` vs `Δtau_out`，消去重力零点；q 不一致时用实测 q 修正（Kp=55 下 Δq=0.005 rad ≈ 0.275 Nm 位置项）。
2. **正反向对照**：误差是否随方向变号、是否有加卸载滞回。
3. **跨角度**：误差是否随姿态变；不要从单角度外推。
4. **与修正账本对拍**：同 Hip、同角度/负载下，台架 `δτ` 的**方向与区间**要和账本残差一致。

### 2.6 三级结论与两条"不许"

| 等级 | 条件 | 允许表述 |
|---|---|---|
| **T0**（当前） | 只有条件模型残差（1.4–2.2 Nm） | 传动 `UNKNOWN` |
| **T1** | 独立 `tau_out`，`|δτ̂| − U95 > 0`，方向/负载可重复 | "该 Hip 在此台架工况存在估计—输出差" |
| **T2** | O0 + 独立 Fn + μ/CoP 约束后账本仍超预算，台架差与账本**同关节/同位形/同负载/同符号** | 可把**区间中的一部分**归给传动/输出估计层 |

- 只有拉力计 + 外载位移、没有独立 `tau_out` → **`T1_NOT_IDENTIFIABLE`**，不能叫"tau_est 标定"。
- `U95 ≥` 候选差额 → **`UNDERPOWERED`**，不得硬下结论。

### 2.7 与修正后账本的对接门槛

修正后 `t* = 1.384 Nm（load-v0）/ 2.157 Nm（26 kg）`。
- 若台架 `U95 ≤ 0.3 Nm`：可以判 1 Nm 级差；
- 若只有 `U95 ≈ 1 Nm`：只能判"是否 ≥2 Nm"，不能定量对接 `t*`；
- 若 `U95 > 2 Nm`：不要做这个实验，先升级工装。

## 3. 决策顺序（给项目负责人）

```
O0 已通过（本轮）
   │
   ├─ 只做离线 → 报告"模型条件方向 + t* 基线"，停
   │
   ├─ 有 M2 设备 → M0 → M2 →（M4）→ 修正账本重算 → 后轮符号是否仍跨零？
   │        ├─ 不跨零 → 条件方向结论，停
   │        └─ 仍跨零 → 侧向变形/力板（不是更多接触模型）
   │
   └─ 无 M2 设备 → M0 → M4（容量筛查）→ 用实测 μ 重算可行域
            └─ 若账本仍不闭合且 U95 达标 → 髋台架（T1）
```

**结论**：M0+M4 能筛"摩擦容量够不够"，**不能**证实"真实 Fy 方向"；要把 1–2 Nm 与传动解耦，**M2 的独立 Fn 是关键**。
