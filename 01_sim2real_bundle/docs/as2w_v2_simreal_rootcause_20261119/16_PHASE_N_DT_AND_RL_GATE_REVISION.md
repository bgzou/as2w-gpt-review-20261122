## 1. 现有 dt 证据（同一初态、同一物理时间 360 s）

| 分支 | dt 0.00125 | dt 0.0025 | dt 0.005 | dt 0.01 |
|---|---|---|---|---|
| `hip_p002` | **2.198** | 4.014 | 4.696（480 s：4.622） | 3.175（360 s 仍在漂） |
| `pitch_p2` | 未跑 | 1.665 | 1.443（480 s：1.436） | 2.392（360 s 仍在漂） |
| 间距 | — | 2.35° | 3.25° | 0.78°（收窄中） |
| `dq P99`（pitch_p2） | — | 0.438 | 0.400 | 0.089 |

**收敛趋势（关键）**：`hip_p002`：0.01 → 3.175、0.005 → 4.696、0.0025 → 4.014、**0.00125 → 2.198**。
- 0.005 是离群高点；0.0025→0.00125 又下降 **1.82°**，**不是收敛，而是随步长继续移动**。
- 0.00125 的 60/120/180/240/300/360 s = 3.390/2.438/2.160/2.172/2.185/2.201：60→180 s 有一次 ~1.2° 的下移，之后稳定在 2.16–2.20。
- `dq P99=0.302`、`settle_time=359.22 s`：仍有间歇腿速（>0.2 rad/s 到接近末段）。
- **结论：上分支的终态由步长强烈选择，0.0025↔0.00125 不满足 0.15° 门（差 1.82°）。"两个观测到的局部稳定终态"只能写成"在 dt 0.0025–0.005 窗口内观测到"，不能写成物理平衡点，也不能跨 dt 外推。**

**480 s 漂移（360→480 s）**：
- dt 0.0025：hip +0.060°、pitch −0.003°（无扰动）
- dt 0.005：hip −0.089°、pitch −0.016°
- dt 0.01：无法评价（360 s 仍未收敛）

**扰动（+0.1° 同进程，dt 0.0025）**：净效应 −0.010°（hip）/ −0.006°（pitch），远小于扰动幅度。

- dt 0.005 的 `pitch_p2` 在本次 480 s 对照里再次出现：180 s=3.023 → 240 s=1.458，之后 1.43–1.45。

## 4. `settle_ok` 的真实含义（必须降级）

`settle_ok = 四轮 Fn>5 N 且 末步 dqmax<0.2 且 pitch 有限`。
它**只检查最后一步**。`pitch_p2` 在 dt 0.0025/0.005 的 `dq P99` 是 0.43/0.40、`settle_time` 479–480 s，说明该分支**一直有间歇腿速**，却仍判 `settle_ok=true`。

**修订**：任何报告引用 `settle_ok` 时必须同时给末 60 s 的 `dq P95/P99`、pitch 漂移、四轮接触切换次数；只写 `settle_ok` 视为无效。

## 5. 双时钟方案

| 时钟 | 用途 | 配置 | 状态 |
|---|---|---|---|
| **历史/训练回归时钟** | 与既有权重、历史实验可比 | `physics_dt=0.005`、`policy_dt=0.020`、`decimation=4` | 保留；**不是**物理正确性证据 |
| **离线高精度检查时钟** | 静态/接触可行性检查 | `physics_dt=0.0025`、`policy_dt=0.020`、`decimation=8` | 待验候选（跨 dt 0.10–0.68°，未过 0.15° 门） |
| 压力/反例 | 观察数值失稳 | `physics_dt=0.010` | 只记录"未收敛"，**不作验收** |
| 更细对照 | 判断收敛趋势 | `physics_dt=0.00125`、`decimation=16` | 单条条件运行 |

**纪律**：不得用"某个 dt 下通过"替代物理真值；不同 dt 的结果只在**相同物理时间、同一初态、同一控制目标周期**下比较。

| 类别 | 阈值 | 用途 |

## 7. Gate 修订（新增 G1-K）

| Gate | 状态 | 说明 |
|---|---|---|
| G0 合同/资产 | **PASS**（范围不变） | 关节序/符号/零位、控制合同、资产版本、悬空重力已验证；**不能**由此推出 `tau_out` 准确 |
| G1 接触/数值稳定性 | **PARTIAL** | W_A/C0 仅相对对照；同轴分片 CLOSED；跨 dt 未过 0.15° 门；dt 0.01 不可作验收 |
| **G1-K 已知静态缺口声明** | **OPEN / MUST DISCLOSE** | 每次训练准备、回放、评审必须列出：P55G2 的 `q/τ_est` 与仿真差、Fy 条件区间、Fn/μ/τ_out UNKNOWN、dt 未收敛、7.2/3.1 Nm 的勘误 |
| G2 独立物理约束 | **BLOCKED** | 需 M0 + M2（+M4）；G2 反演 Fn 不算实测 |
| G3 冻结权重零更新回放 | **NOT RUN** | 两条训练线各用自己合同 |
| G4 正式 PPO/部署 | **FORBIDDEN** | 本轮无授权，前置未满足 |

**G1-K 的两种处理**
1. 研究性离线实验：可在明确授权后带声明继续，不因一个不可直接辨识的静态差异长期停摆。
2. 正式 Sim2Real 训练/部署：若缺口可能导致策略学到不可实现的支撑力/下沉/过限接触，则为**阻塞项**；解除需独立测量约束 + 数值稳定候选 + 预注册多姿态验证 + 人工风险接受。

**不采用**"Hip 力矩误差必须 ≤0.3 Nm"作为普适门槛。

## 8. 训练步长建议（本轮结论）

1. **不宣称任何 dt 是静态真值。**
2. 历史回归用 0.005；离线检查用 0.0025；0.010 只作压力/反例。
3. 0.00125 的实测是 **2.198° vs 0.0025 的 4.014°（差 1.82°）**，**未收敛**；按任务书 §6.3 停止更细步长盲试，把"数值未收敛"写进 G1-K，静态验收保持 BLOCKED。
4. **不通过调奖励、`impratio`、摩擦系数来"修复"静态模型。**
5. **"两个观测到的局部稳定终态"只能限定在 dt 0.0025–0.005 窗口**；不得跨 dt 外推，也不得写成物理静态平衡点。
