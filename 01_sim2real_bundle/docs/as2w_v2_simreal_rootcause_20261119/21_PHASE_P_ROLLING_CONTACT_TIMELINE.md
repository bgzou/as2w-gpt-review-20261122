## 1. 结论

1. **两个"终态"都不是静止状态。** 末 60 s：`hip_p002` 轮速 P99 **0.046 rad/s**、`pitch_p2` **0.123 rad/s**；两者都超过预注册的 0.02 rad/s 门槛 → 按任务书判 `UNKNOWN_STATIONARITY`（更准确：`CREEPING` / `ROLLING`）。
2. **180–240 s 的"迁移"是一次滚动 + 短暂失载事件**，不是两个静态平衡之间的跃迁：
   - `pitch_p2` 在 180–240 s 内基座 **+62.4 mm**、轮转 **0.61/0.65/1.00/0.86 rad**、pitch **−1.564°**；
   - 同窗口 RL 轮出现 **47 个 20 Hz 采样点 Fn<5 N**（含 211.95 s、212.3 s 两次完全失载）；
   - 迁移前后 pitch 从 ≈3.0° 降到 ≈1.45°，与"轮子滚过一段距离"同时发生。
3. **`hip_p002` 分支相对安静但不是静止**：末 60 s 基座 xy 只 0.12 mm、pitch 漂移 −0.022°，但轮子仍以 0.046 rad/s 缓慢转动（≈4 mm/s 轮缘）。
4. **累计轮角不能判断末段速度**：`pitch_p2` 全程轮转 2.1–2.5 rad，其中 180–240 s 占 0.6–1.0 rad；末 60 s 只转 0.005 rad。→ 必须用 `wheel_dq` 而不是 `wheel_delta_q`。
5. **接触切换确实存在**：`hip_p002` 在 0.05–3.35 s（FR）、26.8–31.7 s（FL）有启动瞬态失载；`pitch_p2` 在 211.95/212.3 s（RL）失载。**这些都不是"两个静态分支"能解释的。**

## 3. 迁移窗口与接触事件的对应

`pitch_p2` 失载事件（20 Hz 采样，`Fn<5 N`）：

| 时刻 (s) | 轮 | 说明 |
|---|---|---|
| 0.05 | RL, RR | 初始瞬态 |
| 12.05–17.05 | FR | 落稳过程的单点失载 |
| 31.15–36.0 | FL | 落稳过程 |
| **211.95 / 212.3** | **RL** | **迁移窗口内的两次失载** |

`pitch_p2` 在 180–240 s 的基座 x 增量 62.4 mm，与轮转 0.6–1.0 rad 一致（0.086 m × 1 rad ≈ 86 mm 量级），说明这段时间**轮子在地面上滚过**，不是"关节姿态微调"。迁移的 pitch 变化（≈3.0→1.45°）与滚动同步。

`hip_p002` 的失载只发生在启动段（<36 s），之后 320 s 无失载，Fn 稳定在 52/52/75/76 N。

## 4. 对"两个局部稳定终态"的处置

| 旧表述 | 新表述 |
|---|---|
| 两个局部稳定终态（`INFERENCE`） | **两个数值轨迹族**，终态静止性未验证；`pitch_p2` 分支在 180–240 s 发生滚动+失载 |
| 180–240 s 迁移"机理 UNKNOWN" | 已定位为**滚动事件 + RL 短暂失载**；具体触发（切向漂移/求解器）仍 `UNKNOWN` |
| `settle_ok=true` 表示稳定 | 只看末步 `dqmax`；**必须**同时给末 60 s 轮速/基座/pitch/Fn 统计 |

**不能**写的：① "两个物理静态平衡点"；② "pitch 回到 1.44° 就是回到同一平衡点"（轮子还在转）；③ 用累计轮角变化推断末段滚动。

## 5. 限制

- 只有一组 20 Hz 数据、两个初态；没有做 P1-B 的基座/轮自由度消融（时间与预算）。
- `Fn` 是 PhysX `net_forces_w`，不是逐点接触力；`contact_pos` 未记录。
- 没有记录轮地切向相对速度（需要接触点速度），本轮用 `wheel_dq` 与基座速度近似。
- 180–240 s 的 50–100 Hz 事件片段未单独加采；20 Hz 已足以看到失载，但看不到失载的上升/恢复波形。
