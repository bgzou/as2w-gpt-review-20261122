## 1. 测量顺序（更新）

| 顺序 | 项目 | 结论 |
|---|---|---|
| 1 | **M0 整机质量** | 合成不确定度 ≤0.2 kg 时裁决 26.000/27.512；不裁决 CoM/Fn/μ |
| 2 | **M2 四轮同步 Fn** | 物理上最直接的下一步：每轮 95% ≤1 N（达不到报实际值）；Fy 与 Fn 在同一力平衡里互相补偿，没有独立 Fn 就没有唯一分解 |
| 3 | **M4 侧向摩擦/剪切** | 两档 Fn × 两档轮倾 × 正反两向；只测容量，**不定 Fy 符号** |
| 4 | 单轮 Fy 力板 / 髋台架 | 仅在前三步后仍跨零/仍不闭合时 |

- 有四轮同步设备：**M0 → M2 → M4**。
- 没有：**M0 → M4（容量筛查）→ M1/M2**，但不得把 μ 当作 Fy 符号的证据。
- 若现场已有能同步测某轮 `Fz` 与 `Fy` 的双轴/六轴力板，可省掉纯垂向 M2，但**不能跳过 Fn 测量本身**。

## 2. 髋台架（可判别性）

| 目标效应 | 台架要求 | U95≈1 Nm 时 |
|---|---|---|
| 1 Nm | `U95(δτ) ≤ 0.3 Nm`；分辨率 ≤0.05–0.10 Nm | `UNDERPOWERED_FOR_1NM`，不做定量归因 |
| 2 Nm | `U95 ≤ 0.5 Nm`，且 `|δτ|−U95>0`、重复且符号稳定 | 只能排除大偏置 |
| 大偏置初筛 | 事先声明可检出的最小差额 | 不可用"未检出"排除 1 Nm |

- **不得把台架精度直接挂钩 `t*`**：`t*` 是 16 个关节行的 min-max，不是单 Hip 的 signed residual。
- T1：独立 `tau_out`（或可闭合的输出端力矩测量）+ signed 95% 区间不含 0 + 双向可重复。
- T2：O0 + M0/M2 + 真实 μ/受约束 CoP 代入**同关节、同姿态、同载荷**账本后，残差仍超综合不确定度，且台架差值同符号一致。
- 只有拉力计但没有支撑反力/重力/受力路径闭合 → `T1_NOT_IDENTIFIABLE`。
- 单轴拉力计 + 已校准力点/方向 + 固定受力路径 + 外载力矩平衡，**可以**作为输出端外载测量候选，不一概否定。

## 4. G1-K（Phase P 版）

> **G1-K — KNOWN_STATIC_CONTACT_AND_NUMERICAL_GAP：OPEN / MUST DISCLOSE。**
>
> P55G2 共位形（实测 q/IMU）修正版四点假设下，条件 LP 的 `t*(μ=0.25)` 为 **2.1573 Nm（26.0 kg）/ 1.3841 Nm（27.512 kg）**，不是实际关节误差、传动损失或物理下限；跨会话留出验证为 P55G1 2.00/1.22、P55G3 2.02/1.33、**OG 0.54/0.71**（OG 合同不同，仅作留出）。
>
> 四个倾斜刚性圆柱最低点在**水平单平面**下高度相差 **4.266 mm**；允许倾斜的最佳平面倾角 **0.253°**、残差峰峰 **1.94 mm**。地面实际倾角、轮胎垂向柔顺、CoP 与四轮 Fn 未知；三点/两点支撑几何上只有 2/4 子集可能，且 `t*` 跳到 15.7 Nm 以上，**四轮刚性同时接触未独立证实**。
>
> 后轮 Fy 条件区间跨零（两资产、全 μ、合法 CoP），实际方向 **UNKNOWN**；前轮外撑仅对 P55 族 + 指定模型假设成立（**OG 四轮全部跨零**）。`tau_est` 由固件估计，不是独立 `tau_out`。
>
> PhysX 多个长时轨迹记录到轮角变化、基座漂移或离散轮失载（`dt=0.00125` 60 s RR `Fn=0`；`dt=0.010` 360 s 前移 1.35–1.41 m）。**本轮新增 20 Hz 时序**（见 `21_PHASE_P_ROLLING_CONTACT_TIMELINE.md`）用于区分末段是否持续滚动；在完整状态未静止前，只能称"数值轨迹族"，不能称"静态终态"。
>
> MuJoCo W_A 与 PhysX 数值结果只用于候选模型相对比较，不作实机绝对验收。研究性离线实验可在明确授权且隔离下继续；正式训练/上线/权重替换仍受 G2/G3/G4 阻塞。
>
> **审计勘误，仅供追溯**：Phase N 旧实现 `t*(μ=0.25)` = 1.9846/1.1231 Nm（`DEPRECATED_IMPL`，接触点缺端面项、摩擦锥外切、Hip 分解混加四轮）。**不得**把新旧值合并成"测量区间"，也不得再引用 7.2/3.1 Nm 为同位形传动缺口。
