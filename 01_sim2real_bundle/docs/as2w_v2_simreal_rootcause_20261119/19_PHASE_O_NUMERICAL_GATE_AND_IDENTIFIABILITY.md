## 1. O3：受限 CoP（S1）小规模探测

**做法**：接触点沿轮轴在地面的投影方向移动 `s ∈ [−0.026, +0.026] m`（仍在 52 mm 胎面内、z=0），分别做"四轮同移"与"仅后轮移"，μ=0.25/0.50，两套资产。**这是几何受限的 CoP 探测，不是自由接触模型。**

| 资产 | 工况 | `t*`（μ=0.25） | 后轮 Fy 跨零 |
|---|---|---|---|
| 26 kg | 同移 −26 mm | 2.876 | 是/是 |
| 26 kg | 同移 0 | 2.155 | 是/是 |
| 26 kg | 同移 +13 mm | 2.263 | 否/是 |
| 26 kg | 同移 +26 mm | 2.738 | 否/是 |
| 27.5 kg | 同移 0 | 1.377 | 是/是 |
| 27.5 kg | 同移 ±26 mm | 2.10–2.17 | 是/是 |

**结论**：
1. CoP 在几何允许范围内移动可以把 `t*` 从 2.15 变到 2.88 Nm（±0.7），**说明"1–2 Nm 结构下限"不是硬下限，而是强依赖接触点假设的代数值**。
2. 但**没有一个几何允许的 CoP 让两个后轮的 Fy 区间同时不跨零** → 后轮方向仍 `UNKNOWN`。
3. 因此**不升级 S2（接触力偶）**：按任务书 §7 的停止条件，S1 没有给出"明确、可解释、可重复"的改善。

## 2. O4：已有 PhysX 长时轨迹的滚动/失载/漂移审核

从各 run 的 60 s checkpoint 统计（`root_pose_w`、四轮 `Fn`、轮铰 `joint_q`）：

| run | dt | 基座 x 漂移 | 轮角变化（FL/FR/RL/RR, rad） | 失载事件 |
|---|---|---|---|---|
| `b0_dt00125_hip` | 0.00125 | +0.013 m | +0.16 / −0.06 / +0.10 / −0.51 | **60 s 时 RR `Fn=0.0 N`**（FR 104 N） |
| `b1_dt0025_hip` | 0.0025 | +0.0007 m | +0.01 / +0.05 / +0.07 / +0.08 | 无 |
| `b1_dt0025_pitch` | 0.0025 | +0.005 m | +0.78 / +0.04 / +0.43 / +0.70 | 无 |
| `b3_dt0025_hip` | 0.0025 | −0.0007 m | −0.00 / +0.03 / +0.06 / +0.06 | 无 |
| `b3_dt0025_pitch` | 0.0025 | +0.005 m | +0.78 / +0.04 / +0.43 / +0.81 | 无 |
| `b3_dt005_hip` | 0.005 | +0.011 m | +0.13 / +0.12 / +0.13 / +0.09 | 无 |
| `b3_dt005_pitch` | 0.005 | **+0.148 m** | +1.58 / +1.63 / +2.22 / +1.87 | 无 |
| `b2_dt01_hip` | 0.010 | **+1.345 m** | +3.39 / +3.44 / +3.42 / +3.58 | 无 |
| `b2_dt01_pitch` | 0.010 | **+1.412 m** | +4.26 / +4.33 / +4.33 / **−8.08** | 无 |

**读数**：
1. **dt 0.010 不是"静止"**：360 s 内基座前移 1.35–1.41 m、轮转 3.4–4.3 rad（>半圈）。这是**滚动**，不是数值噪声。该 dt 的"两个分支"只是滚得快慢不同 → 明确 `NONCONVERGED_DO_NOT_ACCEPT`。
2. **dt 0.005 的 `pitch_p2` 也在滚**：0.148 m、轮角 1.6–2.2 rad。所谓"1.44° 终态"不是静平衡。
3. **dt 0.0025 的 `pitch_p2` 轮子仍转 0.78 rad**，但基座只移动 5 mm；`hip` 分支接近静止（轮角 <0.1 rad、x <1 mm）。
4. **`dt=0.00125` 的 60 s `RR Fn=0`**：一次真实的**接触状态切换**（三轮支撑），随后恢复四轮。说明这条轨迹至少发生过一次失载—再加载。
5. **`settle_ok` 并不能排除滚动**：它只看末步 `dqmax<0.2`，而轮子慢速滚动时腿关节 dq 可以很小。

**能下的结论**：PhysX 的"长期终态"至少包含**缓慢滚动/接触切换**，不是严格静态；跨 dt 的 pitch 差异有一部分来自滚动状态不同。
**必须保持 UNKNOWN**：180–240 s 迁移的瞬时机理（60 s checkpoint 无法定位）；失载事件的触发条件；滚动是否由接触求解器的切向漂移驱动。

## 4. G1-K（Known Static Contact Gap）最新写法

状态：**OPEN / MUST DISCLOSE**。每份训练/回放/评审材料固定列出：

1. 实机 P55G2 `q`、IMU、`tau_est`（注明不是 `tau_out`）；
2. 对照模型是**同位形账本**还是 W_A 闭环落点；**不得**再引用 7.2/3.1 Nm 为同位形残差；
3. Phase N **旧实现** `t* ≈ 1.123–1.985 Nm` 与 Phase O 修正后 `t* = 1.384–2.157 Nm`（并注明是"4 点刚性 + 误差带的代数最优值"，不是物理下限）；
4. 四轮 Fn、Fy 条件区间与真实 μ/CoP/`tau_out` 的 UNKNOWN；**后轮 Fy 跨零**；
5. PhysX 跨 dt 未收敛、轮速/基座漂移、`dt=0.00125` 的 RR 失载；
6. W_A/C0 是候选相对对照，不是现实物理验收环境；
7. 研究性 RL 结果不得用于宣称正式 Sim2Real 通过或替换实机权重。

**Gate 处置**：G0 PASS（不代表力矩真值）· G1 PARTIAL · G1-K OPEN · G2 BLOCKED · G3 NOT RUN · **G4 FORBIDDEN**。

**权限三分**：
- 研究性实验：需用户**另行明确授权**，独立分支、单独风险标注、与正式主线隔离。
- 正式重训：G1-K 未闭合 + G2 未满足 → 禁止。
- 部署：G3/G4 未过 → 禁止。

**两条策略不受本轮静态诊断影响**：v2-step 的"右移死结/门禁/无轮差速/训练摩擦"与 HIMLoco 的"kp 余量/训练载荷口径"仍是各自训练侧问题，不能被"静态账本已解释"或"未解释"任一方替代。
