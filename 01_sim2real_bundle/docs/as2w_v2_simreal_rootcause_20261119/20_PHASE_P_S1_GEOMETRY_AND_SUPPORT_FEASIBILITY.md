## 0. 结论

1. **旧 S1 确实越界**：`p_new` 已经在轴向 `t=±26 mm` 的轮缘，旧扫描 `p_new + s·a_h`（s=±26 mm）让每轮 **5 个点里有 2 个** 超出 `|t|≤w`。→ 旧 O3 的"±0.7 Nm CoP 敏感度"**部分来自非法点，降级为 `SENSITIVITY_ONLY_INVALID_AS_PHYSICAL_COP`**。
2. **合法向内扫描**（d=0/5/10/20 mm，逐轮按 `sign(a_z)` 定义向内）：`t*` 从 **2.155→2.015**（26 kg）/ **1.377→1.172**（27.5 kg），即最多降 **0.19 Nm**；代价是 **4.2–8.6 mm 的垂向变形**。**后轮 Fy 在所有合法点仍跨零** → 后轮方向仍 `UNKNOWN`，S2 继续 CLOSED。
3. **四点最佳拟合平面倾角 0.253°**，残差 `[-0.975,+0.965,+0.936,-0.926] mm`、峰峰 **1.94 mm**（与 GPT 手算一致）。4.266 mm 只证明"水平单平面下不共面"；允许倾斜后仍差 1.94 mm。
4. **3 轮支撑几何上只有 2/4 子集可能**，且 `t*` 跳到 **15.7–15.8 Nm**（比四点大 7 倍）→ 三轮支撑在静态账本里不可行；2 轮支撑全部不可行（t*=200 上限）。
5. **最简垂向柔顺**：只有很软（k≈2×10⁴ N/m，穿透 3–5 mm）才能四轮同时承载，但 Fn 分成 **103/18/73/61 N**（与 G2 的 48/48/79/79 差很远）；k≥5×10⁴ 时出现轮子卸载，k≥10⁵ 时单轮承重 → **真实轮胎刚度/姿态必须实测（M2）**。
6. **P2 全部通过**：接触点 Jacobian 有限差分 **0.0**；40 组随机可行力的 Hip 轴叉乘 vs Jacobian **0.0**；LP 解基座残差 0 N/0 Nm、`min Fn=49.2 N`、锥违反 0。PhysX 逐点接触守恒 **UNKNOWN**（归档 JSON `record_contacts=False`）。

## 1. P0-A：S1 几何边界

### 1.1 旧 O3 的越界点

| 轮 | `t(p_new)` mm | 旧扫描 s=−26 | s=−13 | s=0 | s=+13 | s=+26 |
|---|---|---|---|---|---|---|
| FL | **+26.0** | 0.6 ✓ | 13.3 ✓ | 26.0 ✓ | **38.7 ✗** | **51.4 ✗** |
| FR | **−26.0** | **−51.4 ✗** | **−38.7 ✗** | −26.0 ✓ | −13.3 ✓ | −0.6 ✓ |
| RL | +26.0 | 1.0 ✓ | 13.5 ✓ | 26.0 ✓ | **38.5 ✗** | **51.0 ✗** |
| RR | −26.0 | **−51.0 ✗** | **−38.5 ✗** | −26.0 ✓ | −13.5 ✓ | −1.0 ✓ |

（`w = 26 mm`；✗ = `|t| > w`。每轮 5 点中 2 点越界，合计 **8/20**。）

### 1.2 s=0 回归

`s=0` 用 O0 的 `p_new`（含 z），`t*` = **2.1573 / 1.3841 Nm**，与 O0 完全一致（容差 0.01）→ `s0_matches_o0 = true`。

### 1.3 合法向内扫描

点沿轴向向内移动 `d`，放回 `z=0`（引入的垂向变形 = `d·|a_z|`）：

| d (mm) | 变形 FL/FR/RL/RR (mm) | `t*` 26 kg | `t*` 27.5 kg | 后轮跨零（两资产） |
|---|---|---|---|---|
| 0 | 0 / 4.27 / 1.54 / 2.10 | 2.155 | 1.377 | 是 |
| 5 | 1.05 / 5.34 / 2.89 / 3.46 | 2.119 | 1.288 | 是 |
| 10 | 2.09 / 6.41 / 4.25 / 4.82 | 2.084 | 1.242 | 是 |
| 20 | 4.19 / 8.56 / 6.95 / 7.55 | 2.015 | 1.172 | 是 |

**判读**：
- 合法的向内 CoP **只能把 `t*` 降 0.14–0.21 Nm**，远小于旧 O3 报的 ±0.7 Nm（那部分来自越界点）。
- d=20 mm 需要 4.2–8.6 mm 垂向压缩，**大于观测到的 4.27 mm 不共面量**，没有实测刚度支持，不能当物理解。
- **后轮 Fy 跨零在全部合法点都不变** → `REAR_FY_SIGN_UNKNOWN`，S1 到此停止，S2 不启动。

## 2. P0-B：平面、支撑集合与柔顺

### 2.1 平面拟合

`z = a x + b y + c`，四点最小二乘：

| 量 | 值 |
|---|---|
| a / b | +0.000876 / −0.004325 |
| 倾角 | **0.253°** |
| c | 0.001919 m |
| 残差 (mm) | −0.975 / +0.965 / +0.936 / −0.926 |
| 峰峰值 | **1.94 mm** |

**严格水平平面**：峰峰 4.266 mm。**允许倾斜**：仍剩 1.94 mm。
**这不是实测地面坡度**，只是"四点能否被一个平面解释"的几何检查。

### 2.2 3 轮 / 2 轮支撑

| 支撑子集 | 被抬起轮 | 该轮离面距 (mm) | 几何可行 | `t*` (μ=0.25) |
|---|---|---|---|---|
| FL,FR,RL | RR | −3.904 | ✗（该轮在地面下） | — |
| FL,FR,RR | RL | +3.864 | ✓ | **200（LP 不可行）** |
| FL,RL,RR | FR | +3.745 | ✓ | **15.74** |
| FR,RL,RR | FL | −3.708 | ✗ | — |
| 任意 2 轮 | — | — | — | 全部 200（不可行） |

→ 只有两个 3 轮子集几何可能，一个连基座平衡都不可行，另一个需要 **15.7 Nm** 的关节修正（四点只要 2.16）→ **三轮支撑不是可行静态解**。

### 2.3 最简垂向柔顺 `Fn = k·max(0, penetration)`

`c` 由 `ΣFn = W` 解出；`tilt=0`：

| k (N/m) | Fn FL/FR/RL/RR | 穿透 (mm) | 四轮都载？ |
|---|---|---|---|
| 2×10⁴ | 103.3 / 18.0 / 72.5 / 61.3 | 5.16 / 0.90 / 3.63 / 3.07 | **是** |
| 5×10⁴ | 145.6 / **0** / 68.7 / 40.8 | 2.91 / −1.35 / 1.37 / 0.82 | 否（FR 悬空） |
| 1×10⁵ | 204.5 / 0 / 50.6 / 0 | 2.04 / −2.22 / 0.51 / −0.05 | 否（两轮悬空） |
| 2×10⁵ | 255.1 / 0 / 0 / 0 | 1.28 / −2.99 / −0.26 / −0.82 | 否（单轮） |

- 要让四轮同时承载，需要 **k≈2×10⁴ N/m（很软的胎）**，且 Fn 分配 **103/18/73/61**，与 G2 反演 48/48/79/79 和 LP 的 49/51/79/77 都不一致。
- k≥5×10⁴ N/m 时前右轮卸载 → 说明"四轮刚性同时接触"本身就可能不成立。
- **没有实测刚度时不得拟合单值 k**；上表只作"哪种条件模型能支持四轮承载"的可行性说明。
