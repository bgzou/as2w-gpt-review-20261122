## 1. O0-A：倾斜有限宽圆柱的最低点

### 1.1 旧代码错在哪

`n0_2_force_ledger.py` 的 `wheel_lowest_point()`：

```python
perp = down - (down·axis)axis         # 只取径向
p = c + r * perp/|perp|               # 缺端面项
```

对有限宽圆柱，最低点在**下端面圆周**上：

```
p = c − w·sgn(a_z)·a + r·(a·a_z − ẑ)/√(1−a_z²)
z_min = c_z − w|a_z| − r√(1−a_z²)
```

### 1.2 修正后的几何（实机 P55G2 位形）

| 轮 | 倾角° | 旧点 (x,y,z) | 新点 (x,y,z) | Δz mm | Δy mm |
|---|---|---|---|---|---|
| FL | 12.08 | (0.26124, 0.29673, 0.00544) | (0.26224, 0.27132, 0.0) | **−5.44** | **−25.40** |
| FR | 12.39 | (0.27477, −0.28921, 0.00985) | (0.27496, −0.26382, 0.00427) | **−5.58** | **+25.39** |
| RL | 15.71 | (−0.13822, 0.30152, 0.00858) | (−0.13706, 0.27652, 0.00154) | **−7.04** | **−25.00** |
| RR | 15.81 | (−0.12829, −0.30636, 0.00918) | (−0.12794, −0.28134, 0.00210) | **−7.08** | **+25.01** |

- 端面项在 z 方向 5.4–7.1 mm，与任务书估算（5.5/7.0 mm）一致；同时把接触点**横向内移 25 mm**（从轮缘回到胎面内），这直接改变 `r_y` 与 Hip 力矩。
- 旧报告里"前 4.8°/后 12.1°"是 **W_A 落点**的体轴倾角；实机位形的**几何轴**倾角是 12.08/12.39/15.71/15.81°，与 G2 解析值一致。两组不可混写。
- 修正后四轮最低点 z 跨度 **4.266 mm**：刚性平面四点**不能同时接触**。所以四点 LP 只能标为**假设性接触力账本**；真实实现要么有轮胎变形（≈4 mm），要么只有接触子集。本轮结果标 `INFEASIBLE_GIVEN_RIGID_PLANE`。

## 2. O0-B：摩擦锥

### 2.1 旧实现的真实性质

`cone_rows()` 用的是 `n_k·(Fx,Fy) ≤ μFn`（8 个法向），即**外切**八边形：允许 `|F_t|` 到 `μFn/cos(22.5°) = 1.0824 μFn`。例：`Fx=μFn, Fy=(√2−1)μFn` 满足全部 8 条但 `|F_t|=1.0824μFn`。**不能称为"保守内接"**。

### 2.2 修正与结果

- 内切 32 边形：`n_k·(Fx,Fy) ≤ μFn·cos(π/32)`（cos = 0.99518）；外切 32 边形作上界。
- 对最优解逐轮计算真实违反量 `v_i = max(0, |F_t| − μF_z)`。

| μ | `t*` 内切 | `t*` 外切 | 最大锥违反 |
|---|---|---|---|
| 0.20 | 2.4559 | 2.4467 | 0 |
| 0.25 | 2.1573 | 2.1573 | 0 |
| 0.50 | 1.3122 | 1.3122 | 0 |
| 0.80 | 1.3122 | 1.3122 | 0 |

**结论**：八边形近似确实是"非保守"，但在本问题的**最优点上摩擦锥并不活跃**（违反量 0，切向力远低于上限），所以修正后 `t*` 只在 μ=0.2 变化 0.009 Nm。**不是"数值没变所以没错"，而是"错在表述与边界，最优点恰好不受影响"**。真正受影响的是 Fy 上下界（在锥边界上取极值），下表用内切 32 边形给出。

## 3. O0-C：单 Hip 广义力分解

### 3.1 旧实现错在哪

`hip_moment_decomposition` 把**四个轮**相对该 Hip body 原点的 `r×F` 全部相加。一个 Hip 的广义力只由**该腿子树内**的接触力决定；其他腿的轮端力通过基座平衡影响解，但不是这个 Hip 的直接关节力矩。

### 3.2 修正与验证

```
τ_hip = a_hip · [(p − o_hip) × F]     # 仅该腿的轮；o_hip 用关节锚点，a_hip 用世界系关节轴
```

与 `A[hip_dof,:] @ f` 对拍（μ=0.25，delivery）：

| Hip | τ（轴叉乘） | τ（Jacobian） | 差 | `r_yF_z` | `−r_zF_y` |
|---|---|---|---|---|---|
| FL | 13.6772 | 13.6772 | **0.0** | 10.189 | 3.394 |
| FR | −14.1017 | −14.1017 | **0.0** | −10.445 | −3.547 |
| RL | 17.5683 | 17.5683 | **0.0** | 17.249 | 0.640 |
| RR | −17.2340 | −17.2340 | **0.0** | −16.831 | −0.471 |

**结论**：分解方法现在与 Jacobian 逐位一致；`r_yF_z` 仍是主项（占 75–96%），但这是**单 Hip、仅自身轮**的量，不能再说"四轮叠加"。
