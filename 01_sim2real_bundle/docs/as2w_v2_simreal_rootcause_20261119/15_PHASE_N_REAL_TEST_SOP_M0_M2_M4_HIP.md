## 0. 顺序与能排除什么

| 序 | 实验 | 能裁决 | 不能裁决 | 前置 |
|---|---|---|---|---|
| 1 | **M0 整机称重** | 26.000 kg 还是 27.512 kg 资产更接近实机 | CoM、四轮 Fn、μ、传动 | 平台秤 |
| 2 | **M4 单轮侧向摩擦/剪切** | 指定轮载/轮倾/地面下的 `μ_front` 落在哪个区间（<0.365 / 0.365–0.44 / ≥0.44） | 四轮同时承载的 Fy 分配；传动 | 单轮工装 |
| 3 | **M2 四轮同步垂向载荷**（或 M1 轴载） | 真实 Fn 分配、G2 反演是否成立、`μ·Fn` 的上限 | 无侧向信息时的 Fy；单轮 CoM | 四通道秤/两平台 |
| 4 | **髋带载台架**（条件触发） | 该 Hip 在所测负载下 `tau_est` 与轴端输出的带载差 | 是否就是 P55 缺口；是否减速器摩擦 | M4+M2 后仍不闭合 |

**规则**：M4 单独测得 μ **不能**把 3.1 Nm 判给传动（任务书 §0.4）。若 M4 显示 `μ_front ≥ 0.44` 且 M2 的 Fn 与 G2 接近，则**不启动**髋台架作为主线。

## 1. M0：整机质量

**目的**：在 26.000 / 27.512 kg 两套资产间裁决。

**设备**：校准过的平台秤（量程 ≥60 kg，分辨 ≤0.05 kg）或等效整机称重设施；整机可安全承托的刚性托盘；不稳固的家用体重秤不得承托机身。

**步骤**
1. 记录秤型号、量程、分辨、最近一次校准日期；空载置零并记录偏置漂移 3 次。
2. 明确附件清单与状态：电池（型号/电量）、CPRO、相机、线缆、工装、加装件；记录哪些随机、哪些拆下。
3. 整机静止放置，四轮完全落在承托面，无其他支撑分担；读数稳定 ≥10 s。
4. 重复就位 3 次，每次重新抬起—放下；记录每次读数。
5. 若可行，再用第二台秤或第二位置复核一次。

**记录模板**

| 字段 | 值 |
|---|---|
| 日期/地点/操作人 | |
| 秤型号 / 量程 / 分辨 / 校准日期 | |
| 空载偏置（3 次） | |
| 附件清单与状态 | |
| 读数 1/2/3（kg） | |
| 均值 / 极差 / 合成不确定度 | |
| 与 26.000 / 27.512 的差 | |

**判据**：合成不确定度 ≤0.2 kg 时可区分两套资产（差 1.512 kg）；若附件变化 > 模型差，不做选择，记 `UNKNOWN`。
**回退**：支撑分担重量、读数漂移、秤未校准 → 记 `UNKNOWN`，**不得**用模型值替代。

## 2. M4：前轮轮胎—地面横向静摩擦/剪切

**目的**：给出**条件** `μ_s,lateral = F_y,breakaway / Fn_meas`，判定简化摩擦容量落在哪个区间。

**工装（需机械测试资质人员设计与审核）**
- 单轮（含轮毂/胎）固定夹具，能保持与实机一致的轮倾；
- 可控法向加载（配重或加载缸），法向力可读；
- 水平地面试样（与实机测试地面同材质、同清洁度）；
- 校准拉力计/单轴力传感器（分辨 ≤1 N），作用线经过轮心高度附近；
- 位移观测（拉线/激光），用于识别"先滚动"与"纯横向滑移"；
- 防倾覆、防夹具滑移、防人员进入拉伸方向的措施。

**工况**
- 法向载荷至少两档：~48 N 与 ~79 N（G2 反演参考值，**仅作设计载荷**）。
- 轮倾至少两档：(a) W_A 落点前轮 ~4.8°；(b) P55G2 实机 FK 前轮 ~12.1°；必要时补官方 OG。
- 方向：轮轴方向**拉与推分别测**。
- 每个组合重复 ≥3 次，含加载—卸载滞回。

**步骤**
1. 空载（法向=0）测一次横向阻力基线（轴承/夹具）。
2. 加载到目标 Fn，静置，记录轮心高度与轮倾。
3. 以位移控制缓慢增加横向力（≤1 mm/s 量级），记录 `F_y(t)`、`y(t)`。
4. 记录击穿点（连续滑移开始）、最大静摩擦、滑移后动摩擦。
5. 卸载、重新就位、重复。
6. 检查是否出现"轮先滚动"（轮速非零）——出现则该次作废。

**记录模板**

| 字段 | 值 |
|---|---|
| 轮位 / 胎面材质 / 温度 / 清洁度 | |
| Fn_meas（N，含不确定度） | |
| 轮倾（°，实测） | |
| 方向（拉/推） | |
| F_y,breakaway（N） / 位移（mm） | |
| 是否先滚动 / 夹具滑移 | |
| 重复 1/2/3 与均值、95% 区间 | |
| μ = F_y/Fn 及不确定度 | |

**判据**：击穿力可重复（极差 ≤10%），且能与"滚动先发生"清楚分开；与 `Fn`、力传感器分辨、夹具阻力相比有显著裕度。
**回退**：轮先滚动、夹具滑移、外力未过标定作用线 → 记为"总阻力试验"，**不能**用于摩擦锥判定。

## 3. M1/M2：轴载与四轮独立 Fn

**设备**：四通道同步载荷平台（首选），或两平台测前后轴（M1）。单秤分时测四轮**只能粗筛**。

**步骤**
1. 保持现有控制合同（不改 Kp/Kd），机器人以 P55 T2 姿态静止站在平台上。
2. 记录 12 关节 `q`、IMU 姿态、轮倾、轮下表面高度、是否有额外支撑。
3. 四通道同时采样 ≥10 s；重复就位 3 次。
4. 官方 OG 作为留出验证姿态（不参与拟合）。

**判据**：四轮之和与 M0 总重在合成不确定度内一致；重复就位后单轮分配稳定（极差 ≤5% 总重）。
**回退**：轮压平台边缘、台面不共面、垫块改变支撑 → 不能作独立 Fn 证据。

## 4. 髋关节带载外力—输出力矩台架（条件触发）

**触发条件**：M4 + M2 后共位形静力账本仍不闭合（残差 > 2–3 Nm 且无法由接触解释）。

**工装（不由本阶段搭建）**
- 基座可靠夹持的额定承载工装，测试腿完全离地，外力不经其他腿传递；
- 已知力点 + 标定力传感器（矢量或单轴 + 方向约束）；
- 3D FK 给出力点相对髋轴的世界向量 `r`；
- 记录 `tau_est`、命令 Kp/Kd、`q`、`dq`、温度、夹具应变；
- 防跌落支架、力矩/力上限、急停。

**步骤**
1. 无外力，记录重力基线（同姿态、同温度）。
2. 逐级加载（例如 5/10/20 N），双向、加载—卸载，每级静置 ≥3 s。
3. 每级记录 `τ_est`、`q`、外力矢量与作用点。
4. 计算 `τ_ext,hip = axis · (r × F + M_ext)`，与 `τ_est − τ_gravity(q)` 比较。
5. 同一姿态重复 ≥3 次；换 2 个姿态。

**计算口径**
- `δτ_drive = τ_est − τ_out`（带符号）；`Δτ_out(F) = τ_out(F) − τ_out(0)`。
- 报告 95% 区间；不确定度接近 3 Nm 时只能定性。

**判据（三级）**
- T0：仅条件残差（当前状态）；
- T1：`δτ_drive` 区间显著不含 0，且方向/负载可重复 → "该 Hip 在台架条件下存在估计—输出差"；
- T2：M0/M2/M4 约束后账本仍需非零 `δτ`，且与台架同姿态/负载的 `δτ_drive` 带符号一致 → 可把**有区间的一部分**归因。

**禁止**：把台架读到的 ~3 Nm 直接叫"减速器摩擦"；不做无载扫角；不用高 Kp 顶机械限位。

## 5. 不确定度预算（示例，需按实际仪器替换）

| 来源 | M0 | M4 | M2 | 髋台架 |
|---|---|---|---|---|
| 传感器分辨/线性 | 0.05 kg | 1 N | 1 N/轮 | 0.5 N |
| 标定/偏置 | 0.1 kg | 2% FS | 2% FS | 1% FS |
| 几何（力臂/作用点） | — | 2 mm | 台面共面 1 mm | 2 mm |
| 重复性 | 0.05 kg | 5% | 3% | 5% |
| 合成（目标） | ≤0.2 kg | ≤10% μ | ≤2% 总重 | ≤1.5 Nm |

**只有当合成不确定度足以区分 0 与候选的 1–3 Nm 级偏差时，台架才能做数值归因**；否则只写方向。

## 6. 数据交付格式

每次测量输出一个 JSON/CSV：`id, date, operator, instrument, calibration, geometry, raw series, reduced values, uncertainty, verdict(PASS/FAIL/UNKNOWN), notes`。
原始数据与照片（压痕、轮倾、工装）一并归档；**不得**用仿真值替代实测列。
