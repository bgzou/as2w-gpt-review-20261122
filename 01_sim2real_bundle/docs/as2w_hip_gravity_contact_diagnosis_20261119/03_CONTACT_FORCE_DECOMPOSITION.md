- 日期：2026-11-19
- 脚本：`runs/as2w_hip_gravity_contact_diagnosis_20261119/scripts/h3_contact_decomp.py`（+ h2 静态解器复用）
- 输出：`CONTACTS_BY_WHEEL.csv`、`CONTACT_GENERALIZED_TORQUE.csv`、`CONTACT_SENSITIVITY_MATRIX.csv`
- 方法：固定关节姿态，`mj_jac` 取轮底接触点雅可比，与 H2 相同的最小范数静态解；反事实计算用同一雅可比做 `J^T λ` 投影（`SIM_RUN_CONFIRMED`，基座平衡残差 ≤1e-14）。**不跑动力学沉降**（H2 已证软接触+刚性轮的沉降弹跳不构成静态证据）。**这些反事实只说明力学敏感度，不证明该力在实机存在**（任务书 §H3.3 纪律）。

## 1. H3.1 nominal 接触审计（C0，`RAW_DATA_CONFIRMED` 自 MJCF 运行时）

- 碰撞体：MJCF 原生 cylinder r=0.086 m、半宽 0.026 m、轴线 Y、geom 位于 foot body 原点（无偏移）；地面 plane 5×5 m；摩擦 1.0/0.05/0.001（滑/扭/滚）、condim=4、solimp 0.9/0.95/0.001、solref 0.02/1。
- MuJoCo 实际碰撞采样发现圆柱-平面接触点可落在**圆柱端边缘**（y=±0.026 处）而非底面中线——接触点横向位置有 ±26 mm 的离散度（对 hip 力矩路径有影响，见 C2）。
- 静态解接触力（cmd 位姿水平）：Fn 61-66 N/轮、|Ft|≤10 N、锥内；实测位姿 pitch −4.5°：**后轮 77.5-78.1 N > 前轮 49.7 N**（模型自身产生后重分布）。详 `CONTACTS_BY_WHEEL.csv`。

## 2. H3.3 接触广义力矩投影（`SIM_RUN_CONFIRMED`，`CONTACT_GENERALIZED_TORQUE.csv`）

cmd 位姿（水平、4 轮 62-66 N）下每条腿自身接触力的关节分量（FL 为例）：

| 关节 | τ_contact 总 | 法向(Fz)贡献 | 切向(Fx,Fy)贡献 |
|---|---:|---:|---:|
| FL_hip | −3.14 | **−6.95** | **+3.81** |
| FL_thigh | −0.21 | 0.00 | −0.21 |
| FL_calf | +9.90 | **+10.02** | −0.13 |

要点：
1. **calf 力矩几乎全部来自法向力**（+9.9 vs 法向 +10.0）；
2. **hip 上法向与切向贡献方向相反**（法向 −6.95、切向 +3.81，净 −3.14）——hip 是唯一被切向力显著"回填"的关节；
3. thigh 对接触力几乎不敏感（几何近共线）。

### 2.1 关键负空间发现：纯侧向轮力只投影到 hip（`MODEL_CALCULATION`）

对每个轮接触点单独施加 Fy=+25 N（纯侧向）：

| 工况 | Δτ_hip | Δτ_thigh | Δτ_calf |
|---|---:|---:|---:|
| cmd 位姿水平（任一轮） | **−9.54** | **0.000** | **0.000** |
| 实测位姿 pitch −4.5（各轮 −8.6~−9.4） | −8.6~−9.4 | ≤0.32 | ≤1.1 |

**水平位姿下数学上严格为零**：thigh/calf 轴（Y）对 Fy 力的力臂为零，hip 轴（X）力臂 ≈ z_h≈0.34-0.375 m/N。

### 2.2 反事实：多大侧向力能精确复现实机 hip 力矩（`MODEL_CALCULATION`）

在实测位姿（pitch −4.5 共面）逐轮解 `Fy`，使 J^T λ + 重力项 = 实机 st_tau：

| 轮 | 需要的接触贡献 | J_y (Nm/N) | **所需 Fy** |
|---|---:|---:|---:|
| FL | +8.43 | 0.375 | **−22.5 N** |
| FR | −8.45 | 0.375 | **+22.5 N** |
| RL | +10.98 | 0.343 | **−32.0 N** |
| RR | −11.05 | 0.343 | **+32.2 N** |

模式：**左右镜像、指向机体中线对称的内夹（pinch）模式**，幅值 22-32 N（≈Fn 的 35-45%），ΣFy=0、力矩自平衡——恰是基座方程零空间内力，**不改变基座平衡，只出现在 hip轴上**。后轮夹持力（32 N）大于前轮（22.5 N），与后轴载荷更重一致。

**结论（七问 4 的核心答案）**：
- 法向支撑对 hip 的最小范数贡献 ≈0-1.7 Nm（左右相消）；对 calf ≈7-11 Nm；对 thigh ≈0.5-4 Nm。
- 侧向接触内力是**唯一能同时解释"hip 有 10-13 Nm 而 thigh/calf 已被法向支撑解释"这一残差结构的接触侧机制**；
- **但注意不可辨识性**：hip 传动侧的未建模偏置（减速器摩擦、零位、预紧、缆线）同样产生纯 hip 轴力矩，与侧向夹持在关节力矩数据上**不可区分**。区分需要独立测量（06 最小补测）。

### 2.3 反事实：前轮卸载解释后小腿（`MODEL_CALCULATION`）

固定实测位姿（pitch −4.5），改变前后 Fn 分配：

| 前 Fn / 后 Fn (N) | τ_FL_calf | τ_RL_calf | 实机 |
|---|---:|---:|---|
| 62 / 66（对称） | +8.68 | +9.91 | FL +6.97 / RL +16.59 |
| 40 / 88 | +4.66 | +14.25 | |
| **30 / 98** | +2.83 | **+16.22** | RL 吻合（16.59） |
| 15 / 113 | +0.09 | +19.18 | |

实机 (前 calf 6.97, 后 calf 16.59) 落在**前 Fn 30-55 N、后 Fn 90-100 N**（后:前 ≈1.6-1.9×）区间——与 −6.13° 俯仰下前轮部分卸载一致（轮胎柔顺或地面共形）。加上该 Fn 分配，后 calf 的 H2 缺口（−5 Nm）**消除**。

**闭环自洽性检查**：后 calf 实测误差 0.302 rad × kp55 = 16.6 Nm = 上表 Fn 分配下的静态需求 16.2 Nm——**实机后小腿的 0.30 rad 误差、16.6 Nm 力矩与"后重前轻支撑分布 + PD 55/2"自洽**。`RAW_DATA_CONFIRMED` × `MODEL_CALCULATION`

## 3. H3.2 单因素敏感性 C1-C5（`CONTACT_SENSITIVITY_MATRIX.csv`）

| 变体 | 单一改动 | 静态解效应 |
|---|---|---|
| C0 | nominal 圆柱、μ=1.0 | hip 0.6-1.7 / thigh 0.7-4.0 / calf 7.4-11.3 Nm（组均值） |
| C1 | MuJoCo 侧已是已核对圆柱代理（r=0.086/半宽 0.026）；STL/凸包差异在 PhysX 侧，见 05 | n/a（MuJoCo 侧 C1≈C0） |
| C2 | 接触点横移 ±26 mm（圆柱端边缘） | hip 组均值 0.59-1.67 vs 基线 0.61-1.16：**小**（≤0.5 Nm） |
| C3 | 摩擦 0.8-1.2 | 静力学**不敏感**：nominal \|Ft\|≈10 N ≪ μFn≈50-65 N，锥远未激活。摩擦只影响闭环动力学（H4 层次 B） |
| C4 | 轮胎侧向柔顺 → 以零空间侧向内力刻画（§2.2） | 每轮 22-32 N 即完整复现实机四髋力矩 |
| C5 | 前轮支撑面升高 2/5/10/14 mm | 静态解几乎不变（FnF 99.4→99.8 N）；**关键不是支撑面高度而是 Fn 分配本身**（§2.3） |

**C2/C3/C5 的教训**：在"固定关节角的最小范数静力学"框架里，接触几何微调与摩擦范围都不是解释 hip 缺口的杠杆；杠杆只有两个——**Fn 前后分配**（解释后 calf）与**侧向内力/传动偏置**（解释 hip）。这直接缩小了 H4 的假设空间。

## 4. 运行时生效性确认（任务书 H3.2 要求）

C2/C3 反事实通过改变 `mj_jac` 接触点/锥校验实现，不依赖材质改写；C3 结论"静态不敏感"由解本身（\|Ft\|/μFn 比值）证明，非配置断言。C4/C5 为雅可比级反事实，**未声称实机存在该力**。

## 5. H3 结论

1. 法向支撑：hip ≈0（左右相消）、calf 7-11、thigh 0.5-4 Nm（最小范数）。
2. **侧向接触内力（pinch，22-32 N/轮）是唯一与残差结构相容的接触侧 hip 机制**，且对已解释的 thigh/calf 零扰动；传动侧偏置与它在力矩数据上不可区分。`SUPPORTED`（结构相容性） / `UNKNOWN`（归因唯一性）
3. 后重 Fn 分配（后:前≈1.6-1.9×）下后 calf 静态需求 16.2 Nm ≈ 实机 16.6，**后小腿 0.30 rad 误差自洽解释**。`SUPPORTED`
4. 前轮在 −6.13° 俯仰下离地 12-14 mm（H2）+ 后重分配（本节）共同指向**前轮部分卸载/轮胎变形**，但 Fn 实测缺失，标记待最小补测。`POSSIBLE`
