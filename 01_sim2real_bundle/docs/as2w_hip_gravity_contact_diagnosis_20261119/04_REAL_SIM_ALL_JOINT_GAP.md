**Layer B 核心发现——闭环吸引子不同**：

1. 仿真闭环把实机的稳态"纠正"到完全不同的形态：**hip 误差 0.19-0.24 → ≈0（0.5 s 内）**、俯仰 −4.5°→0°、漂移 ≤13 cm；
2. **calf 被推向上关节限位**（e → −0.82，calf 上限 −0.8133 rad 附近）、thigh 补偿性张开 0.47-0.79——仿真里没有实机那 10-16 Nm 的静态负载，55/2 PD 就把腿拉进"几何正确但实际是限位姿态"的吸引子；
3. 实机则稳定停在 hip 0.19-0.24、后 calf 0.30、pitch −6.1°——**实机稳态 = "命令 + 负载偏置角"**，与 §1 的 e_q×kp=st_tau 自洽；
4. 推论：**闭环行为差异不是控制律不同（两边同为 55/2），而是静态负载模型缺口在闭环里的放大**。任何用当前 MJCF 做的闭环轨迹复现（含 H4 层次 A 类轨迹对照）都会在 0.5 s 内偏离实机——这不是仿真 bug，是负载缺口的正确物理后果。

## 4. H4 结论

1. **全关节账本闭合**：thigh、前 calf 被最小范数重力支撑解释；后 calf 由后重 Fn 分配解释（16.22 vs 16.59）；**只剩 hip 的 10-13 Nm 需要非重力机制——侧向夹持或传动偏置（不可区分）**，幅值/符号结构（左右镜像、前后差、左右相消对基座零扰动）由 H3 反事实完整刻画。
2. **层次 B 判据**：闭环 0.5 s 内 hip 误差坍缩 + calf 压限位 = 仿真缺静态负载的直接动力学证据，与层次 A 静态账本互相印证。
3. **"前馈就能解决"的边界**：前馈 τ_ff=e_q×kp 可以抵消稳态偏置，但只在偏置恒定时有效；归因不明时它掩盖的是资产/标定缺口（任务书禁止预设此结论——此处仅为边界陈述，最终判断在 06）。
