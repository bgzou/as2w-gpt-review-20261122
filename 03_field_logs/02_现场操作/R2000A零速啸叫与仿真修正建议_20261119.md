# R2000A 零速档啸叫事件总结（供仿真/训练修正指导）

日期 2026-11-19 · 策略 `as2w_residual_run2000a`（交付包 `as2w-rolling-full-bundle-20261120`）
结论：**策略零速输出饱和颤振 → 真机伺服啸叫；交付 sim 磁带里同样可见该爆发，但 gate 缺"动作质量"判据，所以 sim 侧存活通过。需在 gate、训练正则、仿真保真三处修正。**

---

## 1. 真机现象（一次有界会话，2026-11-19 21:28）

- 链：A 起立 ✅ → B 交接 ✅（2s 零速）→ PolicyWalk 1.4s → 现场速率守卫硬限停 → 急停保持 3s → 干净退出。
- 护停前约 **2.4 秒**出现明显高频**啸叫**；保护流 `motorstate_or=0x0 / warning_or=0x0`、42.6V、关节温度 35–41°C、无跌落。
- 关节 dq 实测（2ms 采样，啸叫窗口 1.65s）：
  - FL calf：**符号翻转 259 次 ≈78Hz**，峰 −3.08 / +0.59 rad/s
  - FR calf ≈56Hz；FL hip ≈23Hz；thigh 15–20Hz
  - → 啸叫 = 齿隙/减速器在 15–78Hz 高频换向下的振鸣，非热/电气故障。

**真机 vs sim 差异**：sim 磁带同站姿大部分时间安静（仅一次爆发）；真机交接期 raw 持续逐帧翻转（2s 内几乎每帧）→ 真机状态落在策略饱和振荡区，把一次数值爆发放大成 2.4s 持续可闻振动。

## 3. 根因链

1. 策略零速附近**动作饱和颤振**（输出贴 ±1、相邻 20ms 帧翻转）；
2. 包装（10Hz 一阶 + 0.25 缩放）把 ±1 翻转变成 **0.3577 rad/20ms 的腿目标交变（25Hz）**；
3. 真机伺服带宽/齿隙 → 关节 dq 15–78Hz 高频换向 → 啸叫；
4. 交付 gate 只测存活/倾角/滑移/接触，**不测动作质量** → sim "存活通过"；
5. 现场速率守卫（warn 连续 5 帧 >0.2、hard 连续 3 帧 >0.35、非越线帧清零）被"交替型"波形打散 → 2.4s 后才硬停（保护按设计工作，但拦不住颤振）。

## 4. 仿真评估修正（gate：立即可做，无需重训）

| # | 判据（逐场景、逐 20ms 策略帧） | 建议阈值 |
|---|---|---|
| 1 | 单帧腿目标步进 | p95 ≤ 0.10 rad、max ≤ 0.20 rad（参考 R1199 已验收最大 0.063）；至少以 0.2 为硬门 |
| 2 | 颤振计数 | 50 帧窗口内腿目标符号翻转 ≥ 8 次 → fail |
| 3 | 频带能量 | 20–30Hz 能量占比 > 5% → fail；`joint_dominant_Hz` 由"信息"升级为"门"（主导频率 >5Hz 或 20–30Hz 能量显著 → fail） |
| 4 | 静止段专项（stand / command=0） | 目标方差 ≤ 1e-4 rad²；关节 dq RMS ≤ 0.3 rad/s；dq 符号翻转率 ≤ 5/s |
| 5 | 回归自检 | 把本交付 STAND 磁带 frame 348–368 作为固定回归样本，**新判据必须判其 fail**，否则判据无效 |

## 5. 训练修正（需重训/微调）

1. **动作速率惩罚**：`(a_t − a_{t−1})²` 加权，command=0 段提高权重；
2. **饱和抑制**：对 `|a|→1` 加 hinge 惩罚，或输出层软饱和/缩放，避免零速贴边；
3. **零速站立专项 curriculum**：长时 command=0 站立段，奖励低动作方差、惩罚颤振；
4. **残差基线复核**：零速时残差应≈0（基线已给稳定站姿）；当前残差贴 ±1，需检查 baseline/scale/残差幅值上限，并在交付合同中写明**零速残差上限**；
5. **交付清单**：新增"零速 60s 站立"专项指标（步进 p95/max、翻转率、20–30Hz 能量、dq RMS）。

## 6. 仿真保真（可选，用于复现/预测真机啸叫）

1. 执行器模型加 **FOC 电流环带宽/一阶延迟 + 关节间隙（backlash）**——刚性 PD 下 dq 3.2 rad/s 无声无害，真机齿隙会把 25Hz 目标变成 20–80Hz 振鸣；
2. 至少增加"dq 高频能量"作为 sim 指标（不依赖执行器建模即可判颤振）；
3. 用真机 2ms LowState 场速磁带（我方 S3 磁带）做 replay 回归。

## 7. 建议的联合验收顺序

1. 训练方先加 gate 判据，用旧磁带自检（必须判 fail）；
2. 重训/微调 → 新 gate 跑 8 场景 + 零速 60s 站立；
3. 交付时附"零速动作质量报告"（步进 p95/max、翻转率、20–30Hz 能量、dq RMS）；
4. 我方随后：parity → sim2sim → 真机零速档复测（每步仍须现场当次同意）。
