# 01 实验协议与现场安全检查清单

- 日期:2026-11-19
- 适用:O-G / O-S / P55-G / P55-S / HIP-SWEEP 全部会话
- **总则:任何可能使狗动作的命令,每次执行前向现场说明具体动作并获当次明确同意;预告不等于同意;Ctrl+C 不是运动急停(遥控器 X / 物理急停才是)。**

## 1. 通用前置(每次会话)

- [ ] CPRO 与机器人上电、链路可用(USB `0123456789ABCDEF` 或 WiFi `tconn <当前地址>:8710`,地址以当次实测为准)
- [ ] 只读基线:`现场入口.ps1 -Stage LowCaptureFast -Seconds 3` 或 CPRO `field.sh low-capture eth0 3 rt/lowstate 10`——LowState 流量正常(~1 kHz)
- [ ] 保护流干净:`field.sh low-protection eth0 5` 无置位
- [ ] 电池电压/温度正常(参照既往会话 ~43–44 V 基线)
- [ ] 场地:平地、防滑、无桌边/高处坠落风险、急停可达、**第二名观察者到位**
- [ ] 会话脚本已同步到 CPRO(见 §7 部署清单),二进制 SHA 与工作站一致

## 2. O-G 地面官方站立(风险最低,先行)

1. 现场用**原厂遥控器**使狗趴下→起立(或 `field.sh sport-command eth0 stand-up`,须当次同意),GetState 应为 `ai_stand_up` 或 `ai_free_walk`(2026-11-19 实测:已站立的狗在 ai 服务下报 `ai_free_walk`/fsm_id=3;判定以现场稳定站立姿态+LowState 为准)
2. **LowCmd 可见性只读探针(≥30 s)**:`field.sh lowcmd-capture eth0 30 rt/lowcmd 10`——纯订阅不发布,判定官方命令是否上 DDS 总线(00 审计 §1.2;2026-11-19 已实测可见 ≈497 Hz、CRC 全过,本步仍每次执行确认当次可见性)。有包→本会话 cmd 字段=探针实测;0 包→cmd 记 NULL,manifest 写明
3. CPRO 侧启动只读采集:`bash tools/run_hipdiag_official_session.sh og 120`(须当次同意;**该脚本不启动任何发布端**,只读;脚本内含步骤 2 探针)
4. 狗稳定站立后保持 ≥10 s;如做三窗,由现场在站立/趴下/再站立间操作,脚本分段记录
5. 结束:原厂遥控器趴下(`ai_damping`),等脚本自行归档
6. 现场填 `experiment_manifest.csv`(支撑=GROUND、四轮接触 YES、fsm=ai_stand_up|ai_free_walk(按当次 GetState 实报)、许可记录、探针结果)

**O-S(悬空官方站立)默认不做**:官方模式悬空运行无厂商许可证据(00 审计 §4)。若现场明示要做,必须:支架完成且四轮离地确认→原厂遥控器起立→异常时遥控器趴下**可能使腿收向支架**,须先确认趴下动作空间再授权。此为额外风险,由现场书面确认。

## 3. P55-G 地面自定义 PD 站立

1. 现场确认许可后启动:`运行现场策略会话.ps1 -Policy hipdiag -Mode p55-hold -MonitorSeconds 150 -ConfirmMotion`(工作站长口令入口,内部走 CPRO 六步链)
2. 六步门检(自动、不可跳过):二进制 SHA/audit → LowState 流量/mode_machine==2 → 控制权(趴下确认→ReleaseMode)→ 16 轴 mode=0 无其他 writer → 趴下小腿门 → 启动监测(500 Hz)+ 发布端
3. **操作员持原厂遥控器**:发布端 ~3–5 s 到 Passive ready;按 **A** 起立(FixStand 3 s 插值→FixedStand 55/2 T2);保持至 **Y**(或 30 s 超时自动趴下);**X=急停**(X 后姿态不受控,须准备接狗)
4. 预期现象:与既往 R214/T15 A 段相同——起立受控、后腿静态下垂约 0.24–0.33 rad(T15 家族已知,55/2 刚度所致)、无报警;若闻异常声音/看到跳动/支架异常→ **Y 趴下**并停止
5. 每窗结束等发布端 RC=0、脚本归档七件套;重复 3 次(3 会话或现场确认后同会话分段)

## 4. 悬空转移流程(P55-S 前置,人工、慢速、两人在场)

**原则:不在机器人通电承重状态下插入平台;不使用手臂持续承重;转移过程不切换控制器。**

1. 结束 P55-G 后狗处于**趴下/Passive**状态(或直接从趴下开始)
2. 机身**下电或保持 Passive 趴下**(现场选择;建议下电再移,消除任何受控姿态意外)
3. 将机身置于支架:承力点为**机身底部主承力结构**(现场确认,不压电池/线束/外壳薄弱处/散热口,不接触腿、轮、电机)
4. 支架稳定、防滑、防侧翻;**四轮与其他运动部件在全部目标角范围内离地且不触支架**——用外部尺测各轮离地间隙并拍照(路径记入 manifest)
5. 记录机身姿态(目视/手机水平仪即可;不要求对齐 −6°,如实记录,分析按实际姿态重算)
6. 若 P55-S 要执行:重新上电→只读基线复核→六步链→`-Mode p55-hold`(manifest 支撑=SUPPORTED_SUSPENDED)
7. **悬空期间遥控器 X 是首要急停;趴下(Y)在悬空态会使腿下摆,执行前必须确认下方/支架无干涉**

## 5. P55-S 悬空静态保持

- 同 §3 流程(同一二进制/同一 T2 目标/55/2);狗悬空后 A 起立——**腿展开瞬间支架与机身必须无人手在可能夹压区域**
- 预期:后腿下垂减小(自重仅 2–3 Nm 量级 vs 地面 10–16 Nm,H2);若 hip/calf 力矩仍接近地面基线(残差分析留给后续),现场无需判断,如实记录即可
- 保持 ≥10 s 稳窗 ×3;任何轮触地/支架移动/振动/异响 → **立即 Y/X** 并终止当天悬空实验

## 6. HIP-SWEEP 悬空单 Hip 扫角(仅 P55-S 全部通过后)

1. 前置:P55-S 三会话 QC 全 PASS(03 §5)且现场同意扫角
2. 启动:`-Mode hip-sweep -MonitorSeconds 240 -ConfirmMotion`(会话脚本内固定 `--sweep-hip <FL|FR|RL|RR>` 与 `--sweep-plan <csv>`)
3. A 起立→站稳→操作员确认环境安静、无人手靠近、支架无松动
4. **B** 触发一次已审计计划(B-gate:姿态误差/安静/杆居中全过才接受;被拒会打印原因,不重试逻辑)
5. 计划自动执行:±0.01 rad 首轮;每点保持 1.5 s;结束自动回零;再保持可由现场决定是否第二轮(±0.02 须另行当次确认,计划文件不同)
6. 终止手段任何时刻可用:**Y**(受控趴下,注意悬空腿下摆空间)/**X**(阻尼急停);异常声音/跳动/卡滞/丢帧/支架移动→立即终止,**不自动重试**
7. 一次会话一个 Hip;FL→FR→RL→RR 顺序逐会话推进,每 Hip 会话间现场确认

## 8. 停止条件汇总(任一即停,当天不自动重试)

- 任一保护位置位 / 低电压 / 通信中断(LowState 流量骤降)
- 异常声音、关节跳动、卡滞、肉眼可见振动
- 支架位移、任一轮触地、机器人触碰任何物体
- 发布端 FIELD_SAFETY warn/hard 行出现(会话日志实时可见)
- 观察员叫停(无需理由)

处置顺序:遥控器 X(急停阻尼)→ 若需受控结束改 Y → 等发布端 RC、停发 → 现场检查 → 当日记录异常再决定后续;**绝不把 Passive 当"通用安全退出"——悬空态 Passive 会让腿摆动。**
