配对纪律:
- P55-G 与 P55-S **必须同一二进制、同一 q_des(T2)、同一增益**,唯一差异是支撑条件;
- O-G 与 O-S 属同一官方模式(若 O-S 被解锁);
- 跨模式(O vs P55)的原始力矩差只作**描述性比较**——官方 q_des/前馈不可见,不能把差异直接归因于补偿或接触;
- 每个"站立保持"记录 ≥10 s 稳定窗口,重复 3 次(3 个会话或同会话内 3 段,逐段在 manifest 标注);
- 与历史 220051_fixedstand_hold(3.66 s,500 Hz)同链,P55-G 结果应可复现实机已有 10–13 Nm 四髋、16 Nm 后 calf 基线量级。

## 3. Hip 扫角(仅 P55-S 验收后)

| 项 | 合同 |
|---|---|
| 前置 | P55-S 三次静态会话全部通过 03 §5 有效性检查,现场确认无异常 |
| 控制器 | as2w_hipdiag_sweep_publish(独立构建;55/2 不变) |

| 顺序 | 单 Hip 会话制:FL → FR → RL → RR(每会话一个 Hip,便于逐次许可与异常隔离) |

| 轨迹 | 速度/加速度限幅平滑(hip_sweep_planner 生成;C++ 启动时二次审计;禁止阶跃) |
| 保持 | 每目标点稳态保持 1.5 s;每 Hip 可 2–3 周期,异常即停、不自动重试 |
| 其他关节 | 其余 11 腿目标 = 该次 P55-S 实际 T2 目标,四轮零速命令 |
| 触发/终止 | A 起立 → 站稳 → **B** 经 B-gate(pose_error/安静/杆居中)后开始计划;**Y 随时趴下、X 急停**;计划结束自动回零偏置 |
| 数据 | 同 P55 会话全链 + policy_diag 逐段阶段标记(03 §4) |

## 4. 执行顺序(任务书 §3.2 A–F)

```
A. O-G   地面官方站立 10s 稳窗 ×3(可与既有数据同日新采一组)
B. P55-G 地面自定义 55/2 站立 10s 稳窗 ×3
C. 人工安全转移至机身支架(见 01 §4:下电或趴下转移、支架承力点、四轮离地间隙拍照)
D. O-S  默认跳过并记录 BLOCKED_BY_VENDOR_MODE_CONSTRAINT(除非厂商/现场解锁)
E. P55-S 悬空自定义 55/2 静态 10s 稳窗 ×3   ← 主诊断
F. 静态质量检查(03 §5)通过 → 才允许 HIP-SWEEP(每 Hip 一会话)
```

每步之间:机器人回到趴下/安全态、日志回收核验、现场确认后再进入下一步。任何异常(声音、跳动、支架移动、接触、报警、丢帧)→ 停止推进,按 01 §6 处置。

## 5. 会话与目录命名

| 实验 | 会话脚本模式(CPRO) | 会话目录后缀 |
|---|---|---|
| O-G / O-S | `run_hipdiag_official_session.sh og` / `os` | `_hipdiag-og` / `_hipdiag-os` |
| P55-G / P55-S | `run_hipdiag_field_session.sh p55-hold`(manifest 区分 G/S) | `_hipdiag-p55-hold` |
| HIP-SWEEP | `run_hipdiag_field_session.sh hip-sweep --sweep-plan <csv> --sweep-hip FL` 等 | `_hipdiag-sweep-<HIP>` |
| dry-run | 各模式加 `-dry-run` 后缀 | `_dry-run` |

每次会话在 CPRO `/root/field_sessions/<stamp>_<mode>/` 生成七件套 + `experiment_manifest.csv`(现场填写),回收后归档 `部署测试/04_调试记录/logs/field_sessions/`(唯一权威位置)。
