## 1. 会话 212128：未滤波零命令 hold（核心发现）

时序：A 起立正常（固定 PD 段腿 |dq|max 0.08）→ B → 交接/策略段抖动 → 守卫 WARN count1/5（PolicyHandoff）→ PolicyWalk WARN×5 → SOFT_TRIP → Brake 段 HARD×3 → EmergencyDamping 趴下。策略活跃窗 4.6s。

量化（策略窗，500Hz）：
- 腿目标单帧步进 0.23–0.36 rad/20ms（守卫 warn 0.2/硬 0.35）；12 轴 |dq| 峰 1.2–3.2 rad/s，rms 0.368；|tau| 峰 37.7 Nm。
- FFT：FR_thigh dq 主频 **19–20Hz** 强分量（固定 PD 段无此峰）。
- 轮（速度模式，未经任何滤波）：|dq| 峰 3.23 rms 0.415。
- 保护流 0 告警；无 motorstate 异常。

机理判断：**策略原始输出在零命令下交替**（≈每 2–3 个策略帧翻转一次方向），与 getup1199 家族曾记录的"raw ±0.24 rad @ 25Hz"同签名。MuJoCo hold PASS（同策略步进仅 0.084 max）说明理想化 PD/接触吸收了该交替——真机 FOC+结构吸收不了。

## 2. 会话 162244 与 163432：40ms 腿低通候选（LP40）

设计：一阶 IIR `applied = prev + α(req−prev)`，α=1−exp(−0.02/0.04)=0.3935，仅腿位置目标、轮直通；rev1 只滤策略段（交接段漏滤），rev2 交接段同滤。

| 指标（策略窗） | 未滤 212128 | LP40 rev2 163432 | 变化 |
|---|---|---|---|
| 守卫 | WARN×5→SOFT_TRIP→HARD | **0 触发** | 消除 |
| 腿 \|dq\| max / rms | 3.19 / 0.368 | 2.26 / **0.103** | rms ×0.28 |
| 腿 \|tau\| max | 37.7 Nm | **19.5 Nm** | ×0.52 |
| 轮 \|dq\| rms（未滤） | 0.415 | 0.280 | ×0.67（轮未滤，降为间接效应） |
| 策略段存续 | 4.6s（被守卫终止） | **10s 跑满 + 刹转保持，操作员 X 结束** | — |
| 残余 | — | FR_thigh 12.5Hz 分量仍可辨；**Brake 轮稳定检查超时**（轮未静） | — |

rev1（162244）：守卫在未滤波的 2s 交接混合段 WARN×5→SOFT_TRIP（leg_step 0.23–0.245），滤波从未进入策略段——我方滤波覆盖缺口，已修复；该会话数据仍可作"交接段即触发"的证据。

结论：**LP40 对腿抖动为有效缓解非根治**；轮通道交替未被处理（R1199 现场配方轮速不滤）。若训练侧出包装版，建议在训练管线内处理零命令交替，而不是部署端事后滤。

## 3. 会话 163052：t2-cal 关节级站姿标定的真机否决

标定目标 = 2×T2 − 实测（把逐关节下沉全量预置进目标；后腿 calf −1.31 vs 前腿 −1.47，**后腿目标比前腿直 0.16 rad**）。

真机表现：第一次站立 15s 基本直立（upright≥0.89，用户目视"姿态奇怪"）；第二次起立后**机头下倾（upright 0.72）**：前腿 |err| 0.37–0.58（后腿仅 0.01–0.08），轮持续缓转 ≈0.3 rad/s（≈2.6cm/s 前爬），B 门拒收（pose_error 0.58>0.35），最终 FOC 应答丢失→故障安全停机。

机理：**自由浮动轮式平台上"关节角对齐"≠"机身水平"**。后腿实测多沉是重心靠后的承重份额；强制后腿伸直=机尾上抬=机头下倾=载荷前移（前腿误差暴增）+轮上前爬。教训固化：轮式平台站姿标定必须以机身俯仰为判据做前后差分、首次 ≤30–50% 幅度。

## 4. 会话 163911：摇杆首测与未解 disarm

B 门通过（pose_error 0.305 / upright 0.994 / quiet 0.025——恢复 t2 后与历史一致）→ 交接 2s → PolicyWalk 2.6s（13 条 WALK_CMD，摇杆全程零输入）→ **控制器自行 disarm → EmergencyDamping 趴下**，rc=0。

disarm 门逐一排查（我方控制器源码）：
1. 命令包络（摇杆全零 → 合法）；
2. 数据 age >50ms：**监控流复查无 >25ms 间隔**（10707 帧 21.4s，0 个）；但发布端自有订阅者的 age 不可外部观测，未排除；
3. 四元数范数 ∉[0.81,1.21]：监控侧 [0.999999,1.000001]（0 异常帧）；
4. 传感器/输出非有限：监控侧全有限；ONNX 输出未记录（本会话未开逐帧 debug）。

下一步：发布端加入 disarm 原因日志后复测。**原始数据全附**，欢迎训练侧用 `analysis/armd_reference_tape_3550frames.npz` 复验策略在该场景的行为。
