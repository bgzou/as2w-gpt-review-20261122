## 3. gpufree 镜像仓库比对

`https://www.gpufree.cn/images` 是 SPA，清单来自 API `GET /api/v1/images/public/display_list`（本次实测 10 个分类、约 90 个镜像）。与机器人/RTX 仿真相关的都在 **「具身机器人」** 分类（48 个）。

### 3.1 直接相关候选

| 镜像（image_id） | 体积 | 与本仓库要求的差距 |
|---|---|---|
| **234 `Isaacsim6.2.0+IsaacLab3.0.0 workstation+ROS2 jazzy`** | 54 G | **Isaac Sim 6.2.0 + Isaac Lab 3.0.0 与本仓库记录的大版本完全对上**；差在实测机用的是 `6.2.0-rc.14`（RC），镜像是 6.2.0 发行版 → 需按 `runtime.md` 先 replay + smoke |
| 233 `Isaacsim6.0.1 workstation + ROS2 jazzy ubuntu24.04` | 57 G | Isaac Sim 6.0.1 低于 6.2，Isaac Lab 版本需现场核；API 面向上不匹配 |
| 230 `IsaacSim5.1+IsaacLab2.3.2 workstation + ROS2 jazzy` | 45 G | Isaac Lab 2.3.2 ≠ 3.0.0，API 层不兼容 |
| 229 `IsaacSim5.1+IsaacLab-2.3.2 pip 安装版` | 40 G | 同上，但 pip 形态，便于自己 `uv pip install isaaclab==28.0.0` 升级 |
| 232 `IsaacSim5.0+IsaacLab-2.2.1` | 40 G | 差两代，不建议 |
| 138 `Mujoco基础环境` | 34 G | 只能当第二仿真器（MuJoCo 3.2.3/3.17 线），不能做 Isaac 训练 |
| 237 `宇树Unitree RL Gym` / 238 `宇树Unitree RL Lab` / 239 `宇树Unitree RL Mjlab` | 26/42/30 G | 宇树**官方**三条 RL 线（Isaac Gym / Isaac Lab / mjlab）。本仓库是自建 `unitree_style` 任务 + Isaac Lab 3.0，不是官方仓库，直接套用会版本对不上 |
| 166 `TCEI 2026 四足机器狗特种场景` | 63 G | 赛事镜像，含赛题栈，与本项目无关 |

### 3.2 结论：首选 234

**选 `234 Isaacsim6.2.0+IsaacLab3.0.0 workstation+ROS2 jazzy`（54 G，tags：cuda/conda/isaacsim/isaaclab/ros2）。**

理由：
1. 这是目录里**唯一**把 Isaac Sim 6.2 + Isaac Lab 3.0 写进名字的镜像，与本仓库 `repro/` 记录的版本是同一代；`isaaclab==28.0.0` 这条 pip 线只有在 3.0 上才成立。
2. 原训练机（`docs/taskbook-20261121/AS2W-服务器核对报告-20261121.md` 里的 `/isaac-sim`、`/opt/isaaclab-venv`、`/root/gpufree-data`）本身就是 gpufree 机器，说明这条“镜像 + L40”的组合已被本项目跑通过。
3. 自带 conda/ROS2 jazzy，后面接 `unitree_sdk2`/CPRO 侧工具不必另配。

**次选**：`229`（IsaacSim 5.1 + IsaacLab 2.3.2 pip 版）——只在 234 起不来时作为“裸环境 + 自己装”的底座，装法与 `runtime.md` 的 pip 路径一致，但要自己 `uv pip install isaacsim[all]==6.2.0.0`。

**不建议**：A100/H100 之类无 RT 核心的卡（Isaac Sim 官方要求 RTX 系），以及 232/233 这种落后两代的组合。

## 4. 机型、磁盘、成本

gpufree 商品接口（`/api/v1/products/list`，价格字段为**分**）当前快照：

| 机型 | 显存 | 时价 | 日价 | 判断 |
|---|---|---|---|---|
| **L40 / 48G** | 48 G | ≈¥2.28/时 | ≈¥54.5/日 | **首选**：与记录机同款，8192 env 有余量 |
| L40S / 48G | 48 G | ≈¥2.78/时 | ≈¥66.5/日 | 同等可用，贵约 20%，Ada 架构更快，可选 |
| RTX 4090 / 24G | 24 G | ≈¥1.38/时 | ≈¥33/日 | 便宜，但 24 G 只够 2048–4096 env 试跑，长训练不建议 |
| A100 / 80G | 80 G | ≈¥5.99/时 | ≈¥140/日 | 显存大但**无 RT 核心**，Isaac Sim 不推荐，别为显存选它 |
| T4 / 16G | 16 G | ≈¥0.78/时 | ≈¥18/日 | 只能做 ONNX/CPU 侧工具，跑不了 Isaac Lab |

成本估算（按记录机 6–8 s/更新）：**600 轮 ≈ 1–1.3 h，1 万轮 ≈ 17–22 h**，L40 上 1 万轮约 **¥40–55**。真正的瓶颈通常不是 GPU 费用而是**磁盘**。

要点：
- **数据盘加 50 G 起步（合计 100 G）**。默认 SKU 是系统盘 30 G + 数据盘 50 G，超出部分按界面 **¥0.01/GB/天** 计（+50 G ≈ ¥0.5/天 ≈ ¥15/月）。依据见 §4.1：单条训练线基线 15–20 G，并行 2–3 个 1 万轮 run 再加 12–18 G，100 G 留出约 60 G 余量；原训练机 49 G 盘用到 73% 就是“不够”的现场教训。要并跑 3 条以上、长期存视频或把实机数据搬上来时再追加 50 G（合计 150 G，≈¥1/天）。

### 4.1 磁盘预算（实测/仓库数据折算）

| 项目 | 体积 | 依据 |
|---|---|---|
| 训练仓库（含 `.git`） | 1.3 G（快照 0.8 G） | 本次实测 798 MB |
| Isaac/Omniverse 着色器缓存 | 2–4 G | 首次 headless 启动生成，落在根盘 `~/.cache` |
| 单个 checkpoint（policy+optimizer） | ≈5 MB | `baseline/` 7 文件 9.6 MB |
| 平地回放产物 `flat.npz` | ≈10 MB/次 | 仓库内 npz 9.5 MB |
| **一个 1 万轮 run**（分段 checkpoint + 评估 npz + 视频） | 2–6 G | 原机 `unified-dr-20261119-013647` 6.2 G、`as2w-rolling-goal` 4.1 G |
| MuJoCo 第二仿真器 venv（可选） | 5 G | 原机 `mujoco-venv` 5.1 G |
| 基线小计（1 条线 + 1 个 run + 少量归档） | 15–20 G | |
| 原机实况 | 49 G 盘用 34 G（73%） | 服务器核对报告 |

**注意 30 G 系统盘才是隐藏约束**：`/opt`、`/root`、`~/.cache` 都在根盘（原机 30 G 用 9.9 G），镜像自带的 `/isaac-sim`（16 G）在镜像层不占这两块。**不要在根盘重装 Isaac Sim**（`uv pip install isaacsim[all]` 约 10–18 G），需要补装就在数据盘上建 venv，并把 `uv`/`pip`/`HF_HOME`/`OMNI_KIT_CACHE` 指到 `/root/gpufree-data`。
- **vCPU 要多**。SKU 默认 14 vCPU/GPU，而记录机是 128 vCPU。Isaac Lab 4096/8192 env 是 CPU 密集型，14 核下 `s/更新` 会明显高于 6–8 s；下单时优先挑多核规格，否则把 env 数降到 2048–4096 并重测速度。
- 内存 128 GiB/GPU 够用（记录机 1 TB 是因为整机共享）。

## 5. 开好机器后的 10 分钟检查清单

```bash
nvidia-smi --query-gpu=name,memory.total,driver_version --format=csv   # 驱动必须 ≥580，否则 torch cu130 / Isaac Sim 6.2 有风险
cat /isaac-sim/VERSION                                                  # 期望 6.2.0 系
python3 --version                                                       # 3.12.x
```

把仓库放到机器上（两种都行）：
1. 服务器直连 GitHub：`git clone https://github.com/YuTaoV5/as2w-unitreestyle.git`（带 .git，服务器侧不受本项目“无 .git”约束）；
2. 或从本机传快照：`部署参考\as2w-unitreestyle`（798 MB，无 .git），用 `SHA256SUMS.txt` 校验。

然后按项目合同对齐路径与预检（**不要跳过**）：

```bash
export ISAACSIM_ROOT=/isaac-sim
export AS2W_PYTHON=/opt/isaaclab-venv/bin/python     # 若镜像的 venv 路径不同，改成实际路径
./repro/check_runtime.sh
```

`check_runtime.sh` 会做三件事：校验 `repro/inputs.sha256`、打印 GPU/驱动、比对 `$ISAACSIM_ROOT/VERSION` 与记录的 RC 版本。**在 234 镜像上出现 “Isaac Sim build differs from the recorded training build” 是预期的**，按 `runtime.md` 的要求继续：

```bash
RUN="$PWD/runs/replay-$(date +%m%d-%H%M)"
./continuation1220/prepare_run.sh "$RUN"      # 校验冻结输入 SHA，建 $RUN/source
./evaluation/replay.sh "$RUN"                  # 48 环境平地回放 → flat.npz / gait gate
./continuation1220/smoke.sh "$RUN"             # 真跑一次完整 PPO 更新（393,216 env 步）
```

只有 `replay` 的 `gait_preserved=true` 且 `smoke` 出现 `AS2W_TRAIN_SMOKE_OK`，才说明这条“发行版 + 新卡”的数值路径可用，再开正式训练。数值差异本身不等于失败，但**必须用 gate 结果说话，不能只看能跑起来**。

## 6. 风险与边界

1. **RC vs 发行版**：训练证据来自 Isaac Sim `6.2.0-rc.14`，镜像是 `6.2.0`。PhysX 构建差异会改变轨迹；`runtime.md` 已声明“不同 GPU、驱动或构建的训练结果可能有数值差异”。所以任何“续训出来更好/更差”的结论，都要先过 `replay`+`smoke`+`gate`，不能直接和 1220 基线比回报。
2. **`workstation版` 是 GUI 安装形态**：headless 训练一般可用，但首次启动有许可交互；若遇 `libcarb.so` 静态 TLS 报错，按 NVIDIA 安装说明加 `LD_PRELOAD`（`runtime.md` 已写明）。
3. **镜像名里的 Isaac Lab 3.0.0 需现场核实**：`python -c "import isaaclab; print(isaaclab.__version__)"` 与 `isaaclab==28.0.0` 对不上就按 `runtime.md` 的 pip 路径补装。
4. **驱动门槛**：`torch 2.11.0+cu130` 与 Isaac Sim 6.2 都吃 580 系驱动。若目标机器 `nvidia-smi` 显示 5xx 以下，先找平台确认能否升级，否则换 L40S 机器或退回 Isaac Sim 5.1 线（但那样 Isaac Lab 3.0 代码要改，等于换版本）。
5. **不要把服务器当权威存储**：项目规则里服务器 `/tmp/opencode` 不持久；训练产物要么落到数据盘，要么定时空回工作站。
6. 本文所有镜像体积、价格、驱动、版本号均为 2026-11-21 的接口/文档快照，下单时以控制台实际显示为准。
