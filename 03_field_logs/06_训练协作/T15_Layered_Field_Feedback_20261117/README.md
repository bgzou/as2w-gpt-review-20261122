## 1. 部署链验证（简述，全部证据随包）

- S1 parity：独立 Python 移植 vs 交付参考链（obs_builder/控制器/mapping 原样 import），6150 帧闭环录带
  （含 6s 命令失联恢复），obs ≤1.06e-07、轮目标 ≤8.5e-07。
- C++ 移植：5500 帧传感器级夹具（q16/dq16/IMU/命令），x86 与 CPRO ARM64 双端 vs 同一带全部 ≤3.7e-07。
- 过程修了三处实现缺陷（相位 float32 常数、轮 wrap float32、prev off-by-one），均已回馈到实现笔记。
- ARM64：ONNX Runtime 加载（外部数据 sidecar 成对分发**必须**——详见 §7 打包建议）。

## 2. 速度控制（通过）

- zero-B（1 次）：B 一次接受、2s 零速交接腿目标单帧步进 **0.00012 rad**（对比：本项目 R1199 训练合同版
  0.003、旧故障版 0.27——本狗历史最平滑 B 交接）、零命令保持无感、松杆零漂移。
- 摇杆 55/2（2 次）与 85/3.2（3 次）：vx 命令满量程 ±0.200（有效帧 685–1294/次）、wz ±0.115–0.117、
  u_yaw 反号正确、松杆 vx_served→0 干净；**速度响应在两种腿增益下无差异**（腿目标步进同量级）。
- 前进速度精度：真机未做精确测量（无外部真值），但 MuJoCo 侧 2–4% 与 PhysX 侧 20–49% 的引擎差保留为已知缺口。

## 3. 站姿塌陷根因（训练侧核心反馈）

**现象**（55/2 摇杆两次会话，PolicyWalk 段）：
- 策略腿目标**逐帧钉死训练默认角**（大腿 0.800–0.803、小腿 −1.600~−1.601，BC 残差 |a|≤0.005）——策略无过错；
- 实际后大腿垂到 **0.44–0.49**（塌 0.24–0.26 rad）、后小腿 **−1.925/−1.932**（塌 0.33 rad）→ 机身后仰
  （up_z min 0.923≈22.7°）→ **后小腿/脚跟拖地**（现场可闻可见）；
- 塌陷与速度**无关**（|vx|=0 站立与 0.2 满速各档塌陷量相同）——纯静态问题；
- 电机**无罪**：塌陷窗口后大腿 tau_est 均值 13.3/11.6 Nm、峰 17.7 Nm ≈ kp55×误差（13.2/11.3）——PD 精确
  执行指令，塌到"55×误差=后腿载荷"的静态平衡点为止；距力矩限（≥60 Nm）与守卫 warn（35 Nm）都很远。

**根因**：训练合同"kp55/kd2 + 低默认姿态 (0.8,−1.6)"在**真机后重负载**（本项目已实证：趴姿下后腿稳态负载
比前腿重 ~40%，getup1199 真机数据）下的静态平衡必然低于仿真预测。MuJoCo 26kg 标称模型塌得少（不显）；
本项目用"质量×1.3 + COM −0.03m"压力工况在 MuJoCo 中**精确复现真机塌陷签名**（后大腿 0.587 vs 真机
0.56–0.60、后小腿 −1.939 vs −1.93）——复现脚本随包，训练侧可直接用。

**为什么 R4000 家族不拖地而 T15 拖**：R4000 训练合同带站姿补偿包装（rolling_precalibrated_stand，
标定量 ±0.38 rad——恰好是同量级的塌陷被预补偿）；**T15 是纯 BC，合同无任何补偿机制**。这不是权重缺陷，
是运行时包装合同差异。

## 4. 抗扰/鲁棒性审计（教师数据）

`bc/teacher_proportional.npz`（9000×65 obs / 9000×14 action）实测：
- **教师腿动作 12 通道逐样本恒为 0**（std=0、max=0，9000/9000）；
- 即教师=「腿永远回默认站姿」，BC 忠实复刻——**策略层没有、也学不到任何负载/姿态反馈行为**；
- 后果：负载变化、推扰、地面变化时，"维持站姿"的唯一机制是 PD 刚度（55/2→塌；85/3.2→挺），策略不会调腿；
- **这不是 bug**：分层设计把平衡交给了轮控律+PD。但「抗扰/变负载站姿调节」能力**在当前教师下不可能存在**，
  若需要该能力须换教师（腿通道非零、含姿态/负载反馈项），例如以 85/3.2 高刚度 PD 站立平衡点为教师的腿目标生成器。

## 5. 部署侧缓解：85/3.2 stiff 候选（三次真机通过）

按项目硬规则作为独立动作修订（独立宏/独立构建/双端 parity/回归 SHA 不变），三次真机会话：
- 后大腿塌 **0.24 → 0.036–0.057 rad**（与 MuJoCo 压力工况预测 0.03–0.06 一致）；
- 后小腿 −1.93 → **−1.728~−1.746**，**零拖地帧**；up_z min **0.989–0.996**（55/2 时 0.923）；
- 后大腿力矩 3–5 Nm、峰 8.2 Nm（warn 门的 23%）——85/3.2 余量充足；
- 速度响应、腿目标平滑度、交接（kp 渐变 55→85）均无差异/无异常；
- **判定：部署侧可用的缓解方案，但治标不治本**——若训练侧更新教师/合同，此候选即作废。

## 6. 给训练侧的具体请求（按优先级）

1. **站姿合同修订**：真机可用站姿需要更高默认角（本项目实测原厂自然站立 thigh≈0.60/calf≈−1.23）或
   部署侧站姿补偿包装（R4000 同款）；当前 (0.8,−1.6) 在真机后重下静态塌陷拖地。
2. **增益合同说明**：训练用腿 kp55/kd2；真机拖地根因即此。若下一版维持 55/2，请同时给出预期的静态塌陷量
   （或换更高增益训练）；部署侧已验证 85/3.2 无副作用（数据随包），可作为训练参数参考。
3. **抗扰教师（如需该能力）**：腿通道恒零的教师不可能产生抗扰策略；建议教师含姿态/负载反馈（可从
   高刚度 PD 平衡点 + 重观测扰动数据生成），并在 README 明确声明本策略"无腿主动平衡"。
4. **forward 速度 PhysX 缺口**（沿用交付 known_gaps）：真机不以前进速度精度为先期判据，继续保留披露。
