# AS2-W「差速转向失效」根因总结与解决方案参考

版本 **v1.1**（v1.0 的重要修正见 §11） | 2026-11-14 | 编制：训练侧（lead）
适用：滚动（四轮接地）策略的转向差动能力；同样适用于踏步/盲走权重上线前的同类排查

---

## 0. 一句话结论

真机长转轮差从命令 1.47 rad/s 塌到 0.14–0.17 rad/s（≈10×）。**不是推理/包装/发布链坏了**，而是三层问题相乘，其中**第一层就足以致死，且它在训练仿真器 PhysX 里就能复现**：

```
10× ≈ ① 策略长转覆盖不足 + 轮差权限不足  ← 主因，PhysX 复现（yaw 17.3 % vs 实机 13 %）
      ② 执行器差动力矩结构性上限 ≈1.5 N·m/轮（kd=2 纯速度环）
      ③ 轮地摩擦/接触模型的仿真器差异（PhysX vs MuJoCo 差 ~4×）
```

**关键修正（v1.1）**：R4000 原报告只有 MuJoCo 对照，据此断言"塌缩与幅差均为实机侧独有"。我补做 PhysX 回放后，**同权重、同真机波形在训练仿真器里跑出 yaw 17.3 % / 轮差 8.5 %，与实机 13 % / 11 % 几乎一致**；而 MuJoCo 给出 83 % / 30 %。→ 塌缩**不是** sim2real 独有，**MuJoCo 在轮差上明显偏乐观，不能单独作为验收基准**。

## 1. 现象（实机会话原始数据）

对象：`20261113-114335_r4000`，权重 rolling-4000-stage020-research，包络 ±0.4 m/s / ±0.1 rad/s，120 s PolicyWalk。

| 量 | 长右转 [1978:2560] 11.6 s | 长左转 [2921:3557] 12.7 s |
|---|---|---|
| 命令 wz | −0.097 | +0.092 |
| 命令轮差 cmdDdq | −1.47 rad/s | +1.40 rad/s |
| 实测轮差 measDdq | −0.17（**11.6 %**） | +0.14（**10 %**） |
| gyro_z | −0.0123（**13 %**） | +0.0126（**14 %**） |
| 塌缩时程 | 3–4 s 内塌完 | 3–4 s 内塌完 |
| **短转（1.4–2.0 s）对照** | **58–105 %，不塌缩** | 同 |
| 直行 0.37 m/s 对照 | 发布-测量一致，servo 斜率 1.92–1.93 | 同 |

**"短转能转、长转必塌"是本次最有信息量的一条**：它把"完全不会转"变成"力矩/阻力平衡点在数秒内滑走"。

## 2. 根因分解

### 2.1 已排除：手柄 → 推理 → 包装 → 发布链（0 损失）

| 验证项 | 结果 |
|---|---|
| 源码公式重算 vs 记录 requested/applied 目标（含 5 Hz 腿滤波、限速、站姿补偿、0.12 s 轮锁存状态机） | **max err 1.376e-06**（全 6001 WALK 帧） |
| applied 目标 vs 最终发布 LowCmd | **29705/29708 = 100.0 %** 精确匹配（残差 3 帧为帧切换边界 ≤0.078） |
| 发布轮行字段 | mode=1、**kp=0、kd=2、tau=0**（纯速度环、零前馈），逐帧核对 |
| 轮锁存 | 5 个分析窗内 0 帧（命令未居中，正确未启用） |
| 保护位 / 通信龄 | warning、motorstate **全零**；通信龄 p99 = 1–3 ms |
| `wheel_step` 守卫 | 未触发（命令斜坡经 0.1 rad/s² 摇杆斜率） |

**结论：链路无问题，问题全部落在"发布轮速命令 → 实测轮速差"这一级。**

### 2.2 策略侧根因（训练覆盖 + 训练结构）

| 证据 | 数值 |
|---|---|
| ONNX 轮差动分量（side 加权 steering range），**全部 4157 运动帧** | **[0.0, 0.0]** |
| 轮 raw 动作裁剪 | `wheel clip fraction = 1.0`（**恒在 ±1 饱和**，没有差动余量） |
| 轮 raw 模式 | `+6, +6, −6, −6`：**前后**反对称，**左右无差** |
| 转向差动**唯一**来源 | 部署包装确定性开环注入 `−0.66·(1+0.25·steering)·wz·side`（r4000_controller.cpp L161–165） |
| 已启用的偏航误差反馈 | **不存在**（只有 0.12 s 轮位置锁存 + 站姿 bias 积分，长转期间都被门控关闭；gyro 只进观测） |

**机理 A（奖励捷径）**：训练包装里同样有开环注入，仿真轮地阻力又低 → 开环注入"够用" → 奖励持续给捷径发分 → 策略没有梯度把（已饱和的）轮动作余量花在差动上。

**机理 B（训练分布盲区，更致命）**：训练命令驻留仅 **1.1–3.4 s**，而实机塌缩要 **3–4 s** 才发展完。**故障模式整个落在训练分布之外**，训练侧永远看不到它——这才是"再训一版也未必修好"的原因。

### 2.3 执行器侧根因（结构性差动力矩上限）

| 项 | 值 |
|---|---|
| 轮端执行器模式 | `kp=0, kd=2, tau=0`（纯速度环，零前馈） |
| 可产生的每轮差动力矩上限 | `kd × (命令差/2) = 2 × 0.735 ≈ **1.47 N·m**`（全失速极限） |
| 实测 `tau_est` 对 `kd×(cmd−meas)` 拟合斜率 | **1.89–2.01**（理想 2），全程线性 |
| tau 峰值 | 1.6–3.4 N·m/轮 ≈ **正好是这个结构上限** |
| 死区 / 固件限流 / 削顶证据 | **无** |

**机理**：速度环停在「可用力矩 = 轮地刮擦阻力」的平衡点。**不是坏了，是权限不够。**

### 2.4 仿真器侧根因（轮地接触模型差异）— v1.1 新增

同权重、同包装、同 11.6 s 真机波形、同初态、同摩擦 0.8、同 90 % 力矩钳：

| 仿真器 | 长右转 yaw | 长右转轮差交付 | 长转非轮触地 | 结论 |
|---|---|---|---|---|
| **PhysX（训练仿真器）** | **17.3 %** | **8.5 %** | 见下 | **复现实机塌缩** |
| MuJoCo（R4000 报告所用） | 83.4 % | 30.1 % | 0 帧 | **明显偏乐观** |
| 实机 | 13 % | 11 % | — | 基准 |

**→ MuJoCo 在轮速差方向上的有效刮擦阻力远低于 PhysX，因此不能单独作为轮差/长转的验收基准。**
（v1.0 里"实机阻力 ≈ MuJoCo 2–3×"的说法仍然成立，但它同时说明 **MuJoCo 是那个偏低的基准**；PhysX 才接近实机。）

## 3. 定量缺口分解

**MuJoCo 单变量实验（R4000 报告，固定腿姿 + 实机轮目标回放，只动轮端 kd）**：

| kd | 轮差跟踪 | 偏航 |
|---|---|---|
| ×1（原生 kd=2） | 29 % | 38 % |
| **×4（kd=8）** | **73 %** | **86 %** |
| ×10（kd=20） | 91 % | 106 % |

该实验把「力矩权限不足」与「腿姿/策略行为/发布链」干净分离。在 MuJoCo 的尺度下：

```
MuJoCo 内 ~3× ≈ 力矩权限（kd×4：29 %→73 %）
PhysX 相对 MuJoCo 再 ~3–4× （17 %/8.5 % vs 83 %/30 %）
合计 ≈ 10×（对齐实机）
```

**但请注意**：由于 MuJoCo 本身不可信，以上 kd 结论**必须先在 PhysX 里重做一遍**才能用于定 kd（见 §7 第 0 步）。

## 4. 明确排除项（避免误修）

| 候选 | 结论 | 证据 |
|---|---|---|
| 后腿下沉 / 蹲姿 | **伴随 + 加重因素，非根因** | 固定腿姿仿真同样不塌缩（E3b）；新右转窗口下沉 1.6 s 起、塌缩 2.1 s 起（下沉略先），但左转窗口开始时腿已蹲着 → 塌缩**立刻**发生。即与「蹲姿存在」强相关，与「下沉过程」无固定先后。无接触力证据 |
| 纯开环增益不足 | **不可行** | 开环增益 ×2/×5/×10 → 偏航 168 %/638 %/1507 %，0/3 稳定 + 非轮触地 |
| 发布槽位/符号/单位/零点 | 无问题 | 全 6001 帧复核 1.376e-06 / 100 % |
| 电机保护 / 通信 | 无问题 | 保护位全零、通信龄 p99 1–3 ms |
| 固件限矩 | **未确认，不建议作为修复入口** | `tau_est` 全程线性且远低于守卫阈值（8/12 N·m） |

## 5. 我方重训权重的最新对照（第一手，2026-11-14）

背景：训练任务已修完 6 个 plant 缺陷（轮 DOF stiffness、5 ms 硬速度环、观测/奖励写活缓冲、90 % 力矩钳、sim2sim 观测一致、指令限速）。**我方训练任务里没有 `0.66·wz·side` 开环注入**（`legged_gym/envs/as2w` 下搜不到 `0.66` / `steering`）→ 策略必须自己学差动。

### 5.1 长转对照（r7 model_2000，R4000 120 s 波形）

| 指标 | 我方 PhysX | 我方 MuJoCo | r4000 MuJoCo | r4000 实机 |
|---|---|---|---|---|
| 长右转 [1978:2560] 偏航 | **17.3 %** | 83.4 % | 38 % | 13 % |
| 长右转 轮差交付 | **8.5 %** | 30.1 % | 29 % | 11 % |
| 长左转 [2921:3557] 偏航 | 未覆盖（见 §9） | 49.1 % | 38 % | 14 % |
| 非轮接触 | — | **0 帧** | 有（后小腿擦地） | — |
| max tilt | **1.62°** | **1.89°** | — | — |
| 轮离地最长 | — | **0.04 s（<0.06 PASS）** | — | — |
| 峰值力矩 / 90 % 上限 | — | **57 %** | — | tau 峰值 ≈ 结构上限 |
| 直行 speed ratio | 1.34 / 1.05 / 0.83 | 1.05 / 1.48 / 1.05 | — | 0.91 |

### 5.2 结论

1. 我方策略**不再依赖开环注入**，MuJoCo 里偏航明显好于 r4000（83 % vs 38 %）。
2. **但 PhysX 里只有 17.3 %，与实机同阶** → **我方 12k 重训并没有修好长转差速**，这是本轮最重要的结论。
3. 姿态与安全全过（倾斜 <2°、非轮接触 0、轮离地 0.04 s、峰值力矩 57 %）→ plant 修复有效，**问题集中在差动通道**。

### 5.3 我方权重新发现的缺陷（必须修）

| 观测 | 数值 | 含义 |
|---|---|---|
| `wz≈0` 时轮差指令偏置（PhysX / MuJoCo） | **−1.12 / −1.20 rad/s** | 零指令下持续偏航漂移 |
| 规范状态 ONNX 输出（标称站姿、零速、零指令） | 轮速 common **+1.64 rad/s 前进**；前后轮反向 scrub；`ddq = +9.44·wz + 1.51` rad/s | 零指令不驻停 + 轮差标度偏大且带直流偏置 |
| 左右不对称 | MuJoCo 右转 83 % / 左转 49 % | 偏置与命令同向/反向导致 |
| 120 s 累计位移 | PhysX 2.30 m（mean vx +0.038） | 零指令漂移可测量 |

→ 这不是沿袭 r4000 的毛病，而是**我方自己的新缺陷**：零指令轮速惩罚不足 + 左右对称性未约束。

### 5.4 新发现的工具链缺陷（必须先修，否则后续结论不可信）

**`gym_rollout.py --friction` 是空操作**：以 `--friction 0.8 / 0.4 / 0.2` 三次运行，`summary.json` 记录了不同的 `friction` 值，但输出的 `.npz` **md5 完全一致**（`f0aa7c81…`）。→ 该工具的摩擦扫描、以及任何"PhysX 侧摩擦敏感性"结论**目前无效**。需改为在 `make_env` 之前设置 `env_cfg.terrain.static_friction / dynamic_friction`（地面才是主导接触面），并加"改一个参数必须改一个输出"的自检。

## 6. 解决方案参考

按「见效速度 / 改动面 / 风险」排序。**建议 D（验收判据）先做，然后 A 与 C 并行，B 在 PhysX 里重新标定后落地。**

### 方案 A：部署端有界偏航率反馈（最小修正）

```
wz_eff = clamp( wz_cmd + Kp·(wz_cmd − gyro_z_body), ±0.15 )
仅作用于差动注入项；观测命令通道与 previous-action 保持原合同
Kp = 3，限幅 ±0.15
```

| 项 | 结果 |
|---|---|
| 效果 | 偏航跟踪 **89 %**，**0 非轮触地**（MuJoCo 快速矩阵） |
| 稳定性 | 2/3 种子稳定；1 种子驻停未过 → **需排查** |
| 反例 | ✗ 开环增益 ×2/×5/×10 → 168 %/638 %/1507 %，0/3 稳定 |
| 落地 | 独立候选开关（默认关闭），独立 SHA，走完整双仿真门槛后才谈实机 |

**性质**：补偿而非根治；上限仍受 §2.3 力矩权限约束。

### 方案 B：执行器差动力矩权限（针对性根治）

1. **提高轮端 kd（2 → 4/6/8）**：MuJoCo 已验证 29 %→73 %（×4）。**必须在 PhysX 里重做**，因为 MuJoCo 偏乐观 → PhysX 里可能需更大 kd。
   - 核对：90 % 力矩硬上限；轮速环带宽 vs 控制周期（现 `dt=0.0025`，轮时间常数 `I/kd = 1.29 ms`，kd=8 时 ≈0.16 ms… 需重新核稳）；高速抖动/啸叫。
2. **轮速环加差动前馈**：`tau_wheel = kd·(cmd−meas) + ff·(cmd_diff/2)·side`，`ff ∈ [0,1]`。不动增益、不改带宽。
3. **改带电流/力矩内环**：最彻底，工作量与实机标定风险最高。

**共同前置**：`kd×(命令差/2)` 必须 ≥ 实机最大刮擦阻力对应力矩。按 PhysX-实机对齐结果反推，kd 至少 ×3–×4 才有余量。

### 方案 C：训练端根治（我方主战场）

| # | 改动 | 依据 |
|---|---|---|
| C1 | **命令驻留 ≥10 s 持续转**（现 1.1–3.4 s） | 塌缩 3–4 s 才发展完，当前是训练盲区（**最高优先级**） |
| C2 | **轮地摩擦 DR 上界扩到 ≥3× 标称**（现 `friction_range=[0.25,1.25]`） | 需先修 §5.4 的摩擦开关，否则无法验证 |
| C3 | **独立差动残差项**：对 `(实测轮差 − 命令轮差)` 单独加信号 | 差动是本次失效主通道，不能混在 tracking 里 |
| C4 | **稳态偏航奖励**：长时间恒定 wz 的稳态误差单独计分 | 与 C1 配套 |
| C5 | **零指令轮速惩罚**（`stand_still` 覆盖轮轴） | 修 §5.3 的 −1.2 rad/s 偏置与零指令前进 |
| C6 | **左右对称性约束**：镜像观测/动作一致性正则 + 对称初态采样 | 修 §5.3 的 83 %/49 % 不对称 |
| C7 | **后小腿净空**（`rear_calf_clearance`） | 后蹲是加重因素；我方当前非轮接触 0，需保持 |

### 方案 D：验收判据增补（防回归，必做，且要先做）

现有验收只看 tracking rmse，**完全抓不到本次失效**（r4000 在原验收里"通过"了）。

| # | 判据 | 通过条件（建议初值） |
|---|---|---|
| D0 | **跨仿真器一致性**：同一权重同一波形，PhysX vs MuJoCo | 长转偏航比值 ∈ [0.5, 2.0]；否则**先修仿真器差异再谈验收** |
| D1 | **轮差权限**：长转（≥10 s）轮差交付率 + `tau_est` 线性度 | 交付率 ≥ 60 %；`tau_est` 对 `kd×(cmd−meas)` 斜率 ∈ [1.7, 2.3] |
| D2 | **真实手柄波形回放**（R4000 120 s / 6001 帧），**双仿真器** | 偏航 ≥ 60 %；轮差交付 ≥ 60 %；非轮接触 0；轮离地 ≤ 0.06 s；max tilt ≤ 60° |
| D3 | **零指令驻停** 10 s | 轮差指令偏置 ≤ 0.05 rad/s；实测偏航漂移 ≤ 0.02 rad/s；位移 ≤ 0.05 m |
| D4 | **左右对称性** | `min(ratio(+wz), ratio(−wz)) / max(...) ≥ 0.7` |
| D5 | **长转驻留** ≥10 s 恒定 wz | 后 5 s 跟踪 ≥ 70 %（对齐报告 §六 门槛） |

D0 是本轮新发现——**没有 D0，D2 在哪个仿真器上跑都会给出相反结论**。

## 7. 建议的执行顺序

```
第 0 步（立即）  修 §5.4 摩擦开关；PhysX 侧重做 kd 单变量（×1/×2/×4/×8）→ 定 kd 目标值
第 1 步          验收加 D0/D3/D4；R4000 波形回放接入双仿真（MuJoCo 已通，PhysX 已通）
第 2 步          定位 PhysX vs MuJoCo 差 4× 的根因（接触模型/关节阻尼/力矩施加路径）
第 3 步          方案 C（C1/C2/C5/C6）进 r8 训练
第 4 步          方案 A 独立部署候选，双仿真完整矩阵 + 12 种子
第 5 步          双仿真全过 + 实机阶梯（zero-B → 0.05 rad/s 点动 → 0.1 rad/s，逐级授权）
```

**不要做的三件事**：① 只重训不改 kd/覆盖（必然复现）；② 开环加大差动增益（不可控超调）；③ 直接上实机调 Kp。

## 9. 尚未验证 / 风险

1. **PhysX 左长转窗口未覆盖**：PhysX 回放受 `episode_length_s=60` 限制只跑到 60 s（120 s 波形未跑完），左长转 [2921:3557]=58.4–71.1 s 只覆盖到 60 s。需把 `episode_length_s` 提到 ≥125 s 后重跑。

3. **`--friction` 在 PhysX 无效**（§5.4），摩擦敏感性结论待重做。
4. **Isaac Lab 同口径对照仍未跑**（AGENTS.md §5 要求双仿真器）。
5. **实机轮地摩擦/胎压/地面状态未实测**——"实机阻力"由行为反推，无独立摩擦测量。
6. **固件电流环细节未知**——`tau_est` 线性只说明本次没触发限流。
7. **方案 A 的 Kp=3 有 1 个失败种子**（驻停未过），守卫参数余量未验证。
