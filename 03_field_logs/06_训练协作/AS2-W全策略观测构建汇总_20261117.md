# AS2-W 全策略观测（Observation）构建汇总

> 目的：把 `部署参考/` 内全部策略 + 同事 chenzihao 工作站策略的**观测合同**收敛成一张可设计的地图，供软件架构同事设计"观测构建"模块。
> 范围：只汇总**输入观测**（逐维语义、来源、坐标系、缩放/裁剪/滤波、历史/状态、复位、时间语义）与**构建过程中的已知缺陷**；不含动作包装细节、不含真机授权判断。
> 编制：2026-11-17。证据以代码为准，文档为交叉核对；每条结论标注证据等级。
> 配套：本文件不含可执行代码，所有数字均引自下节"证据路径"列出的文件。
> **对外简版**：只讲"几类策略 + 每类观测长什么样 + 线速度接口"的版本见同目录 `AS2-W策略分类与观测说明_20261117.md`（给接收方做归一化/泛化用）。

## 0. 一页结论

1. **观测没有"统一规范"，只有 8 个互不兼容的族**（41/58/60/65/42/57/56/720 维）。同一个"关节位置"项在不同族里有 6 种约定（绝对值 / 减默认角 / 减默认角+4π回绕 / 减默认角+无回绕 / 轮槽强制置零 / 仅腿 12 轴），**不能按维度合并，只能按 term + 约定组合**。
2. **65 维族是当前主力**（R284/R4000/R1199/T15/armD 五份策略共用布局），但五份在**命令预处理、上一动作语义、命令增益**三处各不相同；布局相同 ≠ 可互换。
3. **观测与动作包装强耦合**：`[42:58] 上一动作` 有 4 种语义（原始输出 / ±6 裁剪 / 包装后动作 / 14→16 语义展开）。R1199 已实证用错语义会让同一权重从 98.9 N 非轮触地变为 0 N——这是全项目代价最大的观测缺陷。
4. **状态化构件只有 7 类**（命令滤波/清零、轮角解缠绕+参考记忆、相位钟、上一动作、历史环形缓冲、外部 hidden state、零命令沿检测），每类的复位触发条件都必须在 spec 里写死，不能默认。
5. **时间语义目前全项目缺失**：训练与仿真都不建模观测龄，部署侧统一用"≤50 ms 否则 disarm"兜底；500 Hz→50 Hz 的零阶保持语义没有合同。这是架构设计里最值得补的一层。

## 2. 共性基础（所有族共享的硬前提）

### 2.1 频率与时间基

| 项 | 值 | 说明 |
|---|---|---|
| 策略步长 | 20 ms / 50 Hz | 全项目一致（含 glide） |
| 物理步长 | 5 ms + decimation 4 | rolling / glide / T15 的仿真侧；策略周期一律 20 ms |
| 低层发送 | 约 2 ms 一帧（零阶保持） | 发布端高频重发同一目标；策略目标在帧间保持 |
| 观测时刻 | 控制帧开始、动作执行前 | 仿真侧定义为 `t` 时刻状态，下一帧为 `t+0.020` |
| 观测龄 | **训练/仿真不建模** | 部署侧统一 `age > 50 ms → 中止本帧并 disarm` |
| 500 Hz→50 Hz | 零阶保持 | 未写成合同；各适配器自行取最近帧 |

### 2.2 关节序（两套并存的"同名不同序"）

| 序 | 16 轴排列 | 使用方 |
|---|---|---|
| **part-major（部位优先）** | `FL_hip, FR_hip, RL_hip, RR_hip, FL_thigh, …, FL_calf, …, FL_foot, FR_foot, RL_foot, RR_foot` | cpp_deploy 全族、R41/R152/R214/R249/R270/R284/R4000/R1199、T15、armD、getup1199 |
| **leg-major（腿优先）** | `FR_hip, FR_thigh, FR_calf, FL_hip, …, RR_*, RL_*`，轮 `FR_foot, FL_foot, RR_foot, RL_foot` | mlp57（robot_lab 上游约定） |

**踩坑已实证**：T15 S1 移植曾把"部位序默认角"写进"腿序名字循环"，初态整体错位，一度误判为模型自碰撞（INDEX 2026-11-16 深夜）。**架构要求：一律按名字查表，禁止按索引套默认角。**

### 2.3 硬件映射（观测来源侧的唯一定义）

| 关节（part-major） | DDS 槽 | 状态符号 | 编码器零位 |
|---|---:|---:|---:|
| FL_hip / FR_hip / RL_hip / RR_hip | 3 / 0 / 9 / 6 | −1 | 0（未标定） |
| FL_thigh / FR_thigh / RL_thigh / RR_thigh | 4 / 1 / 10 / 7 | +1 | 0 |
| FL_calf / FR_calf / RL_calf / RR_calf | 5 / 2 / 11 / 8 | +1 | 0 |
| FL_foot / FR_foot / RL_foot / RR_foot | 13 / 12 / 15 / 14 | +1 | 0 |

- 转换式：`q_model = sign × (q_DDS − zero)`，`dq_model = sign × dq_DDS`。当前 `zero=0` 属**假设**（`r41_measured_identity_sign.md` 明示不可直接当命令 map）。
- 轮 q 是累计转角，**无固定姿态锚点**，重启/手转后基准会变。

### 2.4 坐标系与 IMU 约定

- 机体系：`x` 前、`y` 左、`z` 上；重力投影 = `R(q)ᵀ·[0,0,−1]`，站立时 `z=−1`。
- `gyro` 一律取**机体系角速度直读**（训练语义）。**已知陷阱**：交付方 MuJoCo 参考脚本把已是体系量的 `qvel[3:6]` 又旋了一次（"双旋转偏差"），T15/armD 部署侧均按训练语义直读，并有 parity 证据。
- 四元数为 **body→world、wxyz**；各适配器先按范数门 `[0.81, 1.21]` 校验并归一化。
- **IMU 安装旋转到 base_link 的旋转矩阵至今未标定**（若 IMU 非对齐安装，gravity/gyro 全族同时出错）。

## 3. 逐族观测合同

### 3.1 A 族：41 维 + 外部 hidden state（R41 / R152 / R214）

| 索引 | 维数 | 内容 | 单位 | 约定 |
|---|---:|---|---|---|
| 0:3 | 3 | 机体系速度指令 `vx, vy, wz` | m/s, rad/s | **原值**（不减 0.4）；推理前按 `command_limit` 钳位 |
| 3:6 | 3 | IMU 机体角速度 | rad/s | 直读，不缩放 |
| 6:9 | 3 | 投影重力 | 单位向量 | `Rᵀ[0,0,−1]`，不缩放 |
| 9:25 | 16 | 16 轴关节角 | rad | **绝对编码器角**：不减默认角、轮角不回绕 |
| 25:41 | 16 | 16 轴关节速度 | rad/s | 不缩放 |

- **无相位、无上一动作、无零命令标志、无轮角记忆**。
- 外部状态：R41 `state[1,835]`、R152 `[1,844]`、R214 `[1,1196]`；进入策略时**全零**，此后逐帧用上一帧 `next_state` 回灌。这是模型自带的递归/历史状态，必须与 obs 同帧、同序、同复位。
- 命令限幅：`[0.6, 0.35, 0.8]`（R41/R152/R214 的 `deploy.yaml` 相同）。
- 输出动作：12 腿位置 + 4 轮速，尺度 0.35 / 16.0，腿 PD 55/2、轮 0/2。
- 证据：`r152_controller.cpp::make_observation`、`r214_controller.cpp::make_observation`、`r41_controller.cpp::make_observation`、`models/{r41,r152,r214}/deploy.yaml`、各交付 README。

> 设计要点：这是唯一"关节角用绝对值"的族，且 hidden state 与 obs 是两个输入张量。架构上必须允许"一个策略多个输入张量 + 一个可复位状态槽"。

### 3.2 B 族：58 维 legacy MLP（recovery / stairs `.bin`）

| 索引 | 维数 | 内容 | 约定 |
|---|---:|---|---|
| 0:3 | 3 | 机体系线速度 | **recovery**：实测绘速度；**stairs**：填 0（`stairs_` 模式位强制清零） |
| 3:6 | 3 | 角速度 | 直读 |
| 6:9 | 3 | 投影重力 | `Rᵀ[0,0,−1]` |
| 9 | 1 | 进度/常量 | recovery：`clamp((t−2)/4, 0, 1)`；stairs：常量 `0.4` |
| 10:26 | 16 | 关节角 | 先**轮角按 4π 周期回绕**，再**减默认角** |
| 26:42 | 16 | 关节速度 | 直读 |
| 42:58 | 16 | 上一动作 | **±6 裁剪后的原始动作**（`result.action` 逐元素钳位后存入） |

- 腿 PD 55/2、轮 0/2；动作 ±6 → 腿 `default+0.35a`、轮 `16a`。
- 该族是"同一权重两套语义"的典型：`stairs_` 布尔位同时改 obs[0:3]、obs[9] 和激活时机。
- 证据：`cpp_deploy-as2w/src/policy.cpp`、`as2w-deploy/README.md`、`as2w-flat-rerun/README.md`。

### 3.3 C 族：60 维（R249）与 720 维历史堆叠（R270）

R249 单帧 60 维：

| 索引 | 维数 | 内容 | 约定 |
|---|---:|---|---|
| 0:3 | 3 | 命令 `vx−0.4, vy, wz` | 先按 `command_limit` 钳位，再 **0.25 s 一阶平滑** |
| 3:6 | 3 | 角速度 | 直读 |
| 6:9 | 3 | 投影重力 | `Rᵀ[0,0,−1]` |
| 9 | 1 | 常量 `0.4` | — |
| 10:26 | 16 | `q − default` | **16 轴统一减默认角；轮角不回绕**（与 65 族相反） |
| 26:42 | 16 | 关节速度 | 直读 |
| 42:58 | 16 | 上一动作 | **后处理之后的动作**（低速门把 `[2,3,6,7,10,11]` 后腿三轴缩放为 0 之后的值） |
| 58:60 | 2 | `sin/cos(2πt/0.62)` | 相位钟按 `fmod` 累加 |

- 低速姿态门（R249 专用）：`hypot(vx,vy) ≤ 0.20` 时后腿 hip/thigh/calf 动作缩放 0；这是**动作侧**门，但通过"上一动作"回灌进观测。
- R270：同一 60 维帧为"当前帧"，其后**追加 12 段历史**，每段取过去第 2,4,…,24 帧的 `[3:58]`（55 维，去掉命令与相位）
  → `60 + 12×55 = 720`。命令平滑 1/6 s、零命令清除阈值 0.005；低速姿态门关闭。
- 证据：`r249_controller.cpp`、`r270_controller.cpp`、`models/r249/deploy.yaml`、`models/r270/deploy.yaml`、`Rob2Nav-r249-source/.../README.md`。

> 设计要点：60 族与 65 族对"轮角"的约定**相反**（不减/不回绕 vs 减默认+回绕）。这是当前最容易被"共用代码"破坏的一处。

### 3.4 D 族：65 维（主力族，五份策略）

统一布局：

| 索引 | 维数 | 内容 | 单位 | 族内变体 |
|---|---:|---|---|---|
| 0:3 | 3 | 命令 `vx−0.4, vy, wz` | m/s, rad/s | **T15：再乘命令增益 8**；R284/R4000/R1199：每帧 0.12 一阶滤波 + 释放后 <0.005 清零；armD/T15：**原值直入，不滤波** |
| 3:6 | 3 | 机体角速度 | rad/s | 全部直读 |
| 6:9 | 3 | 投影重力 | 单位向量 | 全部 `Rᵀ[0,0,−1]` |
| 9 | 1 | 常量 `0.4` | — | T15 也写 `0.4`（**不乘增益 8**，parity 已验） |
| 10:22 | 12 | 腿角 `q − default(0, 0.8, −1.6)` | rad | 全部一致 |
| 22:26 | 4 | 轮角 | rad | **回绕到 ±2π（4π 周期）**；T15 用 double 再转 float（float32 大角度有 4e-6 舍入） |
| 26:42 | 16 | 关节速度 | rad/s | 不缩放 |
| 42:58 | 16 | 上一动作 | 动作单位 | **4 种语义**，见 §4 P1 |
| 58:60 | 2 | 相位 `sin/cos(2π·tick·0.02/0.62)` | — | 全部 tick 计数；常数用 double（float32 长回合漂移） |
| 60:64 | 4 | 零速轮角漂移 `Δ/0.20`，钳 ±3 | rad/0.2 | 仅在零命令帧非零；参考在**进入零命令帧**锁存 |
| 64 | 1 | 零命令标志 | 0/1 | 见 P2：判定用"滤波后"还是"原始"命令，两派不同 |

族内三处关键差异汇总：

| 策略 | 命令预处理 | 命令增益 | 上一动作语义 | 零命令判定依据 |
|---|---|---:|---|---|
| R284-500 | 0.12 滤波 + 0.005 清零；平面模长 ≤0.10、偏航 ≤±0.30 | 1 | **原始输出 ±6 裁剪**（无补偿/滤波类包装） | 滤波后命令三轴严格为 0 |
| R4000 | 同 R284，平面钳位改按 `deploy.yaml` 包络 | 1 | **包装后动作**（5 Hz 腿滤波 + 0.9 rad/s slew + 站姿补偿 + 轮保持之后） | 同上 |
| R1199 | 同 R284（平面 0.10 / 偏航 0.30） | 1 | **包装后动作**（站姿补偿 + 轮保持叠加之后；训练合同分支为叠加而非替换） | 同上 |
| T15 | **不滤波**；包络 0.20 / 0.12 | **8** | **14 维有效动作的 16 通道语义展开**：腿原值 + `K/16·(tanh(u_c)+tanh(u_y)·side)` | 原始命令严格全零 |
| armD | 不滤波；包络 0.25 / 0.05（仅右转且需伴随前进） | 1 | **未裁剪的原始网络输出** | 原始命令严格全零 |

- 动作尺度：腿 `default + 0.35a`；轮 `16a`（T15 例外：轮通道被 `LayeredWheelController` 覆写）。
- 证据：`r284_observations.hpp`、`r4000_observations.hpp`、`r1199_controller.cpp`、`t15_controller.{hpp,cpp}`、`armd_controller.cpp`、`models/{r284,r4000,r1199,t15,armd}/deploy.yaml`、`as2w_layered_rolling_test/.../C3_OBSERVATION_CONTRACT.md`、`Rob2Nav-deploy-as2w/README.md`。

### 3.5 E 族：42 维（getup1199 起身）

| 索引 | 维数 | 内容 | 约定 |
|---|---:|---|---|
| 0:3 | 3 | 角速度 | 直读 |
| 3:6 | 3 | 投影重力 | `Rᵀ[0,0,−1]`（upright 时 z=−1） |
| 6:18 | 12 | `q − default` | **仅 12 腿轴**；轮不在观测内 |

- **无命令、无相位、无轮项**；轮由策略外的"位置保持"接管（锁存进入策略时的轮角）。

- 高度/直立/轮静等门限是**部署侧估计器**（腿 FK 高度、轮速安静度），**不进观测**，只做门。

### 3.6 F 族：57 维（mlp57，robot_lab / chenzihao 服务器产出）

逐维合同（`runtime/observations.csv` 57 行，逐行有单位/坐标系/缩放/噪声）：

| 索引 | 维数 | 内容 | 处理（**先 clip ±100，再乘 scale**） |
|---|---:|---|---|
| 0:3 | 3 | `base_ang_vel` 机体角速度 | ×0.25 |
| 3:6 | 3 | 投影重力 | ×1.0 |
| 6:9 | 3 | 命令 `vx, vy, wz`（原值，无 0.4 偏移） | ×1.0 |
| 9:25 | 16 | `q − Q0`（Q0 = 0/0.65/−1.3） | ×1.0；**4 个轮槽强制置 0**（"constant zero"，不得填轮角） |
| 25:41 | 16 | `dq − 0` | ×0.05 |
| 41:57 | 16 | 上一动作 | ×1.0；**raw，未裁剪**；复位清零 |

- 顺序为 **leg-major**（FR/FL/RR/RL），与 cpp_deploy 全族相反。
- 无相位、无历史、无零命令标志、无 hidden state；`previous_action` 保存的是"模型原始输出"（即使物理目标被 ±100 裁剪也保存 raw）。
- 训练噪声（部署关闭）：gyro ±0.2 rad/s、重力 ±0.05、关节角 ±0.01 rad、关节速 ±1.5 rad/s。
- 证据：`as2w_mlp57_flat_model2700_v1_20261112/runtime/{observations.csv,reference.py,effective_runtime.yaml,entry_exit.md}`、`model/as2w_contract.json`。

### 3.7 G 族：双足滑行 56 / 560 / 72（chenzihao 工作站）

> 证据等级：**仅二手报告**（2026-11-16 只读勘察），服务器源码不在本项目内。

| 观测 | 维数 | 内容 |
|---|---:|---|
| `policy` | 56（GPU0 版 53） | 角速度 ×0.25 `[0:3]`；重力投影 `[3:6]`；**指令 vx/wz + 参考路径/航向** `[6:9]`；实测腿角相对参考的误差 `[9:21]`；关节速度 ×0.1 `[21:37]`；上一步动作 `[37:53]`；编码器路径误差、相对航向误差、保持标志 `[53:56]`（GPU0 版无此三项） |

## 4. 已验证的坑（按设计影响排序）

### P1 上一动作语义（最高风险）

同一槽位 `[42:58]` 在项目内有 4 种写法：

| 语义 | 使用方 | 说明 |
|---|---|---|
| 模型原始输出（raw，未裁剪） | armD、mlp57 | armD 合同明示 "RAW, unclipped" |
| 裁剪后动作（±6） | B 族 legacy、R284 | 与训练 `action_manager.action` 一致（C3 合同写作"裁剪前"，R284 实现为裁剪后，需训练方确认） |
| 包装后动作（含补偿/滤波/门控） | R4000（5 Hz 滤波+slew+补偿）、R1199（补偿+轮保持）、getup1199、R249（低速门之后） | 训练侧 `current` 是包装后的归一化动作 |
| 14→16 语义展开 | T15 | 轮通道 = `K/16·(tanh(u_c)+tanh(u_y)·side)` |

**实证代价**：R1199 旧复演器把 ONNX 原始输出当上一动作，`[42:58]` 与训练方最大相差 **6.328**（旧值可达 −6）；同一权重同一初态，seed 202 从"1.44 s 起 RR_calf 触地、峰值 98.9 N"变为"0 N 非轮接触、0.305 m/s 跟踪通过"。档案：`R1199_real_robot_feedback_20261112/docs/previous_simulation_differences.md`。

**设计含义**：观测构建器必须能读"动作包装器的输出"，并与动作包装**同一 tick 图**内闭环；prev-action 的语义必须是 spec 字段，而不是默认值。

### P2 零命令判定：原始命令 vs 滤波后命令

- R284/R4000/R1199：命令经 0.12 滤波 + 释放后 <0.005 才清零；零命令标志与轮角参考由**滤波后**的 `frame[0]==−0.4 && frame[1]==0 && frame[2]==0` 判定。
- armD/T15：由**原始**命令三轴严格为 0 判定。
- 后果：同一摇杆动作在两派里"进入零命令"的时刻差数帧到数十帧，轮角参考锁存点、`zero_flag`、观测历史全部错位。
- **设计含义**：`zero_source ∈ {raw_command, filtered_command}` 必须显式。

### P3 轮角：解缠绕 → 回绕 → 精度

- 编码器以 2π 周期返回时，必须先展开连续角度，再按 4π 周期映射到 `[−2π, 2π)`。
- **float32 不够**：T15 parity 修正项显示大轮角下 float32 wrap 有约 `4e-6` 舍入，改 double 后误差降到 1e-7 量级（r4000 同款先例）。
- 轮角参考只在"进入零命令"帧锁存，离开零命令**不更新**；`reset` 清空。
- **设计含义**：轮角状态（unwrap + reference）是独立构件，精度类型必须 pin 为 double。

### P4 相位钟

- `tick` 计数 → `2π·tick·0.02/0.62`，`sin/cos` 各一维；`reset` 归零，不随命令清零。
- 常数（π、周期）必须 double；float32 在 ~750 帧后已出现 1e-6 级漂移（armD 注释）。
- R270 的历史帧里**包含相位**（取 `[3:58]`），即历史里 12 个相位值同时存在。
- **设计含义**：相位是"回合内状态"，必须与 FSM 的回合起点绑定，而不是进程启动时间。

### P5 关节序与默认角（P5a/P5b）

- P5a：两套关节序（§2.2）。任何"按索引套默认角/按索引取轮槽"的写法都会在跨族复用时出错。
- P5b：默认角本身也不统一——cpp_deploy 全族 `(0, 0.8, −1.6)`；mlp57 `(0, 0.65, −1.3)`；glide 有"实测姿态"与"承重 PD 目标"两套（明示不能拿实测当 PD 零位）；T15 出现"两套参考并存"二义。

### P6 轮角项的两套相反约定

- 60 族（R249/R270）：`q − default`，轮角**不回绕**（等价于原始累计角）。
- 65 族：腿减默认角、轮**回绕 ±2π**。
- 41 族：**全部绝对角**，不减不回绕。
- **设计含义**：`wheel_q_convention ∈ {absolute, rel_unwrapped, wrapped_4pi}`，且必须与训练方逐策略确认；R249/R270 的"不回绕"是否为训练时的真实语义，目前**没有文档确认**（列入待确认问题）。

### P7 命令偏移 `−0.4` 与常量槽 `0.4`

- 60/65 族的 0:3 是 `(vx−0.4, vy, wz)`，第 9 维恒 `0.4`。这是历史遗留（早期用 0.4 m/s 表示前进档），现在纯属"给模型一个常量偏置"。
- 41 族**没有**这个偏移（0:3 是原值，第 9 维不存在）。
- mlp57/glide 也没有偏移。
- T15 的 8 倍增益只乘 0:3，**不乘**第 9 维——若实现时"统一乘增益"会直接错维。
- **设计含义**：offset/scale 必须逐 term 配置，禁止"整族乘一个系数"。

### P8 观测噪声与历史掩码（训练态）

- mlp57：gyro ±0.2 rad/s、重力 ±0.05、q ±0.01、dq ±1.5（逐维清单）。
- glide：训练开、评估关；历史旧帧的指令/参考槽位清零（`mask`）。
- 部署侧必须**显式关闭**噪声，且要把"关噪声"写成可断言项（避免把训练噪声带进真机）。
- **设计含义**：noise 是 spec 的一部分（`training_only: true`），运行时必须是 hard-off。

### P9 时间/龄/丢包

- 训练与两个仿真器都不建模观测龄；T15 交付明确"实机传感器缺测/时间戳跳变语义未定义"，并实测了 NaN/Inf 行为（NaN gyro 不传播、Inf 被钳、NaN 命令崩溃）。
- 部署侧现有做法：`age>50 ms`、非有限值、四元数范数越界 → 本帧不推理并 disarm。
- **设计含义**：观测构建器应返回 `(obs, validity, reason)`；不能静默 zero-fill（会把故障变成"合法但错误"的观测）。

### P10 历史与外部状态

| 形态 | 使用方 | 复位 |
|---|---|---|
| 1 帧上一动作 | 几乎所有族 | arm/模式进入 |
| 12 帧 × 55 维 | R270 | arm/stop |
| 10 帧 × 56（带掩码） | glide history | episode reset |
| 外部 hidden state 向量 | R41(835) / R152(844) / R214(1196) | 进入时全零，逐帧回灌 `next_state` |
| CENet 隐变量 | glide 部署 | 由 history 在线重算，同一 history 给同一上下文（推断路径确定性） |

**设计含义**：需要一个通用"历史环形缓冲 + 掩码 + 顺序（旧→新/新→旧）"构件，以及一个"外部状态槽"构件；两者都要有 reset 钩子。

### P11 形状/命名/外部数据

- ONNX 输入名不统一：`obs`（A/B/C/D/E 族）vs `observation`（mlp57）vs `obs`+`state` 双输入（A 族）；T15 输出名 `action`、mlp57 `raw_action_mean`。
- T15 是工程内首个**外部数据 ONNX**（`.onnx` + `.onnx.data` 必须原名成对，加载时双 SHA 校验）；曾因 handoff 文档 SHA 末位笔误触发校验拒绝（设计有效）。
- **设计含义**：spec 需 pin `input_names/shape/dtype/sidecar`；加载期校验，运行期不再猜。

### P12 观测依赖动作包装的开关（版本耦合）

- R1199 的 `park_odometry / park_settle_joints / park_continuous_bias / park_straight_bias` 是**动作包装**开关，但通过"上一动作"影响下一帧观测；实机与训练相反时出现停走姿态跳步。
- 项目硬规则：任何运行时开关/包装/增益与训练 `actual_runtime_flags` 不一致即**新版本**。
- **设计含义**：观测 spec 的版本号必须包含"所依赖的动作包装版本"，不能只标自身。

### P13 逐项 clip 的位置

- mlp57：每个 term **先 clip ±100 再乘 scale**（顺序写死在清单里）。
- 其他族：无 per-term clip；clip 出现在动作侧（±6）或部署守卫（腿步进/力矩）。
- **设计含义**：clip 是 term 级操作，且顺序（clip→scale vs scale→clip）必须可配。

### P14 缩放的族间不一致

- glide：角速度 ×0.25、关节速 ×0.1；mlp57：角速度 ×0.25、关节速 ×0.05；其余族：×1.0。
- **设计含义**：不存在"全局归一化器"；每个 term 自带 scale，且必须来自训练侧实测值（不是拍脑袋）。

### P15 命令包络与观测的关系

命令既是控制量又是观测项，包络/限幅位置不同会改变观测：

| 策略 | 包络（vx / vy / wz） | 限幅发生处 |
|---|---|---|
| R41/R152/R214 | 0.6 / 0.35 / 0.8 | 推理前对 obs[0:3] 钳位 |
| R284/R1199 | 平面 0.10 / 偏航 ±0.30 | 观测构建内部（滤波前） |
| R4000 | `deploy.yaml` vx 0.4 / wz 0.1 | 观测构建内部：平面模长钳位 = `vx_limit`(0.4)，偏航仍钳 ±0.30（0.1 包络下不生效） |
| R249/R270 | 0.15 / 0.15 / 0.5 | 观测构建内部（平滑前） |
| T15 | 0.20 / — / 0.12 | 适配器入口 gate（不改观测值） |
| armD | 0.25 / — / 0.05（仅右转+需前进） | 适配器入口 gate |
| mlp57 | ±1（训练采样域） | 无（部署侧只做拒绝） |

**设计含义**：包络必须在"观测构建之前"统一施加并留痕，否则同一策略的 obs 会随外层 CLI 参数漂移。

## 5. 面向架构的观测构建设计建议

### 5.1 分层（建议）

```
DSH/RobotStateSource (500 Hz, 带时间戳)
        │  RobotStateSnapshot（同一 tick：imu, q, dq, tau, mode, remote）
        ▼
JointCodec（名字→槽位/符号/零位/轮解缠绕）      ── 硬件相关，唯一一处
ImuProjector（quat→gravity；gyro→body）
        ▼
CommandPipeline（钳位→包络→滤波→清零→zero_flag→有效性）
        ▼
ObservationBuilder（按 policy spec 组装；含 7 类状态构件）
        │  (obs, validity, reason)
        ▼
PolicyRuntime（ONNX 多输入）──► ActionWrapper（包装/门控/轮控律）
        │                                   │
        └──────── prev_action ◄─────────────┘   ← 必须回灌到下一帧观测
```

**关键结论：观测构建器与动作包装器是同一个 tick 图里的两个节点，不能各自独立实现。** P1 的代价就是两边各自实现 prev_action 造成的。

### 5.2 需要抽象出的构件（7 个带状态 + 1 个无状态）

| 构件 | 职责 | 复位触发 | 典型参数 |
|---|---|---|---|
| `JointCodec` | 名称→槽位/符号/零位；轮角解缠绕 | 进程启动 | `map`, `unwrap`, `wrap_period` |
| `ImuProjector` | quat→gravity（`Rᵀ[0,0,−1]`）；gyro 取体系 | 无状态 | `gravity_convention`, `imu_mount_R` |
| `CommandPipeline` | 钳位、平面/偏航包络、一阶滤波、清零、zero_flag | arm / 模式进入 | `alpha`, `snap_eps`, `zero_source` |
| `PrevActionStore` | 保存"上一动作"，语义可选 | arm / 模式进入 | `kind ∈ {raw, clipped, wrapped, semantic_expand}`, `clip` |
| `WheelZeroMemory` | 零命令帧锁存轮角参考，输出 `Δ/scale` clip | arm / stop（离开零命令不重置，仅下次进入时重锁存） | `trigger`, `scale`, `clip`, `precision=double` |
| `PhaseClock` | tick→sin/cos | arm / 回合开始 | `period`, `dt`, `precision=double` |
| `HistoryRing` | 多帧缓存、顺序、掩码、抽取步长 | arm / episode reset | `len`, `order`, `mask`, `stride`, `frame_slice` |
| `HiddenStateStore` | 外部 state 张量的零初始化与回灌 | 模式进入 | `size`, `dtype` |

```yaml
gates:
  sensor_age_max_s: 0.05
  quat_norm2: [0.81, 1.21]
  finite: reject
noise: {enabled: false}          # 训练态字段，部署 hard-off
```

一份 spec = 一个 `(policy_id, revision)`；**任何 term/约定/包装/增益变化 = 新 revision**，禁止"就地调参"。

### 5.4 验收清单（建议直接做成 CI 用例）

1. **形状/名字/dtype/sidecar** 加载期 pin，不符即拒。
2. **逐维 golden fixture**：每策略至少一段"传感器级→obs→action→目标"的逐帧带（T15 教训：只交 obs 级不够，要传感器级）。
3. **跨实现 parity**：Python 参考 vs C++，逐帧 max_abs_err；报告"最差维/最差帧/第一处分歧"，不只看通过率。
4. **复位用例**：arm/stop/re-arm 后 prev_action、相位、轮角参考、滤波状态、hidden state 全部归零/重锁存。
5. **零命令边界**：进入/离开零命令各 1 帧的 `zero_flag`、`[60:64]`、prev_action 断言（两派语义各测一遍）。
6. **轮角边界**：±2π、±4π、大累计角（>100 rad）下的解缠绕与回绕；double 精度断言。
7. **相位漂移**：10 000 tick 后与解析值差 <1e-6。
8. **异常输入**：NaN/Inf（各字段）、四元数范数越界、数据龄超限 → 必须 `validity=false` 且给出 reason。
9. **历史/掩码**：顺序、掩码索引、抽取步长逐位断言。
10. **噪声关闭**：部署构建里 noise 必须 hard-off（可 grep/断言）。
11. **关节序**：按名字构造的期望表与 spec 顺序逐项比对（防 P5a）。
12. **观测留痕**：运行时按需 dump 每个 term 的原始值/变换后值 + spec 哈希，便于现场复盘（当前现场只能看 debug_policy 的行，缺 term 级溯源）。

### 5.5 与现有代码的关系（迁移建议）

- 现有实现每个策略一个 `*_observations.hpp` / `make_observation`，**逻辑正确但重复**：65 族的轮角记忆、相位、prev_action 被复制了 5 份；轮角 wrap 与相位的 double 精度修正（大角度 4e-6 舍入、长回合相位漂移）是**各副本在 parity 中逐个发现的**，先修 r4000、再修 T15——没有共用件就意味着每加一份策略都要重新踩一遍。
- 建议先抽 **D 族共用内核**（65 维），用 spec 参数化三处差异（命令预处理/增益/prev 语义），再逐步收编 C/E 族；A 族因"hidden state + 绝对角"差异大，单独一个实现。
- 迁移期间保留"旧实现 + 新实现"双跑对拍（同一帧输入，逐维比较），确认 0 差异后再切换。
