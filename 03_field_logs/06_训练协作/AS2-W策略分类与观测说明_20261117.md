## 1. 一共几类

按**观测向量结构**分，共 **7 类**；按**形态**可归为 3 组：

| 组 | 形态 | 类 | 策略 |
|---|---|---|---|
| 单帧定长 | 一帧固定维度，无历史、无状态 | 2、3、4、5、6 | legacy `.bin`、R249、R284/R4000/R1199/T15/armD、getup1199、mlp57 |
| 单帧 + 外部状态 | 观测之外还有模型自带状态张量 | 1 | R41 / R152 / R214 |
| 多帧历史 | 当前帧 + 历史堆叠 | 3b、7 | R270（720）、双足滑行（560） |

| 类 | 名称 | 维数 | 策略 | 状态 |
|---|---|---:|---|---|
| 1 | 爬楼/全向 + 外部 hidden state | **41** + state（835 / 844 / 1196） | R41、R152、R214 | 有外部状态张量，逐帧回灌 |
| 2 | legacy MLP 平地/爬楼 | **58** | recovery-r09/r12/r13、stairs-r14/r17 | 无 |
| 3 | 滚动单帧 | **60** | R249 | 无 |
| 3b | 滚动 + 12 帧历史 | **720** = 60 + 12×55 | R270 | 无 |
| 4 | 滚动主力族 | **65** | R284、R4000、R1199、T15、armD | 无 |
| 5 | 起身（仅腿） | **42** | getup1199 | 无 |
| 6 | robot_lab 平地 | **57** | mlp57（model2700） | 无 |
| 7 | 双足滑行 | **56** + history 560（+ critic 72） | chenzihao 工作站 glide v3 / 在线九课程 | CENet 上下文（网络内部） |

**频率全部是 50 Hz（20 ms 一帧）**，无例外。

## 2. 每类观测逐段

约定：`cmd` = 机体系速度指令 `vx, vy, wz`（m/s, m/s, rad/s）；`gyro` = 机体系角速度；`gravity` = `Rᵀ[0,0,−1]`（站立 z=−1）；`q` = 关节角；`dq` = 关节角速度。关节顺序除类 6 外均为 part-major（`FL/FR/RL/RR × hip/thigh/calf/foot`）。

### 类 1：41 维 + 外部状态（R41 / R152 / R214）

| 段 | 维 | 内容 | 处理 |
|---|---:|---|---|
| 0:3 | 3 | `cmd` | **原值**，推理前按 `[0.6, 0.35, 0.8]` 钳位 |
| 3:6 | 3 | `gyro` | 不缩放 |
| 6:9 | 3 | `gravity` | 不缩放 |
| 9:25 | 16 | `q` | **绝对编码器角**：不减默认角、轮角不回绕 |
| 25:41 | 16 | `dq` | 不缩放 |
| 附加输入 | 835 / 844 / 1196 | 模型自带状态 | 进入策略时全零，逐帧用上一帧 `next_state` 回灌 |

无上一动作、无相位、无零命令标志。

### 类 2：58 维（legacy recovery / stairs）

| 段 | 维 | 内容 | 处理 |
|---|---:|---|---|
| 0:3 | 3 | 机体系线速度 | recovery：实测；**stairs：填 0** |
| 3:6 | 3 | `gyro` | 不缩放 |
| 6:9 | 3 | `gravity` | 不缩放 |
| 9 | 1 | 进度 / 常量 | recovery：`clamp((t−2)/4,0,1)`；stairs：`0.4` |
| 10:26 | 16 | `q` | 轮角先按 **4π 周期回绕**，再减默认角 |
| 26:42 | 16 | `dq` | 不缩放 |
| 42:58 | 16 | 上一动作 | **±6 裁剪后的原始动作** |

### 类 3：60 维（R249）

| 段 | 维 | 内容 | 处理 |
|---|---:|---|---|
| 0:3 | 3 | `cmd − (0.4,0,0)` | 钳位后 **0.25 s 一阶平滑** |
| 3:6 | 3 | `gyro` | 不缩放 |
| 6:9 | 3 | `gravity` | 不缩放 |
| 9 | 1 | 常量 `0.4` | — |
| 10:26 | 16 | `q − default` | **16 轴统一减默认角；轮角不回绕** |
| 26:42 | 16 | `dq` | 不缩放 |
| 42:58 | 16 | 上一动作 | **后处理之后**的动作（含低速门） |
| 58:60 | 2 | `sin/cos(2πt/0.62)` | 相位钟 |

### 类 3b：720 维（R270）

= 类 3 的当前帧 60 维 + **过去第 2,4,…,24 帧各取 `[3:58]`（55 维）**，`60 + 12×55 = 720`；历史里**不含命令、不含相位**（相位在每段历史里各有一个）。命令平滑 1/6 s。

### 类 4：65 维（R284 / R4000 / R1199 / T15 / armD）

| 段 | 维 | 内容 | 处理 / 族内差异 |
|---|---:|---|---|
| 0:3 | 3 | `cmd − (0.4,0,0)` | R284/R4000/R1199：0.12 滤波 + 松杆 <0.005 清零；**T15 乘命令增益 8**；armD/T15 不滤波 |
| 3:6 | 3 | `gyro` | 不缩放 |
| 6:9 | 3 | `gravity` | 不缩放 |
| 9 | 1 | 常量 `0.4` | T15 也不乘 8 |
| 10:22 | 12 | 腿 `q − default(0, 0.8, −1.6)` | 一致 |
| 22:26 | 4 | 轮角 | **回绕到 ±2π（4π 周期）** |
| 26:42 | 16 | `dq` | 不缩放 |
| 42:58 | 16 | 上一动作 | **四种语义之一**：raw / ±6 裁剪 / 包装后 / 14→16 语义展开（见 §4） |
| 58:60 | 2 | 相位 `sin/cos` | 0.62 s |
| 60:64 | 4 | 零速轮角漂移 | `(Δ轮角/0.20)` 钳 ±3，仅零命令帧非零 |
| 64 | 1 | 零命令标志 | 0/1 |

> 五份策略布局相同，但**不可互换**：命令预处理、命令增益、上一动作语义三处不同（见 §4）。

### 类 5：42 维（getup1199 起身）

| 段 | 维 | 内容 | 处理 |
|---|---:|---|---|
| 0:3 | 3 | `gyro` | 不缩放 |
| 3:6 | 3 | `gravity` | 不缩放 |
| 6:18 | 12 | 腿 `q − default` | 仅 12 腿轴，无轮 |
| 18:30 | 12 | 腿 `dq` | 不缩放 |
| 30:42 | 12 | 上一动作 | 包装后的归一化动作 |

无命令、无相位、无轮项（轮由策略外位置保持接管）。

### 类 6：57 维（mlp57）

| 段 | 维 | 内容 | 处理（**先 clip ±100 再乘 scale**） |
|---|---:|---|---|
| 0:3 | 3 | 角速度 | ×0.25 |
| 3:6 | 3 | `gravity` | ×1.0 |
| 6:9 | 3 | `cmd` | ×1.0（无 0.4 偏移） |
| 9:25 | 16 | `q − Q0`（Q0 = 0/0.65/−1.3） | ×1.0；**4 个轮槽恒 0** |
| 25:41 | 16 | `dq` | ×0.05 |
| 41:57 | 16 | 上一动作 | ×1.0；raw 未裁剪 |

**关节顺序为 leg-major**（`FR, FL, RR, RL`），与其他类相反。

### 类 7：56 维 + history 560（双足滑行）

| 段 | 维 | 内容 |
|---|---:|---|
| 0:3 | 3 | 角速度 ×0.25 |
| 3:6 | 3 | `gravity` |
| 6:9 | 3 | 指令 vx/wz + 参考路径/航向 |
| 9:21 | 12 | 腿角相对参考的误差 |
| 21:37 | 16 | 关节速度 ×0.1 |
| 37:53 | 16 | 上一步动作 |
| 53:56 | 3 | 路径误差、航向误差、保持标志 |
| history | 560 = 56×10 | 最近 10 帧，**旧→新**；旧帧的 `{6,7,8,53,54,55}` 清零 |
| critic | 72 | 仅训练用（含真实本体速度等特权量），部署不需要 |

部署时需由 history 在线重算 CENet 的 35 维上下文（速度 3 + latent 32），与 56 维拼成 91 维送 Actor。

## 3. 线速度接入接口（**必须保留**）

### 3.1 现状

| 类 | 机体系线速度在哪 |
|---|---|
| 1（41） | 无（不用实测线速度） |
| 2（58） | **`[0:3]`，唯一把实测线速度当观测输入的类**（stairs 模式置 0） |
| 3 / 3b / 4 / 5 / 6 | 无 |
| 7（56） | policy 观测里没有；仅训练 critic 用真实本体速度（特权量） |

也就是说：**当前 65 维主力族（类 4）根本没有线速度输入槽**。如果后续策略要用实测/估计线速度，必须从接口层面预留，不能临时塞进命令槽。

### 3.2 建议接口（只定物理语义，不定归一化）

| 字段 | 类型 | 说明 |
|---|---|---|
| `base_lin_vel_body[3]` | float32 | 机体系线速度，单位 m/s，`x` 前 / `y` 左 / `z` 上，**实测或估计值**（不是命令） |
| `base_lin_vel_valid` | bool | 本帧是否有效；无效时 `base_lin_vel_body` 填 0 且 `valid=false` |
| `base_lin_vel_stamp` | uint64 ns | 该速度量的采样时刻（不是发布时刻），供外部做龄检查 |
| `base_lin_vel_source` | enum | `none / estimator / wheel_odometry / sim_truth`，写进运行日志即可，不必进 obs |

接入规则：

1. **独立槽位**：在类 4/5/6 等布局**末尾追加 4 维**（3 速度 + 1 有效位）作为预留段；不用时全零且 `valid=false`。**新增即新 revision**，不得悄悄改现有索引。
2. **不得复用命令槽**：`cmd.vx/vy` 是"期望"，线速度是"实际"，语义相反；本项目已有教训（R1199 用 `vx−0.4` 反推物理命令）。
3. **不得用 IMU 加速度积分**：全项目没有这么做的策略；噪声/漂移不可接受。来源优先级：外部状态估计器 > 轮里程计差分 > 仿真真值（仅仿真）。
4. **无效语义要一致**：`valid=false` 时策略侧必须有明确缺省行为（填零 / 保持上一帧 / 触发降级），由该策略合同写死，禁止静默 zero-fill。
5. **归一化留给接收方**：接口只承诺"物理量 + 单位 + 坐标系 + 有效性 + 时间戳"；scale/clip/统计量按 term 单独配置（现有类 2 是 ×1.0 不缩放，仅作参考，不是规定）。
6. **延迟**：估计器输出通常滞后 1–3 个控制帧，需在 spec 里记录并单独扫参，不能与 IMU/关节同刻假设。

## 4. 需要特别注意的三处差异（会影响你们的归一化/泛化设计）

1. **同一 term 多种约定**：关节位置有 6 种（绝对角 / 减默认角 / 减默认+4π / 减默认+不回绕 / 轮槽置零 / 仅 12 腿轴）；轮角 3 种。做统一归一化前必须先按类拆开。
2. **上一动作语义有 4 种**：raw（armD、mlp57）/ ±6 裁剪（类 2、R284）/ 包装后（R4000、R1199、类 3/5）/ 14→16 语义展开（T15）。用错会直接改变闭环结果（有实测证据）。
3. **命令预处理不统一**：`−0.4` 偏移只在类 3/4；T15 额外 ×8；滤波（0.12 / 0.25 s / 1/6 s）与不滤波并存。归一化时不要把"命令"当成同一种量。

---

## 5. 交给你们决定的清单

1. **归一化**：每 term 的 scale / clip / 统计量来源（训练集统计 or 物理量纲），是否跨类共享；顺序（clip→scale 还是 scale→clip）。
2. **泛化方式**：统一一套 layout 加 padding，还是每类一份 spec；维度不一致时如何补齐（补零 / 掩码 / 分模型）。
3. **线速度**：是否全类启用 §3 接口；估计器选型、延迟预算、无效时的缺省行为。
4. **缺测/异常**：NaN/Inf、观测龄超限、四元数越界时的统一语义（当前部署侧是"本帧不推理 +  disarm"）。
5. **训练/部署差异**：观测噪声、history 掩码、数据龄在训练侧是否要建模（当前基本没建模）。
6. **版本**：spec 哈希 + 依赖的动作包装版本；任何 term/约定变化必须升 revision。
