# AS2-W 实机数据用于 Isaac Lab / MuJoCo 动力学校验

**版本**：2026-11-14 ｜ **数据**：4 个真机会话 + 20 个对齐 clip ｜ **对象**：AS2-W 16 轴（12 腿 + 4 轮）

这份文档回答：**手里这些实机 log，哪些能用来判断仿真里的动力学建模是否正常，怎么用，看到什么算“像/不像”。**
包内所有 clip 都是 500 Hz 命令 + 500 Hz 状态（factory 为 100 Hz），已按 tick 对齐，可直接喂给仿真器。

---

## 0. 先看结论

1. **最有价值的是“静态保持 + 阶跃 + 制动 + 蹲下”四类**：它们有明确的激励和可比较的稳态/瞬态，受策略闭环影响小。
2. **行走数据不是纯动力学测试**：它是“策略 + 动力学 + 接触”的闭环结果。适合做**同策略闭环复现**或**短时开环发散对比**，不适合单独拿来拟合质量/摩擦。
3. **静态 T2 保持的实测基线**（本包 2026-11-12/13 会话）：pitch 均值约 **−6.0°～−6.5°**，后小腿误差约 **0.30 rad**、`tau_est` 约 **16–17 Nm**；2026-11-10 的早期会话为 **−4.7°～−5.5°**、约 14.5 Nm。**跨会话有约 1°/2 Nm 的差异**，不要只拿一个 clip 调参。
4. **原厂站姿**（`factory_stand`）是 T1 参考：pitch **+0.33°**，后小腿 `tau_est` 仅 5–7 Nm。它没有 LowCmd，只能做姿态/力矩参考，不能做开环 replay。
5. **`tau_est` 不是关节力矩真值**，是驱动器估计；仿真里应对比 `actuator_force` 的**量级/符号/趋势**，不要追求逐点相等。
6. **没有基座线速度、基座高度、足端接触力**。这三项是当前数据最大的盲区；静态/蹲下 clip 可以假设基座速度≈0，行走 clip 不行。
7. **轮子是速度模式**：`cmd_q=0`、`cmd_kp=0`、`cmd_dq` 才是目标，`cmd_kd=2`。腿是位置模式 `cmd_q/kp/kd`。
8. 先用**开环 1–3 s** 比较，再放长到 10–30 s；闭环行走的误差会累积，不能拿 120 s 末端误差判断动力学好坏。

## 3. 六类测试的具体做法

### 3.1 静态重力 / CoM / 关节刚度

**用**：`220051_fixedstand_hold`、`112630_fixedstand_hold`、`114335_fixedstand_hold`、`factory_stand`、`220051_prone_passive`。

**做法**：

1. 取 clip 第一帧 `st_q`、`quat` 作为仿真初态；基座高度用几何/接触估计（或从 0.30–0.35 m 附近落下 0.5 s 再重置，保证四轮/腿接触）。
2. 以 500 Hz 逐帧施加 `cmd_q/kp/kd`（轮 `cmd_dq/kd`），跑 3–5 s。
3. 取最后 1 s 的稳态，比较逐轴 `q`、`tau`、pitch。

**实测基线**（后 1 s 中位数，模型坐标）：

| 量 | 2026-11-12/13 会话 | 2026-11-10 早期会话 |
|---|---:|---:|
| pitch | −6.0°～−6.5°（均值） | −4.7°～−5.5° |
| 前/后大腿 | 0.70–0.75 | 0.71–0.75 |
| 前小腿 | −1.72～−1.74 | −1.72～−1.73 |
| 后小腿 | −1.90～−1.91 | −1.86～−1.87 |
| 后小腿 `tau_est` | 16–17 Nm | 14.5 Nm |
| 前髋 `tau_est` | 10.6–11.1 Nm | 11.8–12.2 Nm |
| 后髋 `tau_est` | 12.9–13.1 Nm | 14.5–14.9 Nm |

**判读**：

- 仿真稳态误差**明显小于**实机（例如 <0.05 rad、pitch≈0）→ 仿真的 CoM 太靠中间、腿太轻、缺少 CPRO/背包质量，或关节摩擦/柔顺太小。
- 仿真**远大于**实机或直接塌 → CoM 太靠后、腿太重、kp 太低、关节阻尼/摩擦太大。
- 仿真稳态**符号对但幅值差 20–30%** → 先查质量/CoM，再查零位与关节摩擦；不要先改 kp。
- `factory_stand` 只做**姿态/力矩参考**：它没有 LowCmd，不能直接 replay；若仿真在 T2 下比 T1 还“直”，说明 CoM/姿态模型不对。

### 3.2 PD / 执行器阶跃

**用**：`*_fixstand_rise`（3 s，kp 20/3 前 1.8 s → 55/2 后 1.2 s）、`*_fixsquat`（kp 35→20→10→0 的缓降）。

**做法**：

1. 从 clip 第一帧 `st_q/quat` 起，逐帧施加命令（注意 B2 段目标从实测 q 重新插值）。
2. 记录每轴 `q`、`dq`、`tau` 的阶跃响应。
3. 比较：10–90% 上升时间、超调、`dq` 峰、`tau` 峰、稳态误差。

**实测特征**（可直接对照）：

- 起立总时长 3.0 s；前 1.8 s kp=20/kd=3，后 1.2 s kp=55/kd=2；B2 段从实际 q 插值，不是从固定起点。
- 起立过程 pitch 会先到约 −9°，再回到 −6°；`gyro_z` 峰约 0.07 rad/s；轮 `dq` 峰约 0.6–0.7 rad/s（被地面反拖）。
- 如果仿真起立“一下就到”、没有 3 s 的过渡，通常是仿真里直接设了 q 而没有按 500 Hz 命令/PD 走。

**判读**：

- 仿真响应**过快/无超调** → 执行器无延迟、无摩擦、转动惯量偏小。
- 仿真响应**过慢/超调大/振荡** → 延迟大、阻尼小、惯量大，或 kp/kd 与实机不一致。
- 某轴 `dq` 峰明显大于实机 → 该轴摩擦/阻尼偏小或目标步进过大。
- 注意：`cmd_tau=0`，所以这是**纯 PD**；如果仿真里加了重力补偿/前馈，响应会与实机不同。

### 3.3 轮-地摩擦 / 制动

**用**：`*_brake_return`（Brake 0.3–0.5 s + ReturnStand 2.5 s，轮 `dq` 目标为 0）、行走 clip 的起停段。

**做法**：

1. 从行走/刹车前一刻起，保持腿命令，轮 `cmd_dq=0`、`kd=2`。
2. 记录四轮 `st_dq` 衰减；积分 `dq×r` 估算停止距离（轮半径按模型）。
3. 比较停止时间、残速、是否反向爬行。

**实测特征**：

- `112630_brake_return` 轮 `|dq|` 峰约 1.66 rad/s，2–3 s 内衰减到接近 0；`220051_brake_return` 几乎无轮速（零速接管后刹车）。
- 行走 clip 的轮 `|dq|` 实测峰约 2.4–4.7 rad/s（命令峰 5.2 rad/s），可作为轮速范围参考。

**判读**：

- 仿真停得**太快** → 轮地摩擦/滚动阻尼偏大，或 `kd` 偏大。
- 仿真停得**太慢/一直滑** → 摩擦偏小、制动力不足、轮惯量偏大。
- 仿真出现**反向爬行** → 静摩擦/速度环符号或死区不对。

### 3.4 接触 / 落地

**用**：`*_fixsquat`（7 s）、`220051_prone_passive`。

**做法**：

1. 从站立/趴姿初态起，逐帧施加 FixSquat 的腿目标与 kp 渐变。
2. 记录 pitch、关节 q、`tau`、`gyro`，标出“腿接触地面”的时刻。
3. 与实机对比：落地时刻、pitch 峰、最终趴姿、`tau` 峰。

**实测特征**：

- FixSquat 7 s；最终趴姿 q 约 `hip ±0.54–0.59, thigh 0.97–1.01, calf −2.73～−2.77`。
- 落地过程 `|gyro_z|` 峰 0.27–0.31 rad/s；pitch 变化可达 10°。
- 没有足端力传感器，只能用 `tau`/IMU 事件做“接触时刻”的间接对照。

**判读**：

- 仿真落地**弹跳/穿透** → 接触刚度/阻尼、时间步、几何穿透容差不对。
- 仿真落地**太软/下沉** → 接触刚度低、腿 kp 低、质量大。
- 仿真 `tau` 峰远小于实机 → 腿惯量/质量小或接触力被“吸收”。

### 3.5 行走 / 转向（闭环）

**用**：`112630_policy_walk_30s`、`114335_walk_00_30` … `90_120`。

**两种用法**：

1. **开环命令 replay**（推荐先做 1–3 s）：把真实 `cmd_q/kp/kd` 直接喂给仿真，不跑策略，看短时轨迹/姿态是否跟得上。超过 3 s 后策略闭环缺失，误差会累积，不能怪动力学。
2. **同策略闭环**：在仿真里跑同一个 ONNX/策略，输入同一组 `cmd_vx/vy/wz`，比较基座 pitch/roll、yaw、轮 `dq`、接触事件。这才能区分“策略问题”与“动力学问题”。

**实测特征**：

- 30 s 行走 clip：轮 `|dq|` 峰 2.4–2.9 rad/s，`|gyro_z|` 峰 0.18 rad/s，pitch −1.7°～+6.4°。
- 120 s 长会话：轮 `|dq|` 峰 5.2 rad/s，`|gyro_z|` 峰 0.24 rad/s；不同 30 s 段差异明显（转向/直行混合）。
- **注意**：行走时髋目标含较大的准静态偏置（约 ±0.26～0.38 rad），而实测髋在 0 附近摆动；这是真实控制的一部分，不是日志符号错误。比较时看**髋力矩/姿态响应**，不要用“目标-实际瞬时相关”判断对错。

**判读**：

- 仿真**比实机稳**（实机后腿下沉/塌，仿真不塌）→ 仿真 CoM 偏前/偏中、接触/摩擦太理想、腿刚度太足。这正是 R214/R4000 已经暴露的差异方向。
- 仿真**比实机先倒** → 初态（q/quat/高度）不对、关节符号错、接触太滑、执行器太弱。
- 仿真 yaw 响应明显强于实机 → 轮地摩擦/转向力矩模型偏理想；弱于实机 → 摩擦太大或差动饱和。
- 仿真的轮 `dq` 饱和点/峰值与实机差很多 → 轮执行器/限幅/摩擦不对。

### 3.6 IMU / 基座 / 时延 / 噪声

**用**：全部 clip；静态 clip 看噪声，起立/蹲下看冲击，行走看频谱。

**做法**：

- 对 `gyro` 做 PSD，比较主频/峰值；对 `quat` 比较 pitch/roll 的 RMS 和漂移。
- 用 `cmd` 阶跃到 `st_q` 响应的互相关估计**命令-响应延迟**（本包 `st_offset_ms` 已给出 tick 对齐，但执行器/滤波延迟仍存在）。
- 用静态 clip 的 `st_q` 标准差（约 1e-5 rad）和 `st_dq` 噪声设定仿真传感器噪声；如果仿真完全无噪声，控制器行为会偏“干净”。

**注意**：没有加速度计、没有基座平动，PSD 只能比较旋转/关节量；不要声称“基座平动建模正确”。

## 4. Isaac Lab 接入建议

1. **关节映射**：用 `joint_names` 找 articulation 的 joint id；Isaac 的关节顺序通常不是 contract 顺序，必须显式映射。
2. **初态**：`root_quat` 用 `quat[0]`（wxyz），关节用 `st_q[0]`；基座高度没有真值，按模型腿长/接触估一个，先自由落体 0.3–0.5 s 稳定，再重置到该高度。
3. **命令**：每 2 ms 设一次 joint position target `cmd_q`，stiffness=`cmd_kp`，damping=`cmd_kd`；轮子设 velocity target `cmd_dq`，stiffness=0，damping=`cmd_kd`。
4. **执行器**：优先用 implicit actuator；若 Isaac 的 actuator 模型不支持逐帧改 kp/kd，按 `cmd_state` 分段设两组增益（FixStand 20/3 与 55/2），不要用一组常数跑完整段。
5. **接触**：平地、轮子摩擦 0.8–1.2、腿接触摩擦 0.6–1.0；先不要加随机化，做“标称对比”。
6. **对比**：仿真输出按同样 500 Hz 采样，比较 `q/dq`、`pitch/roll`、`gyro`、轮 `dq`；`tau` 用 actuator force 对比 `tau_est` 的趋势/量级。

## 5. MuJoCo 接入建议

1. **模型**：16 个关节 + free joint；关节顺序按 `joint_names` 建映射。
2. **初态**：`qpos` 设 `st_q[0]`，`qvel` 设 `st_dq[0]`（腿/轮），基座角速度用 `gyro[0]`；基座线速度未知，静态/蹲下设 0，行走可先用轮速×半径粗估。
3. **执行器**：腿用 position actuator（`kp` 对应 `gainprm`，`kd` 对应 `biasprm` 的阻尼项）；轮用 velocity actuator（`kp=0`、`kd=2`、`ctrl=cmd_dq`）。
4. **时间步**：0.001–0.002 s；命令保持 2 ms；接触用默认椭球/软约束，先调 `solref/solimp` 让静态穿透和落地不弹。
5. **对比**：`data.qpos/qvel` 对 `st_q/st_dq`，`data.actuator_force` 对 `st_tau`（按 gear 换算）；`data.qpos[3:7]` 对 `quat`。

## 6. 指标与判读

建议每个 clip 输出一张逐轴表：

| 指标 | 定义 | 用途 |
|---|---|---|
| `q_rmse` | `sqrt(mean((q_sim-q_real)^2))`，逐轴 | 位置跟踪/静态误差 |
| `q_maxerr` | `max|q_sim-q_real|`，逐轴 | 最大偏差（静态/瞬态） |
| `dq_rmse` | 同上，速度 | 阻尼/摩擦/延迟 |
| `tau_rmse` | `sqrt(mean((tau_sim-tau_est)^2))` | PD/负载量级 |
| `pitch_rmse` / `roll_rmse` | 基座姿态 | CoM/支撑 |
| `wz_rmse` | `gyro_z` | 转向/摩擦 |
| `wheel_dq_rmse` | 四轮速度 | 轮地摩擦/制动 |
| `delay_ms` | 命令阶跃到响应 10% 的互相关峰 | 执行器/通信延迟 |
| 接触时刻差 | 仿真 contact vs 实机 `tau`/IMU 事件 | 接触模型/落地时序 |

**建议**：先报告“逐轴表 + 一个总表”，不要只给一个总 RMSE；AS2-W 的后腿/髋误差远大于前腿，平均值会掩盖问题。

## 7. 数据特征与陷阱（重要）

1. **`tau_est` 不是力矩真值**：驱动器估计，含摩擦/齿隙/电流环误差；仿真的 `actuator_force` 与它只能比趋势/量级。
2. **没有基座线速度/高度**：静态/蹲下可假设 0；行走不能。不要用行走 clip 的“位置误差”判断动力学，除非你有 motion capture/VIO。
3. **没有足端接触力**：只能用 `tau`/IMU/关节运动间接判断接触时刻。
4. **`cmd_q` 与 `st_q` 的髋关系**：行走时髋命令是准静态偏置（约 ±0.26～0.38 rad），实测髋在 0 附近；同一时刻可能同号也可能反号。这是真实控制/接触的结果，不是日志错。**不要因此改符号**；先确认你的模型关节符号与 `joint_names`/`dds_slots`/`signs` 一致。
5. **`cmd_q` 轮子为 0**：轮子是速度模式，必须用 `cmd_dq`；把 `cmd_q=0` 当位置目标会让轮子锁死。
6. **`cmd_tick` 可能重复**：命令 500 Hz、LowState tick 1 kHz，多个命令可共享一个 tick；时间用 `cmd_t_s`（`mono_ns`），不要用 tick 做积分。
7. **`st_offset_ms` 最大 ±7 ms**：状态是最近 tick 对齐，含最多 7 ms 偏移；做延迟分析时要把这层算进去。
8. **clip 首行可能是过渡帧**：`cmd_state` 在状态切换时可能比命令早一帧（例如 FixStand 首行仍是 Passive 命令）。做纯段分析时先丢掉首行或按 `cmd_kp` 过滤。
9. **`*_brake_return` 的回站目标不是 T2**：策略刹车后 `fixed_pose` 被冻结为最后一帧策略目标，pitch 可能为正（本包 112630 约 +5°），不要拿它当 T2 静态测试；T2 静态用 `*_fixedstand_hold`。
10. **factory_stand 无命令**：只能做姿态/力矩参考，不能 replay。
11. **跨会话差异**：2026-11-10 与 2026-11-12/13 的静态稳态差约 1°/2 Nm（载荷、电池、地面、温度等）。用多个 clip 取范围，不要只拟合一个。

## 8. 推荐验证顺序（checklist）

- [ ] 1. `factory_stand`：只比姿态/T1，确认关节零位/符号/URDF 对齐。
- [ ] 2. `*_fixedstand_hold`：静态重力/CoM/关节刚度；先调质量/CoM，再调摩擦。
- [ ] 3. `*_prone_passive`：趴姿接触/阻尼，确认接触不穿透、不弹。
- [ ] 4. `*_fixstand_rise`：PD/执行器阶跃；确认 3 s 两段增益与响应。
- [ ] 5. `*_fixsquat`：大幅运动+落地接触。
- [ ] 6. `112630_brake_return`：轮速归零/摩擦。
- [ ] 7. `112630_policy_walk_30s`：先开环 1–3 s，再同策略闭环。
- [ ] 8. `114335_walk_*`：长时/转向；比较 4 个 30 s 段，不要只看总平均。

## 9. 如果要做更严格的系统辨识，还缺什么

当前数据能验证“像不像”，但不能唯一辨识全部参数。建议后续补：

1. **单关节正弦扫频/阶跃**（不同 kp、不同幅值、关节离地/加载两种）：辨识关节惯量、摩擦、齿隙、延迟。
2. **轮子离地阶跃**：单独辨识轮执行器/轮惯量，避免地面摩擦混在一起。
3. **已知配重/CoM 变化**：同一姿态加已知质量块，分离质量与 CoM。
4. **基座位姿/速度真值**：motion capture、VIO 或激光；当前完全没有基座平动。
5. **足端接触开关/力台**：直接标定接触刚度和落地时刻。
6. **电机电流/温度与 LowCmd 同步**：区分 `tau_est` 误差与真实负载。
7. **不同地面**（瓷砖/橡胶垫/地毯）：分离摩擦与接触参数。

## 11. 一句话总结

**先用静态和阶跃把“质量/CoM/关节 PD/接触”校到量级正确，再用制动和蹲下校“摩擦/落地”，最后才用行走做闭环综合对比。**
行走不稳时，不要第一反应改策略或 kp：先看静态 T2 是否也偏、`tau_est` 是否对得上、轮速衰减是否合理——这三件事决定仿真动力学是否值得信。
