# AS2-W 第 1,220 轮残差续训

有两种配置。默认 `original` 对照服务器正在运行的残差续训。`raised-v1` 将站立、前进、后退、侧移、转向和混合指令的机身都略微抬高，并在平地纯侧移、纯转向的摆动阶段增加抬轮目标。两者使用各自的输出目录。基准为仓库中的第 1,220 轮权重。

## 启动与监控

在 Linux 上按 [运行环境](../repro/runtime.md) 安装 Isaac Lab。以下命令从仓库根目录执行，BASE 和 RUN 均用新路径。把 PROFILE 改为 raised-v1 可运行增高对照。

```bash
./repro/check_runtime.sh
PROFILE=original
BASE="$PWD/runs/inputs-$PROFILE"
RUN="$PWD/runs/experiment-$PROFILE"
./continuation1220/prepare_run.sh "$BASE"
mkdir -p "$RUN"
AS2W_PROFILE="$PROFILE" nohup bash residual1220/prepare.sh "$RUN" "$BASE" >"$RUN/pipeline.log" 2>&1 </dev/null &
tmux new-session -d -s as2w-progress "./preflight/analysis-python residual1220/monitor.py '$RUN'"
tmux attach -t as2w-progress
```

启动脚本先用 128 环境做两次 PPO 更新，再用零残差和原始参考站姿生成同一评测程序下的 1,220 轮对照。正式训练另起模型，8,192 环境 × 48 步，seed 42。依次训练 100、400、19 × 500 次，最多新增 10,000 次。各段都比较段末权重和按回报保存的权重。若没有候选通过步态验收，脚本退出，原因在该段候选的 gate.json。监控显示最近一次事件的时间，序号使用 TensorBoard 的零基索引加一。Ctrl+b 然后 d 可脱离 tmux。

## 策略与执行器

冻结起点 actor 的确定性输出 b；残差网络末层零初始化，critic 从起点加载，新建 PPO 优化器。探索在潜变量 z 上进行，固定标准差 0.30，熵系数 0，学习率固定 1e-4。12 维归一化动作由下式合成。

```text
g = min(1, max(abs(vy)/0.15, abs(wz)/0.35))
a = clip(clip(b, -1, 1) + 0.24*g*tanh(z), -1, 1)
```

训练切换指令时使用新旧 g 中较小者。纯 vx 或静止时残差为零。每个关节相对本配置参考姿态的残差最多 0.06 rad。腿目标低通 10 Hz；轮子只跟踪 vx/0.086，限幅 ±12 rad/s，低通 5 Hz。控制周期 20 ms。模型文件内附冻结 actor，使用 policy.load_policy 加载复合策略。部署 raised-v1 时，执行器和观测都须使用 height.set_posture 中的参考角。[策略](policy.py) · [PPO](learner.py)

## 奖励与惩罚

单步奖励等于基线每秒奖励乘以 dt，减去跌倒终止代价 0.5，再减去 dt 乘以下面对应配置的附加代价。以下范数平方均按相应轴求和。

| 基线项 | 每秒贡献 |
|---|---|
| 平面速度跟踪 | +3 exp(−‖vxy−cmdxy‖²/0.25) |
| 偏航速度跟踪 | +2 exp(−(wz−cmdwz)²/0.25) |
| 垂向速度、滚转俯仰角速度、重力投影 | −0.5 vz² −0.1 ‖wxy‖² −0.5 ‖gxy‖² |
| 腿关节偏离本配置参考角 | −(0.2+still) ‖q−qref‖² |
| 滤波后腿目标一阶、二阶差分 | −0.06 (‖Δleg‖²+‖Δ²leg‖²) |
| 轮目标变化与静止轮转动 | −0.0005 ‖Δwheel‖² −still × 0.02 ‖wheel_velocity‖² |

still 表示指令三轴绝对值之和小于 0.03。训练继承地形课程和摩擦、恢复系数、质量、质心、PD 增益随机化。[基线实现](../common/environment.py)

两个配置共同增加以下代价。平地纯侧移有效区间为 |vy|=0.15–0.45 m/s，纯转向为 |wz|=0.35–0.8 rad/s。

- **短时反转，权重 0.02。** 用限幅后、低通前的腿动作减去 1,220 轮同相位动作模板。在 1–2 帧内前后反向时，取两个方向幅度中的较小值；两帧反转允许中间差分小于 0.25。超过 0.65 的部分截至 1.35、平方，再对 12 关节取均值。相位由参考轮连续离地和落地各三帧确认，失锁或刚落地时跳过此项。
- **逐轮支撑占空比，权重 0.10。** 以竖直法向力 ≥3 N 判承重。按基线周期分窗，逐轮比较承重比例与同命令基线；绝对误差超过 0.12 的部分平方并取四轮均值。每个有效窗口末乘窗口步数，按窗口结算。该项独立于相位锁定，持续三轮行驶会留下支撑误差。[附加代价实现](train.py)

## 增高配置 raised-v1

四腿大腿参考角从 0.8 改为 0.755 rad，小腿从 −1.6 改为 −1.51 rad，髋角保持 0。该静态姿态覆盖所有地形和指令。纯滚动腿部残差仍为零，因此机身增高依靠静态参考角；高度奖励只在能调整动作的样本中对策略有直接控制作用。

- **机身。** 以旧基线同一命令类别的实测机身高度中位数加 10 mm 为目标。平地所有指令按 0.15 × min(((h−目标)/0.02 m)², 4) 计入每秒代价。
- **摆动轮。** 从基线的完整锚轮周期重采样各轮轮心高度与离地概率。离地概率从 0.50 到 0.85 时，用五次平滑函数 10x³−15x⁴+6x⁵ 将权重 s 从 0 提到 1。轮心目标为同相位基线高度加 10 mm × s。仅在上述平地侧移、转向并锁相时，以 0.20 × mean(s × min(((z−目标)/0.015 m)², 4)) 计入每秒代价。验收使用旋转后的实际轮胎网格最低点与地面的距离。[高度实现](height.py)

## 怎样判定优于起点

每个平地工况有 6 次试验。检查跌倒、速度跟踪、四轮同时承重、逐轮抬落次数、关节角活动范围、周期和去相位后的高频残差。逐轮载荷占比允许偏差 8 个百分点，承重占空比允许偏差 12 个百分点。记录归一化动作两侧幅度均超过 1.3 的短反转次数，以免动作略离开限幅边界就被算成平滑。只有通过步态门槛、四个方向的平均实测关节残差比低于 1、且短反转总数低于基线，才有资格更新 validated-best.json。[配对评测](paired.py) · [选模](select_checkpoint.py)

raised-v1 还要求八类命令的机身中位高度分别升高 5–20 mm；在四种纯踏步命令中，对基线至少有 6 个完整有效摆动的轮，要求保留至少 75% 的事件，单次摆动峰值净空的中位数增加 5–25 mm。保留每个轮的数据。上述是平地仿真门槛。[高度验收](height_audit.py)

**服务器实测。** 两个配置均完成 128 环境 × 2 次 PPO 更新。默认配置的滚动、站立同观测动作差为零，冒烟权重仍因右转抖动和混合命令左前轮抬落而拒收。增高版冒烟回放中八类指令机身中位数升高 11.4–17.7 mm；左侧移右前轮抬落和多轮摆动净空未过门槛。当前证据只支持机身增高效果。原始数据见 [默认配置验收](evidence/smoke-gate.json) 和 [增高配置验收](evidence/raised-smoke-gate.json)。
