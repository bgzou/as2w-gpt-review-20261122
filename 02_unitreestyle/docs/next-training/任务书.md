# AS2-W 下一轮仿真、训练与实机交付任务书

状态：待执行设计稿。适用于原厂风格和 HIMLoco 两条训练线。下文标为“计划”的数值用于组织实验，实测包络须由校准记录确定。

## 1. 最终交付与验收目标

- **原厂风格**：站立与前后纯滚动时维持正常站姿和四轮支撑。前后速度命令通过独立轮速映射实现。侧移和转向由腿周期踏步实现，四轮按步态分工轮流卸载、抬起和落地。周期性的关节角变化是有效动作。要减少的是叠加在周期上的毛刺、落地振铃和无效高频变化。
- **HIMLoco**：沿用 W1W 路线的腿轮联合策略，学习跟踪速度和停车，保持合理的关节姿态、支撑和机身姿态。平地滚动禁止持续三轮支撑。允许按任务使用腿轮协同；通过平地与缓坡验收后，障碍能力作为独立扩展。
- **每条线交付一个通过全部必测工况的主权重**，外加父权重、训练和评估入口、资产及配置、逐场景原始时序、视频、ONNX、部署合同和实机记录。若没有一个权重全过，保留最佳已通过版本与失败清单。
- “一轮”指一次 PPO 更新。4096 环境 × 48 步 = 196608 条环境步/轮；8192 × 48 = 393216。控制周期 20 ms 时，48 步对应每环境 0.96 秒。比较预算时同时记录更新数和环境步数。

## 3. 环境、资产与控制配置

1. 从水平刚性地面开始。先做无策略静站，再回放父权重，之后才更新策略。平地行为过关后引入平滑缓坡，保留平地环境。建议先验收 ±3°、±6°，固定上坡、下坡和横坡方向。基础任务排除随机起伏、台阶和楼梯。
2. 采用 T2 v2 URDF 作为可追溯输入，保存从 URDF 转出的 USD 以及 Isaac/PhysX 版本、转换参数、哈希。轮地 A/B 用同一份明确绑定轮胎材质的 摩擦候选 USD（原工作区 `AS2W-unitree-flat-v2-dr/assets/as2w-t2-v2-mu025.usd`）。独立保留父权重原资产用于回归。MuJoCo T2 MJCF 用于第二仿真器和重力复算。
3. 逐项核对关节名、DDS 到仿真索引、符号和零位、关节轴、限位、驱动模式、质量、质心、惯量、轮胎碰撞体、轮轴与外倾角。区分网格和碰撞体。检查轮胎几何接地点、接触偏移、自碰撞、求解步长和迭代次数。每种设置保存实际生效值。
4. `policy_dt=0.020s`。记录 physics_dt 和 decimation，满足两者乘积等于 policy_dt。将低通截止频率、处理位置、reset 状态和使用的时间步写入合同。历史控制文件存在腿轮 5 Hz 配置，也有单独的腿 10 Hz 实验。续训以父权重的有效读取值为准。比较滤波时，两组只改该参数，并回放原始目标、滤波后目标、实际角与落地力。
5. 控制模式必须对齐真实流程。FixedStand 诊断的 55/2 或 85/3.2、官方静站 200/4、官方动态 40/1 各自保留。策略训练和 ONNX 使用对应部署合同的增益。验证阶段记录限速、限矩、驱动输入、实际应用力矩、重置时关节位置和控制器历史状态。

## 4. 包络如何定、如何采样

“标称”是资产和控制合同的参考点。“训练包络”是有实测、标定或已验证操作工况支持的范围。“压力档”用于摸清边界，先放在验收里。每回合固定一次装配、负载和地面配置。强度扩展须一次只增加一个可以解释的因素。

| 配置项 | 作用 | 如何定标称和包络 | 何时及如何用 |
|---|---|---|---|
| 轮地静、动摩擦与合成 | 决定起滑、侧滑、停车和载荷转移 | 已有有效 0.25 + min 与 0.50 + max 两个仿真对照点。真实材质做滚动、滑移和换向对照，分别记录方向、轮载和地面。 | 先同 USD 固定两档评估。训练优先固定合成规则，并在两档用读回值验证等效接触。每回合整块地面共用同档，离散验证后再插值。横纵差异先做独立压力实验。 |
| 重力矩与重力前馈 | 重力来自实际质量及姿态；前馈是控制器施加的指令 | 用三组悬空实测 q 和 IMU 求逐轴重力保持矩。四髋平均残差幅值现为 0–0.45 Nm。该指标随资产版本复验。 | 先固定实机已有前馈合同。训练随载荷和姿态自然变化。重力前馈若进入控制链，另开仿真和部署一致的 A/B，检查限幅与重复补偿。 |
| 电机与减速器静摩擦、启动力矩 | 建立接近零速的停滞与脱离阈值 | 悬空正反向进入同角度，记录开始连续运动时的带符号力矩，扣除该姿态重力项。多次重复，保存方向和温度。现有悬空静站不足以确定数值。 | 优先对四髋加独立实验。按 Isaac 运行版本核对字段单位及读回。参数可识别后，用标称和重复试验范围训练。零速判定及静动切换必须经过单轴回放。 |
| 动摩擦与黏性阻力 | 前者提供方向相关近常值阻力，后者随角速度增大 | 悬空同角度配对多档正反向匀速片段，扣除重力后拟合，固定独立速度档验证。比较加负载后残差，评估是否需要载荷相关项。 | 按轴或按实测分组。将静、动、黏性参数按辨识结果联合采样。只在物理关节或显式模型的一处施加。同样区分轮电机阻力与轮胎滚阻。 |
| 承重、质心与惯量 | 决定前后轮载、俯仰和关节保持力矩 | 以整机/四轮称重和电池、CPRO、载荷位置为基础。底盘质量 ±0.5 kg、纵向质心 ±10 mm 是压力点。既有 +0.5 kg 与后移 10 mm 对照可先复验。 | 每回合按真实可实现的载荷状态一起更新质量、质心和惯量，读回确认。原位载荷与后置载荷在验收单列。 |
| 轮地接触几何 | 轮胎外倾、接地点和横向力臂直接影响髋载荷 | 实测轮径、受载半径、轮宽、轴线、安装公差与轮心高度。用 T2 三次着地和原厂留出站姿验证。 | 先修标称几何。经过量测后用装配与变形区间；不同几何候选可用独立资产副本或预生成环境桶。禁止用虚假穿地换更好的姿态得分。 |
| 反射惯量 `armature` | 改变加减速响应和闭环带宽 | 候选初值来自可靠的转子惯量 × 减速比平方。用悬空加减速辨识，并和摩擦分开验证。 | 每轴记录是否已包含在模型中。先单轴测试再整机，随机范围取可辨识区间。 |
| 执行延迟与滤波 | 改变相位、落地响应和停车 | 对齐命令、状态与电机响应时间戳。分清通讯延迟、20 ms 动作保持和低通。现有额外 20 ms 用作压力档。 | 按 physics_dt 或 policy_dt 对应到缓冲实际更新时钟。每回合采样一个延迟，重置缓冲，先验收固定延迟再加入训练。 |
| 扭矩—转速与电机命令限幅 | 防止靠不可实现的力矩通过 | 使用电机输出侧实测或经确认的型号包络，区分峰值、连续值、保护阈值与正反向范围。参考 [IIT B2 结构](https://github.com/iit-DLSLab/basic-locomotion-isaaclab/blob/main/source/basic_locomotion_isaaclab/basic_locomotion_isaaclab/assets/b2_asset.py#L426)。 | 起步用已核验的部署限幅，保存请求与应用力矩。待有曲线后以轴为单位接入。 |
| 实机初态、坡度、观测 | 覆盖接管和工作姿态偏差 | q、dq、IMU 从同一采样帧按会话抽取。实测后仰与标称并列，人工合成前倾注明来源。坡面和观测噪声范围由验收地形和实测日志确定。 | 重置时成组抽样。初态、环境噪声和地形互相独立的前提要验证。坡面静站和滚动单独出表。 |

无策略标定要输出两种力矩：根据 LowCmd 重建的请求力矩，以及仿真实际驱动力矩。实机 `tau_est` 标注来源。静态支撑阶段比较无摩擦基线、只改执行器、只改接触、两者都改。已完成的是 MJCF 重力回放（原工作区 `AS2W-actuator-calibration/gravity_replay.py`），Isaac 逐轴扫角与摩擦辨识仍待完成。缺少有效运动片段时，该参数留待辨识，并在试验表中标记未覆盖。

## 5. 训练和域随机化排程

| 阶段 | 训练环境与变更 | 出口条件 |
|---|---|---|
| S0 无策略与零更新 | 原资产和候选资产的静站、悬空、动态回放；父权重零更新平地评估 | 核查 q、力矩、IMU、轮载和接触；记录是否复现悬空/着地四髋反号。确认资产转换、重置与运行配置。 |
| S1 标称平地 | 保持父任务奖励和执行链，训练平地站立、前后、侧移、转向与松杆。先做短烟测，提议 100–200 轮检查首个回归，之后每 100 轮保存。 | 基础动作全部过关，保存基础最佳。在平地不过的动作，先排查奖励门控和接触。 |
| S2 平地与缓坡 | 例如平地 70%、坡面 30%。单独比较新增摆动奖励或俯仰项；一次只改同一机制。 | 平地继续过关，坡面姿态与轮载合理。若坡面正常俯仰被误罚，先修参考角和验收定义。 |
| S3 单组排查与渐进混合 | 开 3 个对照支线做初态/负载、轮地、执行器/延迟的单因素诊断；可顺序跑，也可用同等资源并行。主训练逐组加入已确认范围，并保留先前场景。 | 新组与所有旧组重新验收；退化时从上次全过权重恢复，缩范围并复盘失败桶。 |
| S4 联合随机化 | 计划每批 25% 标称、50% 已验证单因素/常见组合、25% 可解释压力组合；按实际样本数锁定配额。压力档若超出训练范围则只进独立评估。例：后载 + 低摩擦 + 实测后仰。 | 使用留出的种子、初态、载荷组合按桶验收。最弱桶和统计离散度同时合格，标称能力保留。 |
| S5 冻结与部署 | 冻结同一个胜出权重，跑第二仿真器、ONNX 逐帧对齐和实机交付流程。 | 导出可追溯部署件和结果。每次实机升级对应明确的场景验收。 |

**阶段串行，环境内多工况并行。** S3 单因素支线负责诊断，最终使用一个通过联合训练和联合验收的权重。每个 PPO 批次保留标称、旧域与当前新域的配额。避免先后只给一种域，也避免把多个 checkpoint 逐项得分拼成一份“全通过”。训练和验收使用不同种子；同场 A/B 使用相同初态与命令。最终关键对照建议至少三个训练种子；候选阶段先用固定种子快速筛选。失败率、最差桶和 P95 单列，样本不足的桶不算通过。

## 6. 奖励按命令和阶段设计

给每条轨迹的命令分段标注：接管/站立、纯 vx、纯 vy、纯 wz、混合、松杆。用连续权重或带滞回的门控平滑切换。门控逻辑与验收用相同物理定义。奖励计算注明是逐秒率还是单次事件，逐秒率乘一次 dt。

| 分段 | 原厂风格 | HIMLoco |
|---|---|---|
| 共用 | 指令跟踪、合理关节软限位、非轮触地、能量与力矩限制。逐项日志含未加权和加权值。 | 同左。额外监控腿轮信号、HIM 估计误差、PPO KL/clip/value loss。 |
| 站立、接管 | 奖励稳定高度、合理前后腿姿态、四轮承重与低静止漂移。参考真实 FixedStand 和机身高度，保留正常承重角差。 | 姿态从实测分布恢复，持续俯仰约束分前倾与后仰。保留轮载和接管峰值检查。 |
| 纯 vx | 速度由轮映射跟踪，腿自然吸收载荷，检查持续卸载、非必要周期动作和毛刺。摆动/抬轮项关闭。 | 保持允许的腿轮协同，处罚长时间少轮支撑与非轮触地，保留直线速度跟踪。 |
| vy / wz | 四轮均有参加踏步的机会，左右镜像命令成对。用软相位或覆盖窗检测卸载→净空→落地。软五次曲线作为对照参考；奖励只在相应阶段检查净空、向下落地速度和支撑轮横向滑动。 | 保持速度与姿态目标，允许策略选择有效支撑时序。避免把原厂的强制踏步或零轮速规则直接迁入。 |
| 松杆 | 速度衰减、漂移、四轮恢复承重，允许短暂正常过渡。 | 单独看停车漂移、回稳、轮载重分配，防止姿态项压过停车目标。 |

抖动诊断要在同一时间轴上看策略原始目标、滤波目标、关节角、力矩、落地力。原始目标已有高频峰，则试目标二阶差分或时间平滑。只有触地后出现振铃，则先查 PD、轮胎碰撞和物理时间步。纯侧移/转向保留周期幅度，先观察每轮抬起次数和姿态，随后调整毛刺。奖励与门限每次做独立版本，保存无变更对照。

HIMLoco 现有 A/B 在同父权重 9836、4096×48、600 轮下比较有无持续俯仰项。B 用 5 Hz 姿态低通，超过同向 4°计时、回到 3°以内清零，0.30–0.60 秒渐增。低摩擦下运动持续前倾 6/48 → 0/48，但停车位移 P95 14.6 → 16.5 cm。高摩擦下接管持续后仰 48/48 → 29/48。下一轮固定这些场景对比 A、原 B 和按阶段处理的候选。坡面用现场正常姿态作为参考，单独记录世界俯仰和地形相对俯仰。 A/B 原报告（原工作区 `AS2W-HIMLoco-pitch-ab/REPORT.md`）

## 7. 权重筛选、数据和现场问题

1. 固定评估命令、时长、seed、初态桶、资产与材质、评分脚本版本。基本试次可复用 2 s 接管、3 s 命令、1 s 松杆。踏步需要更长窗口覆盖多个周期。补做匹配入速停车，建议 0.42–0.48 m/s，各对差 ≤0.02 m/s。
2. 每个 checkpoint 先过硬门槛，再按运动质量排序。检查跌倒、非轮持续接触、触地异常、离地与穿地、关节软限位、饱和、方向正确。滚动分别记录四轮同时支撑比例、每轮最长卸载、前后轴载。旧 A/B 的统计使用 3 N 作为仿真诊断阈值。步态评估按预期支撑阶段评分，允许摆动轮悬空。阈值用已验收基线、传感精度与用途预注册，保留原始时序。
3. 择优时并列看速度误差、停车漂移、前后倾最长时长、12 轴关节角曲线、摆动轮相位与净空、目标高频和力矩。全部必测桶过关才更新 best；在全过候选中优先改善最差桶。单项冠军单独归档。保留父权重、历史最佳、最新和按周期保存的中间权重。历史 model_1000 的“最佳”来自有限候选筛选，下一轮对所有纳入计划的保存点按同一规则评估。
4. 日志保存物理配置读回、动作原始/滤波/应用目标、q/dq、请求/应用力矩、IMU、四轮法向力、位姿速度、命令、退出原因。每小时报告轮数、吞吐、loss、分项奖励、最近通过/失败 checkpoint 和失败曲线。训练回报上升若伴随日常动作退化，保留父权重，回查门控或物理。
