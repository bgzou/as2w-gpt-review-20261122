## 三条最重要的结论

1. **交付权重 ≠ 上机权重**：v2-step 正式交付 `step_policy.pt`（`45b36ee7…`）**从未上机**；11-20 实机用的是其子代——抖动权重 `99995126…`（18:49 首飞、18:56/19:01 摇杆）与 mu025 摩擦对齐权重 `e90157b3…`（20:04/20:06/20:10）。
2. **实机数据分两块、三条线**：早期 `AS2-W_CPRO`（11-09～11-17，r-family：r214/r1199/r4000/armd-lp5/getup1199/t15）与当前 `AS2W-field-logs-20261120` + `.stage58`（11-19～11-20，unitree58 / HIMLoco 7836/18200 / v2-step jit/mu025）——接口与权重互不通用（41+state / 58+12 / 360+16）。
3. **真正“唯一证据”的数据不到 1 GB**；其余约 15 GB 中约 7 GB 是可删旧快照/重复件，约 4 GB 可“保留 tar、删解包”压缩。

## 使用说明

- CSV 里的路径是**本地工作区相对路径**（`X:\Items\as2w\...`），仓库内没有对应原始文件；用路径去本地找数据，用 SHA256 校验权重。
- CSV 中“可信度 = 低”的行（`r2000a` / `rise63` / 部分 11-16 早期 `zero-b`）在引用前需再查 CPRO `INDEX.md` 原始条目。
- 权重 SHAs 已于 2026-11-21 在训练服务器上实测复核；文档中的冲突点（mu025 两个 SHA、18200 SHA 误标、7836 vs 18200 同目录混放）已在索引 §6 逐条说明。
