### 问题 A：动作输出饱和

base model_2800 的 12 轴标准差均大于 42.42。固定名义回放上，确定性动作被 ±1 限幅的比例约 99.8%；域随机化的若干候选约 98.8%。这些跨权重统计使用固定观测带，不等于每个权重自己的闭环状态分布。即便不依赖固定带，标准差超过 42.42 的标量高斯在任何均值下，落在 ±1 外的概率也至少约 98.1%。

域随机化固定标准差为 0.4，但继承的 actor 均值仍远超限幅范围，说明仅减探索噪声没有消除继承输出饱和。诊断脚本和数据见 action_distribution_audit.py 与 action-distribution-audit.json。当前训练保持约定配置，没有在对照途中改动作参数化或重置 actor。

### 问题 B：奖励与四轮踏步目标不一致

基础与三个阶段的 calibration.json 哈希相同。左移未启用 RR、右移未启用 RL 的抬轮事件和超时约束；左转只启用 RR，右转只启用 FR/RL。因此 16 个方向与轮的组合有 7 个不受这两项约束，而验收要求四轮都反复抬落。源码证据见 reward-gate-alignment-audit.json。

这证明训练激励有遗漏，尚未证明其单独造成全部退化。后续应单独测试左右镜像且覆盖四轮的接触事件配置，保持站立和纯 vx 不进入踏步奖励；另做输出去饱和消融。当前不降低验收门槛，也不把尚未实施的修正写成已解决。
