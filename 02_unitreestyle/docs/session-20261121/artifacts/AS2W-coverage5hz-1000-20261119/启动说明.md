# 四轮抬落覆盖修正＋5 Hz 续训

2026-11-19：从原始 model_1000 重新续训 1000 次 PPO 更新。10 Hz 短试跑已停止，其权重没有用于本次续训。

- 4096 环境，48 步 rollout，20 ms 控制周期；平地 60%、斜坡 40%。
- 腿部目标低通 5 Hz，匹配极点系数 0.4665119089；轮速滤波保持 5 Hz。
- 纯 vy/wz 四轮均参与有效抬落事件；统一净空和离地时长判据。去掉 1220 推导的步频、间隔和轮资格筛选。

- 固定探索 std=0.4、学习率 1e-4、熵系数 0，重置优化器；本轮 DR 等级为 0。因此不能把它与最初基线的差异全部归因于奖励。
- 每 100 更新留存权重，逐更新检查训练回报最佳；训练回报最佳只是候选，不代表通过运动验收。
