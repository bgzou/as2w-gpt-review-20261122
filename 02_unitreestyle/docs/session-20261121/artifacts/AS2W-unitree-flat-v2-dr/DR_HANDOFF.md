# AS2-W v2 平地 DR 交接

独立目录建议 /root/as2w/unitree-flat-v2-dr。用已经通过实机数据对照的 v2 标称候选作为中心。训练动作仍为 vx 映射轮速、vy/wz 学踏步，奖励沿用平地基线。正式父权重取在平地验收中通过的 DR0 checkpoint，记录 SHA256。当前 DR0 尚在运行，父权重待筛选。

| 阶段 | 样本变化 | 建议轮数 |
|---|---|---|
| 0 | v2 标称复评 | 仅评测 |
| 1 | 底盘质量 +[-0.5,+1.5] kg；相对 v2 底盘质心 x ±20、y ±5、z ±10 mm；静摩擦 0.65–1.0、动摩擦 0.50–0.65、恢复系数 0–0.02 | 600 |
| 2 | 继承阶段 1；驱动增益 0.90–1.10；传感器噪声与偏置；腿和轮每回合独立 25% 概率延迟 1 tick（20 ms） | 600 |
| 3 | 继承阶段 2；每 6–10 s 加一次平面速度扰动 0.05–0.12 m/s | 可选 600 |

T2 的增重扫描中 +0.5 到 +1.5 kg 加剧俯仰，底盘前移 20 mm 改善了俯仰和力矩误差，故质量和纵向质心是首批验证维度。区间是工程试验范围，称重与轴荷测到后重新定中心。质量只变化 base_link，避免把 CPRO/电池的不确定性传播到腿。髋符号、零位和前大腿碰撞属于标定或几何问题，固定用已验证的转换合同与过滤对。传感器、延迟和推扰幅度为保守试验值。观测目标块继续采用现有原厂风格运行时的滤波目标定义。

复用服务器已可用的 v2 二进制 USD，放到 generated-v2/as2w-t2-v2/as2w-t2-v2.usd，保留其依赖层。也可用 prepare_v2_usd.py 重新生成。核对资产 SHA、合并后的质量、base_link 质量及 COM，并确认两对过滤存在。

    cd /root/as2w/unitree-flat-v2-dr
    export RESUME=/absolute/path/to/qualified-dr0.pt
    LEVEL=1 UPDATES=1 NUM_ENVS=8 OUT=/root/gpufree-data/as2w-runs/v2-dr1-smoke/train bash launch_dr.sh

各阶段分别冒烟。确认有限奖励、随机范围和 reset 正常，以及延迟确实为 0 或 1 tick。阶段 3 冒烟要覆盖至少一个实际扰动或单独控制触发时钟。随后做 4096 环境 48 步短测并看显存。长训明确设 UPDATES=600，NUM_ENVS=4096 或已验证的 8192，输出目录独立。仅上一阶段经步态验收后才作为下一阶段父权重，每次记录父权重哈希。

每阶段用确定性策略在平地标称、质量/质心边界和摩擦边界复评。记录所用 seed、命令与参数，固定同批对照。vx 正反向看四轮承重、跟踪和腿部是否出现周期踏步。vy/wz 双向逐轮看抬落、净空、承重横滑、机身晃动与关节曲线。先固定门槛并以父权重建立对照；候选出现三轮滚动、常驻抬轮、奇异关节姿态或确定性动作长期贴边时不晋级。训练回报 best.pt 只作候选。
