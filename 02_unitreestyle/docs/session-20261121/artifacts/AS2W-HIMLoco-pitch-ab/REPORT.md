# AS2-W HIMLoco 持续俯仰惩罚 A/B

A 和 B 从同一份 model_9836 续训 600 轮，4096 个环境，每轮 48 个推理步，控制周期 20 ms，训练种子 42。A 保留原奖励，B 新增持续俯仰和大角度俯仰惩罚。两组使用同一 T2 v2 URDF、同一 field_reset 配置。压力回放比较两组的 model_10436，采用绑定轮胎摩擦 0.25 的同一份 USD。记录保存在服务器 /root/gpufree-data/as2w-runs/him9836-pitch-ab-s2iOhk。

## 试验方法

每格 48 次回放，种子 319，八类命令各六次。每次含 2 秒零命令接管、3 秒命令段、1 秒松杆。每组 A/B 的实机初态采样、命令和摩擦设置逐项相同。初始 pitch 全体约 −5.80° 至 −5.51°。载荷组增加底盘 0.50 kg，并把底盘质心向后移动 10 mm，质量及纵向质心由 PhysX 回读确认。载荷是压力扰动。

持续俯仰使用 5 Hz 的一阶低通。达到有符号 4° 后计时，回到同方向 3° 以内清零，连续超过 0.60 s 记为一个试次中存在持续事件。计时跨段延续，表按事件所在阶段计数。停车偏移为松杆后 1 秒内相对松杆前末帧的最大平面位移，再取 48 组 P95。四轮同时支持使用各轮地面法向力至少 3 N，在命令段剔除最初 0.5 秒后统计。

| 压力工况 | 接管持续后仰 A → B | 运动持续前倾 A → B | 运动俯仰绝对值 P95 A → B | 停车位移 P95 A → B |
|---|---:|---:|---:|---:|
| 0.25 + min | 0 → 0 | 6 → 0 | 4.30° → 3.09° | 14.6 → 16.5 cm |
| 0.50 + max | 48 → 29 | 0 → 0 | 2.99° → 3.06° | 11.6 → 11.5 cm |
| 0.25 + min，后置载荷 | 32 → 0 | 6 → 0 | 4.15° → 2.91° | 15.9 → 17.7 cm |

六批共 288 次均未终止，有效运动窗口四轮同时承重比例均为 100%（按 3 N 门限）。0.50 + max 的 B 有 1 次停车持续后仰，A 为 0 次。两组低摩擦中出现持续前倾的 6 次均为倒车左转。直线倒车速度绝对误差三组分别从 0.096、0.072、0.090 降到 0.051、0.042、0.046 m/s。直线前进的低摩擦两组分别从 0.049、0.054 增到 0.065、0.074 m/s。

0.25 + min 的前/后轴平均法向力 A 为 129/142 N，B 为 126/146 N。后置载荷下对应 127/147 N 与 124/151 N。B 没有卸掉后轮，平均轴载反而略向后移。关节时序图对照前后大腿角、髋力矩绝对值和轴载，逐场景的十二轴角度、力矩和四轮压力可从 comparison.json 及 pressure 子目录查看。

## 判定

B 保留为姿态候选，暂不升级到部署最佳。只增加俯仰惩罚已能解决低摩擦倒车左转的持续前倾，但不能同时保证直线前进和转弯停车质量。下一轮可从同一父权重配对比较当前 B 与按接管、运动和停车分段的版本。在接管和有速度命令时保留持续俯仰约束，停车阶段单独考核漂移，前进误差、转弯漂移、四轮承重和关节角作为并列条件。

本批实机初态仅覆盖轻度后仰。前倾初态、前置载荷、横向摩擦和多训练种子未验证，轴载也没有同场真机传感真值，暂不能把回放改善外推到实机。


## 原 URDF 固定回放

中期目录名 eval-10136 表示请求的最低轮数，实际读取两个分支首次保存且满足该轮数的 model_10200。该检查点两组接管持续后仰均为 48/48。到 model_10436，A 仍为 48/48，B 为 29/48。两组在运动阶段均无持续前倾或后仰。该固定回放和 0.50 + max 的压力回放观测一致，也显示 B 的改善主要出现在接管窗口。中期与终点固定回放均已归档。
