# HIMLoco 平地 10000 轮训练与验收

种子 model_9836.pt，源目录 /root/gpufree-data/as2w-runs/him-flat-t2-v2-20261119-G6IW9O/train。20 ms、4096 环境、48 rollout 步为暂定训练合同。Codex 每小时巡检 automation ID himloco。训练允许范围以用户指令为准。

| 阶段 | 轮数 | 推进门槛 |
|---|---:|---|
| 实机初态和交接 | 1000 | 真实站姿接管和零速交接、前后滚动、停车验收 |
| 质量和质心 | 1500 | 实测姿态和名义工况都通过，按独立称重约束参数 |
| 轮地接触 | 3000 | 实现逐环境材质隔离。用 T2 55/2 与官方 200/4 留出静站对照同时检验俯仰及带符号髋力矩，分解法向、纵向和横向分量 |
| 执行时序 | 1500 | 已筛选组合的交接、跟踪、停车回归通过。延迟以日志为准 |
| 联合巩固 | 3000 | 固定测试集最终复验 |

每 100 轮保留独立 checkpoint。保留 seed、阶段端点、回报最佳、验收最佳及其 SHA256。阶段接力传入上一阶段验收最佳，避免启动器固定读 9836。未经测试的候选保留待评，不标记为验收最佳。

每 500 轮及每次验收最佳更替，对同一组固定试次归档。覆盖名义和实机留出初态的交接、前进、倒退、弧线和停车。以 50 Hz 存关节实际角/目标角、速度、力矩、逐轮仅地面的法向力和切向力、机身姿态/速度、命令和非轮接触。保存曲线和原始时序、种子、试次、checkpoint SHA256 与场景版本。阶段末另存代表视频。

权重筛选先淘汰持续后仰、异常关节姿态、长期三轮支撑、非轮借力以及靠不动回避跟踪的候选。余下按统一留出集的姿态、支撑、跟踪、停车表现比较。每小时记录运行轮数、最新 checkpoint、待验收数量、最佳权重及问题。自动巡检不等价于服务器内部 checkpoint 和评测实现。启动前仍需接好阶段接力、定期评测入口及归档，接触阶段另须通过上述门槛。
