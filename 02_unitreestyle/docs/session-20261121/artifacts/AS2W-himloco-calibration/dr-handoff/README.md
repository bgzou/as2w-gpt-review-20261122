# HIMLoco 平地域随机化交接

状态：实机 fixture、分阶段配置和参考采样器已就绪。Isaac Lab 回调、交接状态机和 GPU 批量采样尚待接入与验证。训练保持停止。sampler.py 是确定性参考，可用于验证 GPU 版采样范围。4096 环境训练应批量生成参数。

## 入口与资产

服务器 /root/as2w/him_arc/run_quality.py、arc_environment.py、quality_environment.py。待启动基线脚本 /root/as2w/calibration/candidates/t2-v2-20261119/train_him_flat_t2_v2.sh。候选 URDF 同目录 as2w-t2-v2.urdf，源 URDF 27.512 kg，base_link 相对 load-v0 前移 20 mm。配置的质心区间是相对 v2 的增量。PhysX 两对自碰撞和 DDS 髋映射需独立核对。

原 --stage randomized 与这里的三阶段不同。应保持 --stage flat、关闭原随机事件，通过独立配置加载本方案，避免两套随机化叠加。先优选已通过平地验收的同合同种子，现有启动器的 7836 属台阶种子。

## 接入顺序

1. 在 ArcEnv reset 后按环境批量写 root 姿态及关节状态。fixtures.json 是 DDS 槽重排后的原始 q/dq，明确验证 Isaac 的符号与零位后再转。训练只用 train，holdout 按整个会话隔离。根部高度从接地几何估算并用站立 PD 稳定。四元数按 wxyz，角速度按 Isaac 写入所需坐标转换。
2. 固定姿态后做 100 步零速交接。从实机 FixedStand 合同目标混合至策略目标，保留 55/2、轮 0/2、腿 10 Hz、轮 5 Hz。分开滤波状态和最终施加反馈。若开启延迟，反馈取真正出队的目标。逐局清理队列和历史。零速命令需要覆盖 ArcEnv 自身命令重采样。
3. 在 reset 事件按原始 v2 质量和质心加本局 delta，禁止跨局累加。对增重核对惯量更新并记录实际值。地面摩擦用每环境独立的地面碰撞体，若现有地面共享材质，先改为独立材质再开启此阶段。20 ms 延迟上限待日志核实。
4. 先小批量跑名义回归、时间步、双向映射、每环境材质隔离、队列清零。记录实测姿态可恢复、无 NaN、实际写入值。验证后每 100 轮按同一组固定试次筛 checkpoint。看俯仰、漂移、逐轴关节角与力矩、轮载时序及速度误差。单独检查三轮长期承重和停止后的漂移。
5. 三阶段 300/700/1000。未过阶段验收时停在本阶段定位。称重后更新质量和质心的中心值及区间，保留同一 holdout 进行对照。

基线奖励继续用 ArcEnv 已有设置，零命令轮速惩罚 0.02。质量 29.3–30.1 kg 仅为法向反推的等效范围，不作为采样中心。
