# AS2-W 真机轮地差异、物理校准与 HIMLoco 域随机化
2026-11-20 · 项目交接文档

## 1. 结论与当前状态

AS2-W 的主要差异出现在轮胎承重之后。悬空重力力矩能较好复现，但落地后，轮胎接触位置、法向力分配及横向约束会共同改变髋轴力矩。调准俯仰并不能保证承重正确。已有候选能显著改善 T2 和官方站立的部分指标，尚未找到在独立留出会话上两种站姿都同时改善俯仰和四髋力矩的统一参数。

HIMLoco 平地起点为 model_9836，已完成 Isaac Lab 平地评测与视频。10,000 轮分阶段目标和每小时巡检已建立，服务器第一阶段启动参数检查通过。本记录编写时，域随机化训练尚未启动。训练准备与旧的物理校准结果应分别记录。

实测量包括关节角和速度、IMU、最终 LowCmd 与电机估计力矩 tau_est。两次 HIMLoco 交接按 tick 对齐共 1845 帧，最终命令反算 PD 与腿部 tau_est 的 MAE 均约 0.118 Nm。tau_est 仍为电机估计值。逐轮法向、切向力未直接测量，文中涉及实机轮载的反推均依赖模型与静力假设。26 kg 是另一官方模型的整备质量，27.512 kg 是 Isaac load-v0 的读回质量，均不能替代当前整机在相同附件配置下的独立称重。

HIMLoco 的中止试验在零命令交接约 1.74 s 内从 −5.8° 到 −14.3°。完整试验行走段平均约 −19.8°。两场交接的历史目标最大归一化反馈误差约 0.904，原策略反馈的是混合前请求。固定实测传感器历史替换反馈后，滤波前腿目标最大变化约 0.23 rad。最终 LowCmd 的 MuJoCo 无策略回放也复现同方向后仰，末帧误差约 3.0–4.6°。这些试验支持分别核对部署反馈和物理接触。

## 3. 几何、悬空及质量校准

- 官方 03 同帧 8500 ms、tick 8254106，按轮轴高度取两前轮网格外缘。DDS 髋使用 +1 时 PhysX / MuJoCo 外宽为 40.97 / 40.95 cm，使用 −1 为 59.29 / 59.27 cm。实机约 40 cm。应比较轮胎外缘，避免把轮关节原点间距与轮胎中心距混用。这个方向用于离线日志转换，实机双向映射需独立验证。
- 两种符号各自重算关节姿态及重力力矩，再转回 DDS 比较。+1 对官方、T2 55/2、T2 85/3.2 四髋 MAE 为 0.270 / 0.126 / 0.149 Nm。−1 均约 6.2 Nm。Isaac 导入前后四髋均为局部 +X，无材料支持修改训练资产关节轴。
- 现用 MuJoCo 候选的轮胎网格保留轮轴偏置。静站报告识别出模型底盘与左右前大腿的异常自碰撞。仅在诊断中排除这两对后，官方两组落地 12 轴力矩 MAE 从 6.25 / 6.53 降至 0.91 / 0.82 Nm。此排除尚未等效验证到 Isaac USD。
- Isaac v2 候选在原 URDF 上把 base_link 质心前移 20 mm，总质量仍 27.512 kg，含固定合并的 0.5 kg JT128。旧 MuJoCo 候选的总质量 27.012 kg，比较前应对齐固定件。20 mm 是校准候选，尚无实称轴荷确认。
- MuJoCo T2 仅移动质心 20 mm，把三次静站额外后仰由 6–9° 缩至约 1–4°，仍有后小腿下沉不足。固定该位置再加 0.5、1.0、1.5 kg，三档均增加俯仰误差，同时增加后小腿下沉。
- T2 实测初态的轮胎网格法向力臂约 21.6–23.5 cm。将仿真前轮 38–40 N 代入，前髋保持力矩约 4.4–5.1 Nm，实机约 11–12 Nm。只用前髋反推法向力约 68–71 N/轮。用全腿 12 轴拟合则为前轮 62–63 N、后轮 81–86 N，后轮比例 57–58%。该模型反推等效 29.3–30.1 kg，仍有约 1.1 Nm 残差，因此不作为资产质量标定值。

## 4. PhysX 轮地摩擦验证

ArcEnv 默认传感器读轮刚体的聚合力。检查时为每轮添加独立地面过滤传感器，过滤路径使用 /World/ground/terrain/GroundPlane/CollisionPlane。通配过滤一度给出全零，改用完整碰撞体路径后，逐轮过滤的法向力加摩擦力与聚合力相符。材质检查必须遍历实例代理，否则会漏掉轮胎碰撞网格。

| 检查 | 观察 |
|---|---|
| 运行时地面材质 | 碰撞体绑定 physicsMaterial。静、动摩擦能读回，初版请求 min 时 USD 未显式应用 PhysxMaterialAPI。 |
| 运行时轮胎材质 | 四个轮胎碰撞网格均未解析到显式物理材质。有效默认属性仍需独立确认。 |
| 只将地面系数设 0 | T2 仿真俯仰 −6.21°，但后轮横向摩擦约 −18.3 / +16.7 N。前髋约 5.1–5.3 Nm。 |
| 显式写入地面 min，系数 0 | 读回 min，四轮地面切向力均为 0 N，法向力正常。T2 俯仰 −20.42°，前髋约 2.1 Nm。此项仅作零摩擦对照。 |

原报告中 PhysX 悬空髋力矩 RMSE 约 0.16 Nm，但落地 T2 的髋幅值和方向均可能出错。侧向力对髋轴的力矩可能抵消法向贡献，且在不同接触参数下收敛到不同静态平衡。实机侧向力反演对接触点、重力和力平衡假设敏感。建议用相同实测姿态分解每点的 (接触点−髋轴点) × 接触力，并投影到髋轴。分别报告法向、横向及纵向贡献，同时记录四轮接地和非轮接触。

## 6. 训练与域随机化计划

起点为平地 model_9836，使用原 ArcEnv 策略、20 ms 控制、4096 环境和每轮 48 步。原评测有 48 个试次，8 个代表视频场景包含静站、前进、倒退和弧线。原轨迹包含关节实际角与施加目标、轮刚体法向合力，尚缺只对地的切向力、逐轴力矩与实测初态交接。

| 阶段 | 轮数 / 累计 | 训练与验收 |
|---|---:|---|
| 实机初态与交接 | 1000 / 1000 | 初期约各半名义与实测初态。整帧采样 q/dq 和 IMU，按会话隔离训练与留出。按实机 FixedStand/LowCmd 验证 100 步零速交接并回填真正施加的目标。 |
| 质量与重心 | 1500 / 2500 | 逐局相对 v2 名义值写入，称重前探索增量 ±0.5 kg。质心按相对 load-v0 的 10/20/30 mm 等候选先做物理筛选，称重后再调整采样中心。 |
| 轮地接触 | 3000 / 5500 | 每环境单独材质，同局四轮共享地面。逐环境隔离读回通过后，使用经过 T2 与官方留出静站筛选的离散档。保留约一半名义局，轮胎几何固定在选定的版本。 |
| 时序与组合 | 1500 / 7000 | 若日志支持再加 0–20 ms 目标延迟，逐局清空历史和队列。保持腿 10 Hz、轮 5 Hz，反馈最终出队并施加的目标。 |
| 巩固 | 3000 / 10000 | 使用已验证的组合参数，维持名义与边界覆盖。最终验收同时检查动作能力与姿态、支撑。 |

奖励仍以 model_9836 原 ArcEnv 为基线，零命令轮速项 0.02。若有持续三轮支撑，先用地面过滤验证信号，再对持续卸载做平地稳态限定的单项 A/B。若零速持续后仰或漂移，分别对交接俯仰超差和停车平移速度试验。实机髋力矩用来检验物理与策略行为，不作为需要策略硬追的目标。

## 7. 权重与证据保存

- 每 100 轮保留独立 checkpoint。种子、阶段末、回报最高、验收最佳分别保存并记录 SHA256。只有通过验收的最佳权重允许接力。
- 每 500 轮和每次验收最佳更替，固定同一组名义和实机留出试次。保存 50 Hz 关节实际角、施加目标、速度与力矩、逐轮地面法向和切向力、机身姿态与速度、命令、停车漂移、非轮接触。归档原始时序、曲线、试次标识、资产版本和权重哈希，阶段末保留视频。
- 持续后仰、异常关节姿态、长期三轮支撑、非轮借力和低速躲避命令均须淘汰。用同一留出集比较俯仰、四轮支撑、跟踪和停车。
- 每小时巡检 ID himloco。巡检检查真实进程、轮数及产物，并记录处理问题的证据。服务器曲线自动归档和最佳登记仍待接入。
- 第一阶段与 load 的 8 环境零更新预检已通过。实机 wxyz 在此 Isaac build 的写入边界转换为 xyzw。load 通过 PhysX 质量/质心读回。逐环境摩擦隔离和后续三个阶段仍待接通。
