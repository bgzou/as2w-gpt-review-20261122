## 4. 训练状态核对（本次最重要的发现）

### 4.1 基础 10000 轮没有跑完

| 项 | 实测 |
|---|---|
| run 目录 | `/root/gpufree-data/as2w-runs/unitree-unified-reward-20261119-010208` |
| 目标 | `--iterations 10000`、4096 env、48 rollout、seed 42 |
| 实际 | 日志最后到 **Learning iteration 6033/10000**，`reward-components.jsonl` 最后一条 update=**6034** |
| 退出 | `exit-code` 文件内容 `1`；日志末尾 **`Terminated` + `There was an error running python`** |
| 最后权重 | `model_6000.pt`（2026-11-19 10:25），另有 `best.pt`；`best.json` 记录 `completed_updates: 6000` |
| 停止时间 | 2026-11-19 10:29 |
| 后续 | 无继续训练的 run；未发现 model_7000+ |
| 审计 | `intent-audit-u6001` 已跑但 gate 未通过（如 forward/reverse 四轮支撑、left/right 抬轮、cadence 等） |

> **“Terminated” 表示进程收到 SIGTERM**（人为停止/平台回收），不是 Python 崩溃堆栈。真实原因需现场确认。任务书不能再写“基础任务仍在运行”。

### 4.2 训练速度（实测）

| 证据 | 数值 |
|---|---|
| `train.log` iteration time（update 6033 附近） | 7.93 s / 7.97 s |
| base run model_1000 → model_2000 | 6820 s / 1000 = **6.82 s/更新** |
| base run model_2000 → model_3000 | 5950 s / 1000 = **5.95 s/更新** |
| v2-stephard600 update-100 → 400 | 2062 s / 300 = **6.87 s/更新** |
| v2-stephard600 update-400 → endpoint | 1322 s / 200 = **6.61 s/更新** |

**结论：4096 env 约 6–8 s/更新**；600 更新 ≈ **60–80 分钟**；三级 DR（1800 更新）≈ **3–4 小时**（不含评测）。
旧文档的 4.37 s/更新、44 分钟/级来自早期交接记录，与本机实测不符。
