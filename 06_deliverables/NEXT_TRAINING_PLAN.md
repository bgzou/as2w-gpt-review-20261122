## 2. 评判基线：三条硬约束

任何"下一轮训练"必须先满足：

1. **J3 五条件**（sim2real 包的结论）：①根因已定位到策略可补偿层 ②仿真基准可信 ③DR 能覆盖已识别不确定性 ④有可验证的奖励/观测修正 ⑤成本收益匹配。当前 **0/5 满足**。
2. **门禁可满足性**：每个 gate 判据必须映射到至少一个奖励项/可观测项；映射不到的判据不许开门禁（`index.html` 的教训：eligible 掩码让 7/16 组合不可得分 → 32/33/31 项结构性 FAIL）。
3. **训练合同一致性**：runtime flags / 动作包装 / 腿轮增益必须与训练 `actual_runtime_flags` 逐项一致；任何差异算新版本（本项目 R1199 四开关事故的教训）。

## 3. step（原厂风格）线的评估与修订排程

### 3.1 任务书里合理的部分

| 条目 | 评价 |
|---|---|
| 父权重 1220/1320/1000 各自按原配置复验，再统一协议比较 | 合理；避免"用新配置否定旧权重" |
| 12 轴腿 + 独立轮速映射；纯 vy/wz 时轮速为零 | 合理，且与官方一致（见 §5） |
| 两档摩擦 0.25+min / 0.50+max 同 USD 评估 | 合理；unitreestyle 已量化 μ 0.5→0.25 使静态前髋 1.66→11.91 Nm ≈ 实机 11–12 |
| 接触几何/轮径/轮宽/轴距/轮心高度实测；禁止穿地换姿态 | 合理；与 sim2real J2 第 2–3 项一致 |
| 按命令分桶（站立/纯 vx/纯 vy/纯 wz/混合/松杆）；门控与验收同物理定义 | 合理；`index.html` 指出塑形项只有跟踪项 1% 量级，提权无效 |
| 分阶段 S0–S5、一次只改一项、保留无变更对照 | 合理 |

### 3.2 需要修订的部分

1. **排程**：S1 训练必须后移到 J2 测量之后（见 §7 决策门）。理由：策略会继承接触偏差；且质量/CoM 未定案时训练结果无法解释（本项目 RPT-008：base +1.012 kg 使后腿静差 0.378→0.424 rad）。
2. **接触模型**：任务书只写 μ 两档，需补 `condim / solref / solimp / impratio / 有限接触斑（或轮胎柔顺）`，并接受"双锚点不可兼得"的声明（sim2real J1 问 3：impratio=1 匹配 pitch/Fn/后腿，impratio=100 匹配前髋，任何单点配置不能同时满足）。
3. **Fy 方向**：把"四轮侧向力/接触斑压痕"列为交付项。sim2real Q3：实机需要**外撑**侧向力（前 +24.1/−24.2、后 +18.6/−18.5 N），PhysX 给的是**向内**（−21.9/−19.7 N）；纯 hip 通道下界 46–89 N 已逼近摩擦锥（μFn≈38 N）。**不测 Fy 方向，就无法判断接触模型是否修对。**
4. **right 方向**：改为 skating side-step 判据（位移/偏航贡献 + 不摔倒），不再要求 RR 抬升。几何事实：抬 RR 后 FR–RL 边过重心投影，静裕度 0；15 臂 + 15 mm 配重零抬升。
5. **kp 的地面 A/B**：任务书保留 55/2、85/3.2、200/4、40/1 多套增益但没排地面 A/B。sim2real Q7 禁止用悬空数据推地面高 Kp；必须单独做**地面**（同姿态/同命令/7.7 s，记 `cmd−actual`、Fn、tilt）。
6. **单关节方向/零位核对（P0）**：任务书没有；这是唯一能一票否决"部署映射"假设的实验（12 轴，`+0.02 rad`，2 s，读 `q`，与仿真对符号）。

### 3.3 修订版排程（step）

| 阶段 | 内容 | 出口条件（预注册） | 预算 |
|---|---|---|---|

## 4. HIMLoco 线的评估与修订排程

### 4.1 合理的部分

| 条目 | 评价 |
|---|---|
| 保留父权重 HIM runner / 历史输入 / 估计器 / 观测归一化；算法替换单独开实验 | 合理；身份链可追溯 |
| 平地滚动禁止持续三轮支撑 | 合理；与 sim2real 的"后轮卸载/三轮滚动"观察一致 |
| 俯仰项用计时 + 回滞（4°/3°）+ 渐增（0.30–0.60 s） | 设计合理；A/B 已有数字（低摩擦前倾 6/48→0/48；高摩擦接管后仰 48/48→29/48） |
| 分命令段奖励；平地→缓坡→障碍独立 | 合理 |

### 4.2 需要质疑的部分

1. **父权重 9836 与已上机的 18200 不一致（最优先）**。上机对照表：HIMLoco 唯一上过机的是 `model_18200`（11-20 18:03–18:42），**9836/13900 从未上机**。以 9836 为父 = 把"有现场证据的链"换成"更早、未上机的检查点"。
   - **先做零更新同场景回放对比（18200 vs 9836）**，不动策略、不上机；若差异明显，18200 的现场结论不能平移，须重做 S0–S3。
2. **俯仰项针对 DR 场景，不修现场 zero-B 静差**。现场主诉是后腿 `cmd−actual` 0.336/0.331 rad 与 −6.1° pitch，力学是 `τ_gravity/kp`（见 `ROOT_CAUSE_ANALYSIS.md` §3.3 L1），加俯仰奖励不会改变静差；且 B 有代价：低摩擦停车位移 P95 14.6→16.5 cm（+13%）。
   - **先做地面 kp 55 vs 85（仅站姿）并记录 `cmd−actual`**；俯仰项若要做，预注册"停车退化 ≤10%"与"三轮支撑"两条约束。
3. **缺前置接触/资产测量**：18200 是在"仿真前髋 3.7–5.1 Nm、实机 11–12 Nm"的世界里训的（其合同文档第 92 行自述）。HIMLoco 也要过 S-P0/S-P1 的测量门，不能因为"腿轮联合"就跳过。
4. **第二仿真器证据无效**：会话的 `mujoco-mujoco_eval.py` 用 `deploy_ref_controller.py`，包装与 C++/yaml 不一致（腿差 0.162 rad、轮差 10.95 rad/s）→ 现有 `mujoco-validated-20261121.mp4` 与"前进 92%/后退 85%/转向 20%"都不是同合同证据。**先把包装换成 C++ 合同，再谈第二仿真器。**

## 5. 转向通道：接受"轮差速排除"，但必须给踏步一个基准

用户/现场确认：**宇树官方 AS2-W 的转向同样由腿踏步完成，不靠轮差速**，因此任务书"纯 vy/wz 时轮速指令为零"是**与官方一致的设计选择**，不是缺陷。

由此产生的新要求：

1. **用官方 `ai_free_walk` 的偏航响应做基准**：同一地面、同量级 `wz` 指令下，官方 `gyro_z` 稳态值与调节时间是多少（INDEX 2026-11-19 节已采官方站立/行走/趴下三向参考，标 VALID）。没有这个基准，"转向弱"无法判定是策略不足还是平台上限。
2. 轮差速可保留为**可选对照**（独立新版本、重走 S0–S3），但**不作为任务书必须修正项**。
3. 评价 step 转向时，必须同时报告：指令 wz、实测 gyro_z、偏航累积角、tilt、以及是否在官方包络内。

## 7. 决策门（什么时候才允许开训）

**必须全部满足**：

1. S-P0/H-P0 完成：质量/CoM 定案、接触斑结论、单关节方向核对无符号相反轴。
2. S-P1 完成：仿真基准的 pitch/Fn/后腿 q 三项在容差内；前髋力矩缺口有书面声明。
3. 门禁—奖励映射修正完成（无结构性不可满足项）。
4. 官方偏航基准入库（转向有参照）。
5. HIMLoco：18200 vs 9836 对比完成并选定父权重；MuJoCo 包装已改 C++ 合同。
6. 训练合同逐项对齐（runtime flags / 包装 / 增益），任何差异登记为新版本。

> 现状：以上 6 条**均未完成**（`UNKNOWN` → 0/6）。此时开训 = 在未定标的资产上烧预算，且会把接触偏差学进策略。

## 8. 预算与风险（若照原计划直接训练）

| 风险 | 机制 | 证据 |
|---|---|---|
| 把前髋 7.2 Nm 接触偏差学进策略 | 训练接触流形与实机不同，策略按仿真负载分配重心 | sim2real J1 问 4 |

## 9. 如果只做五件事

1. **四轮称重 + CoM 定案**（判 26.0/0.035 vs 27.512/0.020）——两条线共用。
2. **单关节方向/零位核对（12 轴）**——一票否决部署映射假设。
3. **地面 kp 55 vs 85 的 zero-B A/B（HIMLoco 站姿）+ 记录 `cmd−actual`**。
4. **18200 vs 9836 零更新回放对比 + 修 MuJoCo 包装**。
5. **门禁—奖励映射修正 + right 改 skating 判据 + 官方偏航基准**。

做完这五件，再决定是否训练；否则任何"下一轮"都只是重复上一轮的失败模式。
