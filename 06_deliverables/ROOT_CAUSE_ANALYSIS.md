## 0. 一页看懂

**机器人**：AS2-W 是"轮腿"机器人——四条腿各有髋/大腿/小腿 3 个关节（共 12 个），每条腿末端一个驱动轮（共 4 个）。腿是**位置伺服**（给目标角，电机按 `力矩 = kp×(目标−实际) − kd×速度` 追；本项目 kp=55、kd=2），轮是**速度伺服**（给目标转速）。控制 50 Hz（每 20 ms 一次）。

**两条策略**：

| 策略 | 任务 | 观测/动作 | 关键设计 |
|---|---|---|---|
| **v2-step** | 只做侧移 + 转向的踏步，**不做前后滚动** | 58 维 / 12 腿动作 | 前后交给轮子（本线移除），侧移/转向靠腿周期抬落；动作 `tanh` |
| **HIMLoco** | 腿轮联合：站立、前后、转向一套网络 | 360 维 / 16 动作 | `tanh` 后腿乘 0.6、轮带前馈；100 步零命令交接 |

**证据标签**：`CONFIRMED` = 从原始 JSON/CSV/源码复算；`OBSERVED` = 原始记录或会话直接写下；`INFERRED` = 据多个结果推断；`UNKNOWN` = 无独立数据。本文每条结论在 §10 有等级与出处。

**结论置信度**：v2-step 根因判定 = **高**（三组独立证据：抖动改善、15 臂 RR 全失败、μ 重训后转向更差）；HIMLoco 根因判定 = **中高**（机制由同合同仿真确认，但"实机载荷到底多大"仍依赖反演/自述，缺独立 Fn）。

**上机看到的两件事**：

1. **v2-step**：站着不动时腿在抖；摇杆让它侧移/转向，机器人**几乎不动**（指令转 0.10 rad/s，实测 0.026 rad/s）；往右走时**右后轮一次都没抬起来**。
2. **HIMLoco**：能站、能走，但推杆时**两条后腿被体重压下去**（小腿目标与实际差 0.33 rad ≈ 下沉 3–4 cm）；用"抬高目标"去补，前腿被顶反、机身前倾、关节嗡鸣，2.2 s 后急停。

**根因一句话**：

- **v2-step = 训练目标错 + 训练数据错**：门禁要求了几何上做不到的动作（右后轮抬起）、奖励资格掩码让 7/16 组合不可得分、步态没有轮差速所以转向只能靠踏步、训练地面摩擦（0.5）是实机（≈0.25）的两倍。**不是"实机太滑"这么简单**——摩擦对齐重训后转向反而更差。
- **HIMLoco = 腿的弹簧太软 + 训练世界太轻**：kp=55 对实机重量余量不足（静差 ≈ 重力矩/kp），训练时仿真前髋力矩只有实机一半（3.7–5.1 vs 11–12 Nm）。**不是策略不会站，也不是 kp/kd 抄错。**

## 1. 术语（看数字前先看这节）

| 词 | 意思 |
|---|---|
| **零命令** | 不给运动指令（vx=vy=wz=0），让机器人自己站着 |
| **B 键 / 交接** | 现场状态机：A 起立 → B 把控制权交给策略；HIMLoco 前 100 步（2 s）把策略输出从 0 线性拉到全量 |
| **`cmd−actual`** | 关节"目标角 − 实际角"。**正 = 实际比目标低，腿被重力压下去** |
| **p2p** | 峰峰值（最大−最小），衡量抖幅 |
| **符号翻转率** | 相邻周期腿目标变化方向反转的帧占比，越高越抖 |
| **yaw 斜率** | 实测偏航角速度 ÷ 指令角速度；1.0 = 完全跟上 |
| **PD 力矩** | 按 `kp×(目标−实际) − kd×速度` 算出的"电机该出多大力"，不是实测 |
| **tau_est** | 驱动器反馈的估计力矩（固件算的），与 PD 力矩不是同一个量 |
| **Fn** | 轮地法向力（N），四轮之和 ≈ 整机重量 |
| **门禁** | 验收条件，如"四个方向、每个轮子抬起 ≥2 次" |
| **impratio** | MuJoCo 的摩擦约束阻抗（求解器参数），**不是摩擦系数 μ** |

## 3. v2-step：症状（完整表）

### 3.1 站着不动时腿在抖

**现象**：零命令站立时，腿目标角在约 ±0.18 rad 内来回翻（峰峰值 0.36 rad），约每秒翻 8 次；机身轻微左倾；现场能听到关节轻微"哒哒"声。

| 指标 | jit 权重 | mu025 权重 | 说明 |
|---|---:|---:|---|
| 腿目标峰峰值 | 0.360 rad | 0.369 rad | 抖幅约 20° |
| 符号翻转率 | **8.17%** | **12.85%** | 越高越抖；mu025 反而更差 |
| 机身 roll 均值 | −2.49° | −0.58° | mu025 把左倾修好了 |
| 前髋 PD 力矩 | 6.19 / 3.98 Nm | 5.32 / 4.90 Nm | 四个髋里前两个 |

**口径说明（重要）**：会话 README 写"符号翻转率 30% → 8–13%"，但**仓库里能复算的只有 8.17%（`zeroB_old`，jit 权重）与 12.85%（`zeroB_mu025`）**；30% 对应的旧 clamp 权重**没有完整时间序列**，只能标"会话记录"。`zeroB_old` 是 jit 权重，**不是**旧 clamp 权重。

**为什么是问题**：高频翻转让关节/减速器反复换向（发热、磨损、噪声），也是"策略输出不平滑"的直接证据。旧 clamp 版本（动作直接截断到 ±1）据记录约 30%，改成 `tanh` + 抖动随机化后到 8.2%——这一步是训练侧修好的；但 mu025 又回到 12.85%。

### 3.2 侧移/转向几乎不动

**现象**：摇杆给侧移 0.2 m/s、转向 0.3 rad/s，机器人基本原地踏步/打滑，位移小、转向慢。

| 指标 | jit 权重 | mu025 权重 | 说明 |
|---|---:|---:|---|
| yaw 斜率 | **0.199** | **0.146** | 指令 1 rad/s，实际只跟 0.15–0.20 |
| 活动帧实测/指令 | — | 0.103 → **0.0256** rad/s | 约 1/4 |
| 侧移斜率 | 0.709 | **−1.141** | mu025 侧移方向反了 |
| 样本帧数 | — | walk 911 / wz 活动 260 / vy 活动 142 | 活动占比 wz 28.5%、vy 15.6% |
| yaw 跟踪比 | — | 0.188 | 同一次试验的另一口径 |

**口径说明**：README 的"vy 有效帧 7.6%"来自 18:57 那次试验；"15.6%"是另一段 260/911 的活动帧比例——**两个统计定义，不能混用**。

### 3.3 右移：右后轮永不抬

| 项目 | 数字 |
|---|---|
| 8 条主要训练臂的 `event_right_RR` | 最终全部 **0.000000**（训练中峰值 ≤0.0015，约每 700 帧一次，收敛后消失） |

| 几何原因 | 抬 RR 后支撑三角形 FR–RL 的边穿过重心投影，**静态稳定裕度 0** |

## 4. v2-step：根因（四层）

### 4.1 训练目标的问题

**（1）门禁要求了做不到的动作（几何死结）**：见 3.3——右后轮抬升在现有几何/质心下不可行，不是训练不足。

**（2）奖励资格与门禁不匹配（属 `unified_dr` 线）**：`calibration.json` 的 eligible 掩码把 16 个"方向×轮"组合里的 **7 个标成不可得分**：左移缺 RR、右移缺 RL、左转只认 RR、右转只认 FR/RL；而门禁要求**四轮各 ≥2 次**。两者对不上 → 三阶段分别 **32/33/31 项失败**，是**结构性不可能**，不是训练不够。
> 范围：这是 `unified_dr` 线的缺陷，**不能直接说成 jit/mu025 的奖励错**；但它证明"门禁设计"本身需要审。

**（3）步态没有轮差速通道**：v2-step 删掉 vx 后轮速只由 `vx/R` 决定，**转向完全靠腿踏步**。宇树官方 AS2-W 也是踏步转向，所以**不是设计错误**；但意味着踏步必须自己产生足够偏航力矩，而目前没有"官方踏步能转多快"的基准。

### 4.2 训练域/资产的问题

**（1）摩擦：训练 0.5、实机 ≈0.25**（0.25 是估计值，无独立测量）

| 口径 | μ=0.5 | μ=0.25 | 实机 |
|---|---:|---:|---:|
| 静态保持 55/2（默认姿态） | 0.39 Nm | 5.37 Nm | — |
| 静态保持 55/2（实机姿态均值） | 3.44 | 6.14 | — |
| **刚性保持 kp=200（≈真实负载）** | **1.66** | **11.91** | **11–12** |
| 策略运行 PD 需求（前髋，μ025 重训） | 11.64 | 12.78 | 实机 6.19 |

**反证**：加关节摩擦 0.5/1.5/3.0 Nm 反而让 PD 需求下降（5.37→4.46）——关节摩擦不是缺项，缺的是接触/载荷。

**（2）后髋载荷分布未解**：仿真 6.0–9.6 Nm vs 实机 13–15.2 Nm；质心前后 −10…−40 mm 扫描不单调（前髋降、后髋不升）→ 是**接触/几何分布**问题（轮位、质心高度、接触面），不是单点平移。

**（3）关键否定结果**：μ025 重训 600 轮上机后 **yaw 斜率 0.146 < 0.199**；同时仿真门禁 right 从 0/4 回到 2/4、yaw_left 从 1/4 回到 3/4。⇒ 摩擦是必要背景，**不是转向弱的充分解释**。

### 4.3 部署合同/映射

- v2-step 的 `tanh`、55/2、5 Hz 轮滤波**未发现训练↔部署不一致**。
- **但 12 轴方向/零位没有统一核验**：早期现场人工标定记录 hip 符号 **−1**，后期重力锚定的表述 **+1**（可能坐标约定不同），两者未对齐。
- 实机包络被限制在 `|vy| ≤ 0.10`、`wz ≤ 0.30`（right 锁死），"转向弱"是**窄包络**结论。

### 4.4 证据质量

- 权重 SHA 三份要分清（`45b36` / `99995126` / `a3215`）；
- 30% 缺原始序列；7.6% 与 15.6% 不同口径；`zeroB_old` 是 jit 权重。

### 4.5 已排除/不成立的解释

| 假设 | 判定 | 依据 |
|---|---|---|
| 单纯调大动作幅值能修转向 | 不支持 | 低摩擦下没有有效偏航 |
| 只改 μ 就能修转向 | 已否定 | 0.146 < 0.199 |
| RR 不抬只是训练轮数不足 | 不支持 | 15 臂 + 15 mm 全失败；几何裕度 0 |
| 转向必须用轮差速 | 不成立 | 官方也是踏步转向，是设计选择 |
| 7/16 是 jit/mu025 的直接根因 | 证据不足 | 属 unified_dr 线 |

### 5.3 offset 补偿为什么失败

offset 改的是**目标几何**，不是**刚度**：后腿被拉直 → 重心前移 → 前腿必须反向用力撑（FR_thigh −0.305）→ 机身前倾 + 力矩嗡鸣。问题只是从后腿转移到前腿。

### 5.6 为什么仿真也会下沉，但数字不同

## 6. HIMLoco：根因

### 6.1 先排除"kp/kd 抄错"

控制器按 `motors.kp = config_.stiffness[i]` 下发；审计文档 PD 行判 ✓。

### 6.2 主因：τ/kp 余量不足

`q_actual ≈ q_cmd − τ_gravity/kp`。kp 55→85（kd 2→3.2）在同一仿真里把 RR_calf 从 0.378 降到 0.110、pitch 从 −9.17° 到 −5.26°（实机 −6.13°）。

### 6.3 次因：训练世界太轻

交付方自述"前髋力矩只有实机一半、策略在该静差下训练"；实机负载大 2 倍 → 同一 kp 下静差更大。方向：仿真前髋 3.7–5.1 Nm，实机 11–12 Nm（反演/实测口径见 §5.4）。

### 6.4 未验证的猜测：交接瞬间"变软"

站姿可能用 85/3.2（T15 现场）或 200/4（原厂 `ai_stand_up`）；策略是 55/2；`deploy-drive-kp65.yaml` 是策略相位 65 的候选（已构建、未执行）。100 步 ramp 只平滑**目标**、不平滑**刚度**——若站姿确实用更高增益，B 按下瞬间会有刚度阶跃。**无实测记录 → `UNKNOWN`**。

### 6.5 已修好的合同细节

100 步零命令 ramp 原来缺失（第一帧下发插值后目标 ≈0.1 rad，训练只给 1%）；补齐后 `MAX_LEG_STEP` **0.1206 → 0.0582 rad**，C++↔Python parity 1.19e-07。解释首帧冲击，**不解释持续静差**。

### 6.6 已排除/不成立

| 假设 | 判定 | 依据 |
|---|---|---|
| kp/kd 训练与部署不一致 | 排除 | 三份审计 + 控制器源码 |
| offset 能解决下沉 | 排除 | FR_thigh −0.305、嗡鸣、2.2 s 后 X |

| 策略能力不足（Isaac 72 试次） | 无证据 | 0 终止、0 非轮触地 |

### 6.7 仍未排除的物理侧因素（不能只归 kp）

即使"τ/kp 余量 + 训练载荷口径"是主因，以下仍**没有数据**排除，写在这里避免被读成"已经定案"：

- 减速器背隙（会放大 `cmd−actual` 的静态差）；
- 电池电压/温度导致的力矩能力变化；
- 驱动器在高负载下的限幅/降额（Phase J 的执行器排除只覆盖**静态髋力矩**，没有覆盖后小腿在更高负载下的限制）；
- 真实接触力分布/接触斑（见 §5.6，仿真与实机分布不同）；
- 关节零位偏差（12 轴未核对）。
